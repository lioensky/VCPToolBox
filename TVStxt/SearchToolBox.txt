# VCP 联网与搜索工具箱能力收纳
这里收纳了 VCP 强大的联网检索、网页爬取及深度研究工具。

## 1. 语义穿透联网检索 (VSearch)
首选联网引擎。支持语义级检索范围与多关键词并发搜索，适合获取多角度观点。
tool_name:「始」VSearch「末」,
SearchTopic:「始」探讨AI在医疗诊断中的最新应用「末」,
Keywords:「始」AI medical diagnosis 2024, 深度学习 医疗影像 突破, transformer models in healthcare「末」,
SearchMode:「始」grounding「末」,  //三个模式，'grounding' (Gemini-Google搜索-快),  'grok' (Grok推理级搜索-缓慢-支持舆论媒体搜索-注意偏见),默认grouding
ShowURL:「始」false「末」,
ink:「始」mark_history「末」 //可选，是否将检索结果写入history.json

## 2. 网页/文件内容爬取器 (UrlFetch)
用于获取特定网页、在线文件或本地文件的文本/快照。
tool_name:「始」UrlFetch「末」,
url:「始」(必需) 网页/文件 URL (本地路径请以 file:// 开头)「末」, 
mode:「始」(可选) 'text' (默认) 或 'snapshot' (多模态网页快照) 或 'jina' (AI级网页转md，推荐该模式) 或 'image' (读取网络图片)「末」

## 5. 专业级实时与垂直领域检索，AnySearch，单次最多五路真并发
想查实时信息、专业资料或网页正文时用这个工具。普通搜索只给 query；垂直搜索再加 sub_domain 和必要的 params。

[===vcp_fold:0.0::desc:AnySearch 基础搜索与编排===]
核心参数:
- query: 默认搜索词；sub_domain: 「域.子域」；params: 优先写 k=v,k2=v2；max_results: 1-10。
- queries: 同一路线批量搜索 1-5 个词，用 | 分隔。
- 编号路线: query1..query5、sub_domain1..5、params1..5、max_results1..5，最多五路并发；每路继承顶层默认值，queryN 仅在该路线需要改写搜索词时填写；不能与 queries 混用。
- url: 提取网页正文。领域或深参数不确定时，用 command=get_sub_domains, domain=域 查询，不要猜。

基础搜索:
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
query:「始」what is photosynthesis「末」
<<<[END_TOOL_REQUEST]>>>

多路线搜索:
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
query:「始」Go 1.26 有哪些重要变化「末」,
sub_domain1:「始」code.doc「末」,
params1:「始」library=golang「末」,
query2:「始」Go 1.26 new APIs examples「末」,
sub_domain2:「始」code.snippet「末」,
sub_domain3:「始」general「末」,
max_results:「始」3「末」
<<<[END_TOOL_REQUEST]>>>
[===vcp_fold:0.5===]

[===vcp_fold:0.35::desc:AnySearch 批量搜索、正文提取与兼容参数===]
同路多词用 queries，顶层 sub_domain/params/max_results 会注入每条:
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
sub_domain:「始」finance.news「末」,
params:「始」type=general「末」,
queries:「始」AI 芯片需求 2026|全球 EV 市场展望「末」
<<<[END_TOOL_REQUEST]>>>

提取正文只给 url。params 使用逗号分隔的 k=v 文本；目录括号是官方 Required 标记，部分受 type 等条件约束。不适用的参数不要传，完整规则用 get_sub_domains 查询。
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
url:「始」https://example.com/article「末」
<<<[END_TOOL_REQUEST]>>>
[===vcp_fold:0.5===]

[===vcp_fold:0.35::desc:AnySearch 复杂参数与多领域编排示例===]
复杂参数调用原则：已知参数语义时，直接把多个参数写成逗号分隔的 k=v 文本；字段含义、枚举、格式或条件必填不确定时，先查 get_sub_domains，读完返回规则再搜索。不适用的参数不要传空值。

指定软件包漏洞：
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
query:「始」Jinja2 2.4.1 已知漏洞与修复建议「末」,
sub_domain:「始」security.vuln「末」,
params:「始」type=package,value=PyPI:jinja2@2.4.1「末」,
max_results:「始」5「末」
<<<[END_TOOL_REQUEST]>>>

多条件生物医学文献筛选：
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
query:「始」large language models in clinical diagnosis「末」,
sub_domain:「始」academic.biomedical「末」,
params:「始」sort=date,source=MED,field=tiab,year_from=2024,has_pdf=true,open_access=false「末」
<<<[END_TOOL_REQUEST]>>>

跨领域复杂研究——顶层 query 是默认词，各编号路线只写需要覆盖的字段：
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
query:「始」OpenAI 近期动态「末」,
sub_domain1:「始」finance.news「末」,
params1:「始」type=general「末」,
query2:「始」OpenAI research papers 2026「末」,
sub_domain2:「始」academic.search「末」,
query3:「始」OpenAI API examples「末」,
sub_domain3:「始」code.snippet「末」,
query4:「始」OpenAI legal cases「末」,
sub_domain4:「始」legal.case「末」,
sub_domain5:「始」general「末」,
max_results:「始」3「末」
<<<[END_TOOL_REQUEST]>>>

参数不确定时只查目标领域，不要猜：
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
command:「始」get_sub_domains「末」,
domain:「始」travel「末」
<<<[END_TOOL_REQUEST]>>>
读完返回的完整规则后，再按其中的子域、枚举、格式和条件要求调用搜索。
[===vcp_fold:0.5===]

[===vcp_fold:0.35::desc:学术与文献检索 academic===]
想查学术论文、数据集、预印本、引用或生物医学文献时用 academic 领域。

子域与必填参数:
- academic.search: 通用学术搜索
- academic.dataset: 数据集搜索
- academic.preprint: 预印本搜索
- academic.citation(id): 引用搜索，必填 id
- academic.biomedical: 生物医学文献

academic.biomedical 常用参数:
- sort: relevance / date / pub_date / author / journal / cited
- source: MED / PMC / PPR / AGR / PAT
- field: tiab（标题+摘要）
- year_from / year_to: 年份范围
- has_pdf: true / false
- open_access: true / false
- date_type: 日期类型

示例:
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
query:「始」large language models in clinical diagnosis「末」,
sub_domain:「始」academic.biomedical「末」,
params:「始」sort=date,source=MED,field=tiab,year_from=2024,has_pdf=true「末」
<<<[END_TOOL_REQUEST]>>>

不确定参数含义时，用 command=get_sub_domains, domain=academic 查询完整 schema。
[===vcp_fold:0.5===]

[===vcp_fold:0.35::desc:金融与市场检索 finance===]
想查股票、基金、宏观经济、日历或筛选器时用 finance 领域。

子域与必填参数:
- finance.news(type): 新闻，必填 type
- finance.quote(type,symbol,cn_code): 行情，必填 type 和 symbol 或 cn_code
- finance.fundamental(type,symbol,cn_code): 基本面
- finance.macro(type): 宏观经济
- finance.calendar(type): 经济日历
- finance.screen(type): 筛选器

示例:
<<<[TOOL_REQUEST]>>>
tool_name:「始」AnySearch「末」,
query:「始」Apple 最新公司新闻「末」,
sub_domain:「始」finance.news「末」,
params:「始」type=stock,symbol=AAPL「末」
<<<[END_TOOL_REQUEST]>>>

不确定参数含义时，用 command=get_sub_domains, domain=finance 查询完整 schema。
[===vcp_fold:0.5===]

[===vcp_fold:0.35::desc:其他垂直领域选择===]
其他常用领域：legal 法律，health 医药健康，business 商业/公司/职位，security 威胁情报与漏洞，energy 能源电力，travel 航班，gaming 游戏与电竞，resource 图片，social_media 社媒，ip IP 信息，environment 空气质量，agriculture 农业，film 影视资源。
选择领域后使用「域.子域」；具体子域、必填项、枚举或罕见参数必须用 command=get_sub_domains, domain=域 查询，不要依赖此处静态复制。
