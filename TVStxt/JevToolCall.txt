# JEV 语义工具入口（实验）

当需要联网搜索、B站内容或图片生成时，可用一句完整、自然的话调用能力，而不必记忆插件参数：

<<<[TOOL_REQUEST]>>>
maid:「始」你的署名「末」
JEV:「始」请使用 {能力} 中的 '可选工具'，围绕【主要内容】，并参考[可选约束]来完成任务。「末」
<<<[END_TOOL_REQUEST]>>>

规则：
- 每个 JEV 块只执行一个动作。
- 请始终写完整的自然语言句子，保留“用、从、搜索、生成、修改、参考”等关系词以及正常标点；不要只堆叠标记。
- `{联网搜索}`：默认使用 VSearch。可选工具为 `谷歌搜索`、`谷歌学术`、`Tavily`、`AnySearch`、`B站搜索`、`B站获取`。
- `{图片生成}`：默认使用谷歌 NanoBanana2。可选工具为 `GPT生图`、`ZImage`、`豆包`。
- `【】` 标记句子中的主要搜索内容、视频地址或生图/修图指令。
- `[]` 标记句子中的次要搜索范围、年份、地区、尺寸、画幅、截图时间或图片 URL。
- 图片生成时，无图片 URL 表示生图；一个图片 URL 表示修图；多个图片 URL 表示多图合成。
- B站搜索可用 `[搜视频]` 或 `[搜UP主]` 指定类型；不写时默认搜索视频。`[UP主]`、`[用户]`、`[博主]`也会自动识别为搜索UP主。
- B站输入 URL、BV号或 av号时会自动获取字幕、评论和弹幕；需要截图时，在句子中加入 `[截图 30,120 秒]`。
- 不要填写真实插件字段，不要编造尺寸或复杂搜索参数。

核心示例：

JEV:「始」请使用 {联网搜索}，从[美国土豆产能]和[美国当前土豆价格]这两个次要方向，搜索【最近美国土豆是不是打折】。「末」

JEV:「始」请使用 {联网搜索} 中的 '谷歌学术'，在[2024年至今]的范围内搜索【大语言模型在临床诊断中的应用】。「末」

JEV:「始」请使用 {联网搜索} 中的 'B站搜索'，在B站上[搜视频]，查找【Python入门教程】。「末」

JEV:「始」请使用 {联网搜索} 中的 'B站搜索'，在B站上[搜UP主]，查找【影视飓风】。「末」

JEV:「始」请使用 {联网搜索} 中的 'B站获取'，获取视频【https://www.bilibili.com/video/BV1xx】的字幕、评论和弹幕，并在[截图 30,120 秒]指定的时间点截取高清画面。「末」

JEV:「始」请使用 {图片生成}，生成【一只坐在窗边的猫，电影感】，画面需要[适合手机壁纸]。「末」

JEV:「始」请使用 {图片生成}，参考图片[file:///C:/images/person.png]，把人物修改成【雨夜霓虹风格】，并使用[2K]清晰度。「末」

JEV:「始」请使用 {图片生成} 中的 'GPT生图'，生成【一张细节丰富的科幻城市概念图】，并采用[横版高清]画幅。「末」
