## 1. 总体结构与最终方程

RiverMemo 以 AGS 双尺度统一几何提供长期背景，以残差金字塔和有界 Sense 传播生成请求级河网，以局部／迁移双场及候选有序标签曲线提供语义与结构证据。读出分为两个阶段：先计算完整的四项基线评分并稳定排序，再按严格全局门控和候选落地证据决定是否启用虫洞排序通道。

### 1.1 四项基线评分

候选基线分由四项独立记账：

\[
\boxed{
S_0(c)=\operatorname{clip}_{[0,1]}
\left[B(c)+P(c)+G(c)+A(c)\right]
}
\]

- \(B\)：原始查询基础分加有界非负场共振。
- \(P\)：双场路径奖励，不乘 Ω。
- \(G\)：候选自身图证据奖励，乘 Ω 门控。
- \(A\)：直接锚奖励，不乘 Ω。
- 路径与图共享拓扑预算，默认 \(C_T=0.08\)；锚奖励有独立上限，默认 \(C_A=0.10\)。

基础分不包含路径奖励。场共振已经计入基础分，不能重复相加。截断扣分定义为四项之和减基线分，因此可直接复算：

\[
S_0=B+P+G+A-\Delta_{\mathrm{clip}}
\]

图奖励只由候选自身证据计算，不以同伴均值、条件期望或异常程度决定资格。角色用于解释，不给排序分配倍率、独占上限或前沿压制。多个优秀候选可以同时获奖；在查询观测、候选身份和配置固定的条件下，加入无关候选不改变既有候选的四项基线奖励。候选池截断、RRF 名次及最终排名不受此不变性保证。

### 1.2 边缘稀疏场景的条件式排序修正

**虫洞 RRF 不是普遍情况，不是常驻全局评分因子，也不替代完整拓扑、直接锚与 Ω 主干。** 它是针对极端边缘稀疏知识场景的回归优化解：图构建已经发现有事实支持的逻辑关联，查询传播实际经过该关系，但常规读出未充分反映这条逻辑链的候选证据，才通过严格门控允许路线修正排序。这里的逻辑链仍须落回文件与候选正文，不意味着共现本身构成形式逻辑或因果证明。

“边缘稀疏”说明适用问题，并非新增一个按 Ω 稀疏／稠密工况标签判断的开关；实际触发由完整观测、强显式来源路线、严格全局见证及候选落地共同决定。全局见证表示证据来自全局文件标签图，不表示给全部查询常驻施加全局因子。未触发是正常路径，资料充分的查询不需要虫洞 RRF 也能由完整主干完成读出。

完整基线先按基线分降序、联合候选分降序、联合候选序号升序排列，记名次为 \(r_0(c)\)，从 1 开始。通过全局门控的每条强虫洞路线只对具有落地证据的候选建立独立排序，记路线名次为 \(r_e(c)\)。

令 \(f_e\) 为路线原始观测电流，\(f_{\mathrm{ref}}\) 为观测中非虫洞、非即时回流、非自环普通边的最大正电流；没有这种普通边时，使用原始观测全部边的最大正电流。定义：

\[
w_e=\frac{f_e}{f_{\mathrm{ref}}}\Omega^\gamma,\qquad K=60
\]

若至少一个候选获得正路线贡献，则全部候选使用：

\[
\boxed{
S(c)=\frac{1}{K+r_0(c)}
+\max_{e:\,c\text{ 具备路线落地资格}}
\frac{w_e}{K+r_e(c)}
}
\]

无合格路线的候选，第二项为零。多路线贡献取最大值而非相加，避免相关支路重复投票。最终按融合分降序稳定排序，融合分相同时保留完整基线顺序。

**没有任何实际正路线贡献时，最终分直接保留 \(S_0(c)\)，基线分数逐位不变、排序不变，不转换成倒数名次分。** 启用融合时，四项基线仍完整保留，融合分不受四项评分上限约束，也不是四项之和、余弦或概率；路线权重可以大于 1。严格路线资格与落地条件见第 12 节。

评分实现见 [`assign_v3_scores()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2549)，候选观测与路径奖励计算见 [`run_native_with_connection()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2929)。

## 3. AGS 背景几何与共享传输图

### 3.1 双尺度统一几何

AGS 使用锚定贪心 Gram-Schmidt，在原始向量空间构轴，并通过两遍重正交化维护数值正交性。数学计算以 SQLite 原始向量为权威来源。

- **局部 Explain**：共现邻居解释单位目标标签 \(t\)，得到残差范数比 \(r_t=\|t-\sum_k\langle t,b_k\rangle b_k\|_2\)。它不是残差能量比；解释能量比约为 \(1-r_t^2\)。
- 锚增益采用有界映射 \(a_t=\operatorname{clip}_{[a_{\min},a_{\max}]}(a_0+a_1r_t^\beta)\)，参与传输条件。
- **全局 Span**：中心化星团方向生成真实标签标识的主题面、全库均值和前缀覆盖率，供 EPA 使用。
- 星团方向混合中心化目标与共现邻居方向，默认邻居混合比例 0.8；无有效邻居或方向退化时使用中心化目标方向。

全局基按覆盖率、增量阈值和最大基数截取前缀，不承诺固定主题面数量覆盖全库。实现见 [`memo_geometry.rs`](../rust-vexus-lite/src/memo_geometry.rs)。

### 3.2 传输与资产发布

共享传输图 \(G=(V,E,P)\) 的边来自文件有序标签共现；内联语义增益、枢纽校正、锚增益与行预算共同确定传输率。每行满足 \(\sum_jP_{ij}<1\)，为衰减传输和双场求解提供有界条件。

资产链为：事实快照 → AGS 统一几何 → 传输资产 → 运行时发布。几何在事务内发布，传输依赖事实与派生几何。查询使用已发布快照，不即时重建背景图。实现见 [`memo_artifact_builder.rs`](../rust-vexus-lite/src/memo_artifact_builder.rs) 与 [`load_artifact_with_connection()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1086)。

冷加载校验就绪状态、格式身份、依赖版本、解压上限、校验和及 CSR 结构。共享资产按签名缓存；相同签名发布保持幂等，不制造新代际。观测读取还校验运行时代际和数据库代际，禁止混用旧向量池与新事实行。

## 4. 查询观测、残差金字塔与种子

### 4.1 查询与 EPA

输入向量由调用方构造，不保证是全部历史直接拼接后的 embedding。查询原文用于轻量字面覆盖，不参与查询河网形态的文本分类。

EPA 在中心化查询 \(x=q-\mu\) 上读取前缀主题面。设主题面数量为 \(m\)、向量维数为 \(d\)，则：

\[
r_Q=\frac{\sum_{k=1}^{m}\langle x,b_k\rangle^2}{\|x\|^2},
\qquad
b_{\mathrm{iso}}=
\frac{m/d+\sum_{k=1}^{m}\langle\mu,b_k\rangle^2}{1+\|\mu\|^2}
\]

默认域内门控为 \(\operatorname{clip}_{[0,1]}((r_Q-b_{\mathrm{iso}})/(c_m-b_{\mathrm{iso}}))\)；分母不足时取零。逻辑深度为 \((1-H_Q)g_Q\)。熵只在语义前缀内计算，尾部主题面不能抬高前缀解释率。随机背景是校准参考，不是域外概率或另一张传播图。实现见 [`analyze_epa_with_mode()`](../rust-vexus-lite/src/memo_pipeline.rs:306)。

### 4.2 图内残差分解

每层在当前残差上检索既定 Top-K 标签池，先排除当前 CSR 节点索引之外的标签，再读取权威向量并正交投影。图内无出边节点仍有资格；过滤不扩大 Top-K、不补位，池被图外标签占满时可以没有可接受层。

设当层输入为 \(r_\ell\)，投影后残差为 \(r_{\ell+1}\)。边际解释能量和标签贡献分别为：

\[
e_\ell=\frac{[\|r_\ell\|^2-\|r_{\ell+1}\|^2]_+}{\|q\|^2},
\qquad
a_{\ell,t}=\frac{|\langle r_\ell,b_t\rangle|}{\|r_\ell\|}
\]

两者量纲不同。默认边际解释能量低于 0.03 的层不接受、不注入；默认最多三层，残差能量比例低于 0.1 时结束。拒绝层不发布标签或其投影结果；最终残差始终来自最后已接受层。实现见 [`analyze_pyramid_with_pool()`](../rust-vexus-lite/src/memo_pipeline.rs:651)。

### 4.3 字面焦点、别名与贡献门控

字面覆盖使用标签词元集合被查询覆盖的比例：ASCII 取小写完整字母数字词元，CJK 连续片段取相邻双字，单字片段保留单字。覆盖至少 0.5 为字面支持；它不是通用实体识别或语义同一证明。

普通非核心标签贡献门槛默认为同层最大贡献的 10% 与绝对 0.05 的较大值，且要求正相关。字面标签可豁免低贡献过滤。同层赞助者必须自身达到贡献门槛且正相关，与受助者余弦至少 0.80；受助者残差相似度至少 0.20。普通别名的借用幅度同时乘残差对齐与余弦紧密度，低贡献别名不能递归赞助。

首标签贡献平方大于 0.85 时，可保护最多两个共线隐式冗余标签：自身贡献小于 1e-6、残差相似度至少 0.75、与首项余弦至少 0.90；总借用幅度不超过首项贡献的 0.3。保护不修改原正交贡献、解释能量和残差，也不升级显式身份。

已接受层的强贡献标签减轻层衰减，但不因该机制超过未衰减权重。字面标签免语言误罚及层衰减；非核心字面标签使用 1.6 倍幅度校准，种子权重上限为 1。核心标签保留核心增益契约，不套用该非核心上限。

存在当前图内有效显式种子时，隐式种子统一等比例缩放，使其最大权重不超过显式最大权重的 0.35 倍，并保持隐式权重比例；图外显式标签不参与压制基准，无有效显式焦点则不做相对压制。显式核心、字面种子与隐式种子分别保留来源身份。实现见 [`gate_tags_for_graph()`](../rust-vexus-lite/src/memo_pipeline.rs:888) 与 [`scale_implicit_seeds()`](../rust-vexus-lite/src/memo_pipeline.rs:874)。

### 4.4 路由残差与最终尾部

动态虫洞开启时，每个已接受层保存投影前残差。至少接受一层，且最后已接受层留下的尾残差能量有限、大于 1e-12、占原始查询能量至少 0.02 时，追加该尾残差作为最后一个路由输入。

接受 \(L\) 层时，追加条件满足则有 \(L+1\) 个路由残差；否则为 \(L\) 个。动态虫洞关闭时不保存路由残差。尾残差只供选边，不增加标签层或种子层、不改写已解释能量；拒绝后续层时不使用被拒层的剥离结果。

诊断字段 [`routingResidualCount`](../rust-vexus-lite/src/memo_pipeline.rs:1879) 与 [`routingTailAppended`](../rust-vexus-lite/src/memo_pipeline.rs:1880) 区分路由输入数量和尾部追加状态。尾部存在仅解除更深层支持资格限制，不保证发生动态虫洞注入。

## 5. 有界传播与请求级动态虫洞

### 5.1 状态、电流与累计观测

传播状态包含前驱、当前节点、原始活动能量、动量、跳数和来源层。沿真实边的注入为：

\[
f_{ij}^{(h)}=e_i^{(h)}P_{ij}d_{ij}\rho_{ij}
\]

普通／虫洞衰减默认分别为 0.25／0.70；立即回流乘 0.15。默认发火阈值 0.10、最低注入电流 0.01、安全跳数 4、每状态邻居名额 20、传播状态配置上限 2000。普通边消耗动量，虫洞边不消耗动量，均保留安全边界。

有限时域权重 \(a_h=\gamma^h/\sum_{r=0}^{H}\gamma^r\)，默认 \(\gamma=0.6\)。累计节点势为 \(E_i=\sum_ha_he_i^{(h)}\)。零跳 FIR 权重只影响累计观测，首跳电流使用原始种子活动能量；不能用面板累计能量直接代替首跳输入。

仅正 ID、有限且正能量、当前图内的种子被接收；同 ID 合并，孤立图内节点仍保留零跳观测。输入数、接收数和最终观察到的零跳数是不同口径。请求源场由最终输出节点累计能量归一化得到，包含实际到达的节点。实现见 [`sense_with_context()`](../rust-vexus-lite/src/memo_sensing.rs:385)。

河网边记录已通过注入门槛的实际电流事件；边流记录与目标状态裁剪、后继发火不是同一口径。可选逐跳转移记录还检查目标状态保留情况，并有独立硬上限，不能据边流计数声称完整后继路径已成立。

### 5.2 残差共鸣选边

来源层为 \(L\) 的状态只消费层索引大于 \(L\) 的残差：

\[
R(j\mid L)=\max_{\ell>L}[\,\cos(r_\ell,v_j)\,]_+,
\qquad
D_{ij}=P_{ij}R(j\mid L)^4
\]

目标向量来自 SQLite 权威原始向量池。动态候选只来自源的真实正权重 CSR 出边，须通过共鸣阈值与预估电流门槛。按动态分数降序、导电率降序、目标 ID 升序排序；默认在原有邻居名额内最多保留两个动态席位，静态顺序补齐剩余席位。

动态边使用虫洞衰减，但共鸣不直接乘进电流、不提供电流保底或额外能量，也不创建关系、改写传输图。默认共鸣阈值 0.2，请求级不同目标评估预算 4096。关闭开关、席位为零或目标预算为零时使用静态选边；阈值合法性仍校验。

目标按图内索引确定性截断，跨跳复用相似度与缺失向量结果；预算耗尽的未评估目标不参与动态共鸣，静态路径仍可使用。多路径合并保留最早来源层，不是完整多源血缘追踪。实现见 [`DynamicWormholeContext`](../rust-vexus-lite/src/memo_sensing.rs:281) 与 [`sense_with_context()`](../rust-vexus-lite/src/memo_sensing.rs:478)。

## 6. 双场、投影预算与向量复用

### 6.1 标量双场

同一查询源 \(S\) 与传输算子 \(T\) 求解：

\[
u_L=(1-\alpha_L)S+\alpha_LT(u_L),\qquad
u_T=(1-\alpha_T)S+\alpha_TT(u_T)
\]

默认 \(\alpha_L=0.15,\alpha_T=0.55\)。收敛条件下，\(u_\alpha=(1-\alpha)(I-\alpha T)^{-1}S\)。两场共享 CSR 遍历调度，各自判断收敛；默认迭代上限 80、容差 1e-9。有效域按累计场质量选取，默认局部 0.8、迁移 0.9。实现见 [`solve_dual_fields_with_pool()`](../rust-vexus-lite/src/memo_pipeline.rs:1721)。

候选读出使用各场除以本场最大值后的标量势，不把不同查询的原始总质量当作同一量纲。标量保留与高维投影预算独立：过滤低于本场最大质量 1e-12 倍的数值尾流，并保留有效域并集与河网必需节点。

### 6.2 种子流域投影

全部活跃河网节点作为两场共享内圈。零跳种子及记录来源提供根线索，真实观测边构造确定性多源森林；无法归属的核心节点作为独立内圈保留，不虚构连接。

每个“流域 × 场”沿真实正权重边，以负对数传输率为距离独立扩展。每通道先轮转获得最多两个外圈机会，再按重要性和近期质量收益、已用机会分配，每批最多四个。新节点须有本场已接纳的真实前驱，不能跳过桥接点选远端高峰。

默认两场投影集合的去重并集上限 \(K=256\)，核心计入预算；核心超过正预算显式失败，不静默裁剪或超额。预算为零只取消节点数量上限，不取消质量目标或工作限额。全局处理／发现状态上限为 8192，扫描边上限为 65536。

各场只用自己的支持集与质量投影，共享读取不等于共享资格。观测核心外节点采用温和入度折减 \(1/(1+\sqrt{\mathrm{inbound}/\mathrm{maxInbound}})\)，核心增益为 1。缺失向量不全图补位；支持集连通不保证有效向量子集连通。实现见 [`seed_basins()`](../rust-vexus-lite/src/memo_projection.rs:27)、[`grow()`](../rust-vexus-lite/src/memo_projection.rs:168) 与 [`project_basin_fields()`](../rust-vexus-lite/src/memo_pipeline.rs:1629)。

### 6.3 请求级复用

金字塔、动态虫洞、融合、双场和候选读出共享原始 FP32 标签向量载荷，只批量补读差集，每批最多 128 个标签 ID。候选正文向量和文件标签关系也批量读取，不新增逐候选 SQL。

投影预算不是整个请求向量池上限；动态目标和候选阶段仍会读取其他向量。4096 个 3072 维 FP32 向量仅载荷约 48 MiB，不能将数量预算解释为固定耗时、总内存上限或无损召回保证。

请求观测通过 [`MemoRuntime`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:554) 的句柄复用；全部内部消费者完成后释放，TTL 仅作兜底。释放句柄不清除常驻图，已取得共享引用的消费者可完成计算，最后引用释放后回收载荷。

## 7. 候选边界与路径证据

### 7.1 共同候选与权限

拓扑读出处理共同候选边界内的候选，不从全库凭空补回池外正确记忆。内部候选超集消费原始查询、增强查询、局部／迁移场、BM25、时间和锚来源，记录候选身份及来源；默认超集上限 300。

权限过滤先于候选归一化和统计，显式空权限集合表示无权限。候选标签顺序来自稳定文件序位，不是经正文验证的叙事或因果顺序。实现见 [`select_superset()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1362) 与 [`run_native_with_connection()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2769)。

### 7.2 Span-1／Span-2 路径

候选曲线 \(\Gamma_c=(t_1,\ldots,t_n)\) 的每个起点在相邻与跨一个标签的两种段中择优；Span-2 乘 0.7。相同端点对（包括反向重复表示）共用一次证据容量。总机会数仍为 \(n-1\)，不能因多枚举窗口刷倍数。

每场段势为两端标量势的几何平均。只有两端同在至少一个场的有效域内，且端点间存在真实正权重全局边，才有路径支持。路径并不虚构跨标签的中间传播链。

段质量为混合场势 × 方向平方根 × 连续性平方根 × 活跃支持增益 × 跨段折扣。其中：

- 场势按路径权重混合，默认局部／迁移 0.6／0.4。
- 连续性平均组合标签语义连续性与场连续性。
- 仅全局连接的活跃支持增益为 0.5；本次归一化活跃流 \(f\) 使其变为 \(0.5+0.5\sqrt f\)。
- 有活跃流时按活跃前／反向比例计方向，否则按全局前／反向导电率比例计方向，并保留方向下限。

段质量按有限机会平均，再以支持覆盖与标签到正文闭合收束：

\[
Q_c=Q_{\mathrm{core}}\left(0.5+0.25C_{\mathrm{path}}+0.25C_{\mathrm{tag}}\right)
\]

单标签没有关系段，但保留半幅最强场势的节点退化读出，不声称其具有路径关系证据。实现见 [`evaluate_path()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1516)。

## 8. 一对一拓扑对齐与支流置信度

### 8.1 节点绑定与质量信用

查询节点与候选标签首先按 ID 精确对应，其次计算权威向量余弦。语义匹配默认入口阈值 0.48。设余弦为 \(s\)、正文闭合为 \(h_t\)，质量为：

\[
a(r,t)=\sqrt{\nu(s)h_t}\,w(s),
\quad
\nu(s)=
\begin{cases}1,&\text{精确}\\
\operatorname{clip}_{[0,1]}((s-\tau)/(1-\tau)),&\text{语义}
\end{cases}
\]

语义余弦低于 0.65 时额外乘 \(w(s)=(s/0.65)^2\)，否则为 1。候选与查询双侧容量均为一；确定性贪心先精确，再按查询节点权重乘匹配质量降序，最后按 ID 和位置稳定裁决，重复标签 ID 不能多次响应。

节点覆盖按能量加权质量信用计算，不是匹配即记满票。候选无支持有效长度为标签数减已接受质量之和，其密度校准为：

\[
d_c=\frac{1}{1+[\mathrm{unsupported}-6]_+/16}
\]

密度只折减节点覆盖信用，不直接按标签总数硬罚；充分支持的丰富标注不因长度受罚。最强匹配质量指已接受对齐的质量，包含闭合和弱匹配折减，不是原始余弦。实现见 [`evaluate_topology()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1737)。

### 8.2 边对应与连续图分

查询实际河网边按最低流量和数量上限读取，默认阈值 0.015、上限 96。两端均有不同候选标签对应时，比较归一化 hop 距离、候选序位距离、方向及来源独立性。来源独立性有 0.15 下限，不将唯一来源直接归零。边覆盖按端点质量折算。

节点图分为节点对齐与平均闭合乘积的平方根。边图分组合节点对齐、相对距离、方向、边拓扑和 Motif；Motif 当前复用边拓扑值，不是独立模体或图同构匹配器。三个图头为：

\[
G_A=0.75G_N+0.25G_E,\quad
G_P=0.25G_N+0.75G_E,\quad
G_N^{\mathrm{narr}}=0.15G_N+0.85G_E
\]

最终图分 \(g_c=p_AG_A+p_PG_P+p_NG_N^{\mathrm{narr}}\)。三种形态概率只由查询河网的深度、集中度、浅层比例、方向流、链性、分叉、汇合与持续性统计产生；稳定 Softmax 后按样本量与观测完整度向均匀先验收缩，不读取查询语言关键词或候选。

图分采用完整连续概率混合；支流覆盖和角色判定使用最大概率对应的主导模式。实现见 [`compute_query_morphology()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2239)。

### 8.3 支流覆盖与精度落地

设原始全河网节点／边覆盖为 \(C_N^{raw},C_E^{raw}\)，支流覆盖为：

\[
C_N=\operatorname{clip}_{[0,1]}(C_N^{raw}/0.35),\qquad
C_E=\operatorname{clip}_{[0,1]}(C_E^{raw}/0.20)
\]

\[
C_b=
\begin{cases}
C_N,&\text{原子主导模式}\\
0.70C_E+0.30C_N,&\text{非原子且匹配边数大于零}\\
0.35C_N,&\text{非原子且无匹配边}
\end{cases}
\]

\[
\boxed{\chi_b=\sqrt{C_b\,\overline h\,a_{\mathrm{node}}}}
\]

全网覆盖可靠性保留原始语义，供诊断及角色解释，不进入图奖励乘法链。支流置信度不是候选对全河网的完整复现保证。

完全没有精确节点命中且最强已接受匹配质量小于 0.65 时，精度因子 \(\pi_c=0.65\)，否则为 1。有精确命中或质量至少 0.65 的强软匹配不触发该折减。实现见 [`branch_coverage()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1694)、[`branch_confidence()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1710) 与 [`precision_grounding()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1702)。

## 9. 场共振与查询基础分

原始查询分 \(q_c\) 为查询与正文余弦裁剪至 \([0,1]\)。仅有限且非零的场投影向量参与场余弦混合；缺失场不占分母。默认纯语义权重为查询／局部／迁移 0.7／0.2／0.1。有效场权重占比记为 \(\lambda\)，双场加权余弦记为 \(F_c\)。

标量支持按候选标签 ID 去重后计算。每场的覆盖为有效域内标签比例，势能为候选标签归一化场势的平均值：

\[
C=\min(1,\mathrm{coverage}/0.5),\quad
V=\min(1,\mathrm{potential}/0.02)
\]

\[
s_f=\max\left(\sqrt{CV},\ 0.1\sqrt{\frac{\mathrm{potential}}{\mathrm{potential}+0.02}}\right),
\qquad s_c=\max(s_L,s_T)
\]

\[
\boxed{
R_c=\min\left(\min(0.03,\lambda[F_c-q_c]_+)\,s_c,\ 1-q_c\right),
\qquad B(c)=q_c+R_c
}
\]

先封顶再乘支持，不能由高场余弦抵消低标量支持。无有效场时共振为零，基础分保留查询分。场支持不使用带基线的主题性指标，也不依赖候选池均值。实现见 [`scalar_field_support()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1969) 与 [`field_resonance()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1716)。

## 10. Ω 与拓扑共享预算

Ω 只读取查询河网，不读取候选。设零跳种子数为 \(N_s\)、实际边数为 \(M\)、到达节点数为 \(N_r\)、涌现数为 \(N_e=\max(0,N_r-N_s)\)：

\[
\Omega_E=\operatorname{clip}_{[0,1]}\frac{M}{\kappa_E\max(1,N_s)},\qquad
\Omega_N=\operatorname{clip}_{[0,1]}\frac{N_e}{\kappa_N\max(1,N_s)}
\]

正流归一化熵为 \(\Omega_F\)，无正流为 0，单条正流为 0.5。最终：

\[
\Omega=\operatorname{clip}_{[0,1]}
\left[\sqrt[3]{\max(\Omega_E,\varepsilon)\max(\Omega_N,\varepsilon)\max(\Omega_F,\varepsilon)}\,\chi_{\mathrm{obs}}\right]
\]

默认 \(\kappa_E=0.5,\kappa_N=0.3,\varepsilon=0.02\)；完整／不完整观测因子分别为 1／0.5。几何平均有 epsilon 底值，空图不应被描述为 Ω 必然严格等于零；没有候选结构证据时图奖励仍为零。工况边界为 0.12、0.45，分别解释为坍缩、稀疏、稠密，不代表主题正确率。实现见 [`compute_omega()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2483)。

设路径质量为 \(Q_c\)，标量覆盖／势能组合为 \(U_c\)：

\[
U_c=\operatorname{clip}_{[0,1]}(0.35c_L+0.25c_T+0.25v_L+0.15v_T)
\]

\[
P(c)=\min\left(C_T,\ C_T\operatorname{clip}_{[0,1]}(0.625Q_c+0.375U_c)
\sqrt{\operatorname{clip}_{[0,1]}(Q_c/\tau_P)\,q_c}\right)
\]

默认 \(\tau_P=0.15\)。图方向支持 \(\delta_c\) 在有匹配边时为 \(0.25+0.75\,\mathrm{directionScore}\)，无边时为 0.25。图请求与最终奖励为：

\[
G_{\mathrm{self}}=\min(C_T,C_Tg_c\chi_b\delta_c\pi_c),
\qquad
\boxed{G(c)=\min\left(G_{\mathrm{self}}\Omega^\gamma,\ [C_T-P(c)]_+\right)}
\]

默认 \(\gamma=1\)。路径优先占用预算，图奖励再乘 Ω 并消耗剩余量，因此 \(P+G\le C_T\)。不能把 Ω 写成同时门控路径与图，也不能把全网可靠性再乘入图置信度。

## 11. 直接锚与解释角色

### 11.1 接触与幅度

正常锚资格来自零跳核心、字面和普通种子。隐式种子按最大源质量的 20% 过滤，显式核心／字面种子豁免；无可用来源时可从源场构造兼容锚，但受回退可靠性上限限制。

接触采用精确优先、双侧一对一确定性贪心，最多三个独立接触。语义阈值至少 0.88，以超出阈值的比例连续计权并乘语义折扣，默认 0.7。

存在有效显式源时，源质量以显式最大质量归一化；否则用所有可用源的最大质量。候选没有命中显式源不会改变该分母。各接触贡献组合归一化质量、全局入度特异性、正文闭合、全局稀有度代理和匹配权重；隐式接触永久乘 0.35，与是否存在显式焦点无关。

全局入度特异性和稀有度代理不使用候选池频率。接触通过 noisy-OR 聚合 \(a_c=1-\prod_s(1-a_{sc})\)。可靠性为平均闭合平方根，有精确接触时不按种子数量打折，纯语义接触另乘语义折扣。

回退锚可靠性默认不超过 0.5。纯隐式候选可靠性不超过 0.35，最终锚强度不超过 0.035。没有显式焦点也不能靠隐式精确碰撞解除限奖。实现见 [`anchor_contacts()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2068) 与 [`compute_anchors()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2105)。

### 11.2 绝对激活与角色

锚强度 \(H_c=a_cR_c^A\) 采用绝对阈值平滑激活：

\[
A(c)=C_A\,\operatorname{smoothstep}
\left(\operatorname{clip}_{[0,1]}\frac{H_c-\tau_A}{s_A-\tau_A}\right)
\]

默认 \(\tau_A=0.05,s_A=0.20,C_A=0.10\)。强度不超过阈值时奖励为零；饱和区间退化时按实现采用阈值以上直接激活。纯隐式强度上限低于默认阈值，因此默认无锚奖励；自定义更低阈值可能产生有限奖励。

原子主导模式解释为原子概念。非原子候选成为直接答案，必须同时满足真实显式精确接触和观测正文闭合至少 0.55；隐式精确接触加显式语义接触不等价于显式精确身份。结构角色受原始覆盖可靠性与 Ω 解释门槛约束，但角色不改变奖励公式。实现见 [`assign_v3_scores()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2549)。

## 12. 严格全局门控与虫洞排序通道

### 12.1 观测路线资格

只消费当前请求真实观测到的虫洞边：非即时回流、非自环、正原始电流、正且不同的端点 ID，且同方向关系必须是已发布 CSR 中的真实正权边。目标权威向量必须有限且非零。动态选边也只能使用真实 CSR 关系，不要求它同时具有持久化虫洞标记；读出不再检验来源与终点的语义相似度。

同一有向端点对只保留最大电流，按电流降序、来源 ID 升序、目标 ID 升序稳定排序，再受既有最大河网边数限制，默认 96，读取上限至少为 1。路线相对流量始终为：

\[
\rho_e=\operatorname{clip}_{[0,1]}
\frac{f_e}{\max_{\text{原始观测全部边}}[f]_+}
\]

分母不因路线过滤、门控或候选池改变而重新归一化。门控前资格计数在路线数量截断之前取得。

实现见 [`build()`](../rust-vexus-lite/src/rivermemo_wormhole.rs:141)。

### 12.2 全局文件联合见证

门控查询的是同一读取事务中的全局文件标签事实，不受共同候选文件集合、查询文件夹或候选返回范围限制；它不扩大候选返回权限，也不把见证文件加入候选池。

每条路线必须找到一对符合全部条件的见证文件：

1. 两个不同文件均同时包含来源与终点标签；重复标签行不算多个文件。
2. 两文件校验和均非空且不同。
3. 两文件共享至少一个第三标签；第三标签排除路线两端和全部显式焦点。
4. 至少一个文件包含另一个显式焦点；该焦点不是路线两端。显式焦点来自零跳核心或字面种子，不包含普通隐式种子。

按文件 ID 稳定枚举见证对；符合条件时，焦点与第三标签各取最小 ID。每条路线最多检查 128 个联合文件，每文件最多 128 个标签；通过读取第 129 项探测超限。任何一项超限都使该路线门控失败，不以截断样本放行。未通过门控不影响完整基线计算。

不同文件与不同校验和只表示重复出现的非完全相同内容，不证明证据相互独立、候选相关或关系因果成立。数据库读取错误按原生错误路径返回，不伪装成正常无路线回退。

实现见 [`gate()`](../rust-vexus-lite/src/rivermemo_wormhole.rs:33) 和 [`refine()`](../rust-vexus-lite/src/rivermemo_wormhole.rs:59)。

### 12.3 强路线与候选落地

通过全局门控仍不足以获得排序贡献。还必须同时满足：

- 请求观测完整，且 Ω 大于零。
- 路线来源是零跳核心或字面种子。
- 路线相对流量至少 0.5，仍使用完整原始观测的最大流量作分母。
- 目标向量与候选正文的裁剪余弦为正。
- 候选至少一个文件标签与目标有精确 ID 对应，或具有超过语义节点阈值的余弦；该标签到候选正文的余弦也必须为正。实现将精确 ID 的相似度置为 1，统一要求严格大于配置阈值，默认阈值 0.48。

匹配标签按目标相似度择强，平分按标签 ID 升序；标签到正文闭合在此是正值资格门槛，不再作为额外乘数。对合格候选定义：

\[
E_e(c)=\rho_e
\operatorname{clip}_{[0,1]}\cos(v_{\mathrm{target}},v_c)
\Omega^\gamma
\]

每条路线按该证据降序排列，平分时保持基线顺序，再按第 1.2 节执行解释力度加权 RRF。Ω 同时参与路线证据与通道权重：前者用于路线内排序，后者决定融合贡献；不是将证据分再乘入 RRF，也不是把 Ω 解释为路线正确概率。

不要求候选包含来源标签或完整复现查询图；也不允许仅凭目标与正文的泛语义接近，在没有候选标签落地时获取贡献。来源—终点远距离语义关联由真实关系、全局联合见证及候选落地约束，不靠来源—终点相似度门槛替代。

实现见 [`correction()`](../rust-vexus-lite/src/rivermemo_wormhole.rs:224) 和 [`fuse_rrf()`](../rust-vexus-lite/src/rivermemo_wormhole.rs:415)。

## 13. 原生执行、结果与诊断

### 13.1 执行链

1. 读取控制面配置、查询向量、原文和已发布资产签名。
2. 原生 EPA 校准 → 图内金字塔 → 字面／贡献门控 → 带残差上下文的 Sense。
3. 生成河网、增强查询、标量双场和预算内投影，保存同代请求观测。
4. 准备显式权限范围及候选计划；联合原生路径在后台任务内完成 ANN、合并、展开、去重和拓扑读出。
5. 批量加载候选曲线并补读向量差集；并行计算路径、对齐、标量支持和锚接触。
6. 计算查询形态、Ω、候选自身四项奖励及共享预算，得到完整稳定基线排序。
7. 对真实观测路线执行全局联合见证门控；为具有候选落地证据的强路线计算解释力度加权 RRF，再稳定截取 Top-K。门控读取可在候选数学计算前准备，不改变评分的两阶段依赖。
8. 组装公共结果；全部请求内消费者完成后释放句柄与请求载荷。

一次新观测请求通常包含观测任务和联合检索任务，不能称整个请求只有一次 N-API 调用。多索引 ANN 使用共享读锁，不是无锁；候选级数学并行不代表全部检索阶段都并行。元思考可复用同一观测，但无有效 grounded route 时不得伪装为 Sense 逻辑链。

### 13.3 管线与候选诊断

严格门控回执包含每条路线的联合文件、精细见证、是否截断及接纳状态；同时记录全局证据范围、门控前路线数、门控后路线数、RRF 常数、强流量比例及权重参照模式。回执见 [原生参数组装](../rust-vexus-lite/src/rivermemo_topology_v3.rs:3160)。

候选 [RRF 跟踪](../rust-vexus-lite/src/rivermemo_wormhole.rs:459) 记录是否实际启用融合、基线名次、基线分、基线倒数名次贡献、虫洞贡献和最终分；获胜路线包含原始／相对流量、参照流量、权重、路线名次及候选落地证据。没有合格路线或贡献时，获胜路线为空。启用融合后不能用基础分、路径、图及直锚的相加结果复算最终融合分；四项之和仅用于复算基线分。

- 路由残差数量和尾部追加状态见 [`PipelineDiagnostics`](../rust-vexus-lite/src/memo_pipeline.rs:1866)。
- 输入、接收、缺失、无效、重复及最终零跳种子分别计数；缺失 ID 和缺失显式 ID 列表各有 64 项上限，并报告截断。见 [`SenseDiagnostics`](../rust-vexus-lite/src/memo_sensing.rs:180)。
- 动态虫洞区分候选、入选、实际电流事件和静态 Top-K 外提升，并记录目标评估、SQL、点积、缓存、预算及耗时。事件按状态和跳累计，不等于唯一边数、后继发火或语义正确。
- 双场诊断区分标量求解、有效域、选点、有效向量和投影质量比例；预算用尽不等于满足目标质量。
- 候选详细跟踪给出原始节点／边覆盖、支流节点／边覆盖、支流组合与置信度、最强已接受质量、精度因子、场支持及支持前共振。
- 图请求跟踪中的 [`requestedGraphBonus`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:3068) 已乘 Ω、尚未扣路径预算；最终图奖励可能进一步缩小。
- [`topologyV3`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:3028)、相对拓扑、几何与观测明细仅在请求详细跟踪时输出；不导出完整河网、逐节点绑定表或全部锚接触。

兼容配置中的条件同伴带宽、同伴样本门槛、创新系数、批级锚异常系数、前沿控制及种子数量可靠性饱和项不参与最终奖励；准确字段以原生 [`retiredControls`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:3158) 回执为准。兼容读取不表示这些控制仍生效。

## 14. 不变量与运行边界

1. 共同候选机制、权限和过滤范围必须保持明确；排序不能证明池外召回率。
2. 图内资格按节点索引判断，不以有无出边判断；图外标签不占正交解释能量。
3. 尾残差只供路由，不制造种子、解释能量、历史边或额外电流。
4. 节点对齐与锚接触分别保持双侧一对一容量，不能把主题相似偷换为精确身份。
5. 图奖励使用支流置信度；原始全网可靠性只作诊断和角色解释，不重复乘入奖励。
6. 路径不乘 Ω，图乘 Ω，二者共享拓扑上限；锚点独立限额。
7. 原始查询是基础分下限，不是启用 RRF 后最终分的下限，也不是最终名次下限。
8. 高 Ω 只表示传播可观测，不证明主题正确、实体同一或正文因果成立。
9. AGS 几何、请求河网、双场、投影集合和锚点不能相互替代证据。
10. 签名、资产代际、数据库代际和请求生命周期必须一致，过期观测失败关闭。
11. 全局文件标签见证与候选返回范围分离；严格门控不改变候选权限或补回池外结果。
12. 没有实际路线贡献时，保留基线分数与顺序；启用时四项基线不变，融合独立记账。
13. 不完整观测、弱路线、未落地候选或超限见证不获取虫洞 RRF 贡献；多路线取最大贡献，不累加。

部署原生模块必须停止加载它的服务，替换对应平台文件后重启，核对真实查询返回的原生读出与管线标识；已加载进程不能热替换。Windows x64 MSVC 产物不能用于其他平台。本文不触发编译、资产重建、数据库修改或运行数据操作。

共同候选读出只比较边界内的排序，不能据此推断全库精确召回率。算法不保证指定候选名次、固定延迟，或每个查询都触发动态虫洞及排序融合。Ω 的稀疏／稠密工况描述请求河网状态，不等同于某主题在知识库中的实际资料密度；基线本身具备充分证据时，不需要虫洞通道触发才能正常读出。

## 15. 总结

RiverMemo Topology V3 的最终实现由同一条受约束的计算链闭合：

**AGS 背景 → 图内残差种子 → 有界真实边传播 → 请求河网与双场 → 候选路径及一对一拓扑 → 支流置信度与 Ω → 共享预算图增益及独立锚增益 → 完整基线排序 → 严格全局门控与候选落地 → 解释力度加权 RRF 或基线原样返回。**

基础分、拓扑、直接锚与 Ω 构成完整基线；严格全局见证与候选落地决定虫洞排序通道资格，原始电流相对于普通传播的解释力度决定通道权重。两阶段分别记账，不把融合分冒充余弦或四项奖励之和。
