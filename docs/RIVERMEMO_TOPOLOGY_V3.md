## 1. 总体结构与最终方程

RiverMemo 在全局 Chunk 双曲几何上召回正文候选，在双曲 Tag 场上为残差金字塔选取标签。局部 Cone-AGS 与全局 Span 提供长期背景，原 Tag NNLS 和有界 Sense 生成请求河网。读出器先按候选对父概念的归属程度校准种差分，再结合双场共振与拓扑证据排序。直接锚保留接触观测，不产生独立奖励。

### 1.1 连续最终分

\[
\boxed{S(c)=\operatorname{clip}_{[0,1]}[B(c)+P(c)+G(c)]}
\]

- \(B\)：原查询／种差混合分与有界非负场共振。
- \(P\)：路径质量和标量场支持奖励，乘 \(\Omega^\gamma\)。
- \(G\)：候选图证据与 Hop-1／跨文件虫洞传输证据的有界互补。
默认拓扑预算 \(C_T=0.08\)，路径优先占用，满足 \(P+G\le C_T\)。场共振包含在 \(B\) 内，拓扑奖励为 \(P+G\)，不得重复相加。

\[
S=B+P+G-\Delta_{\mathrm{clip}}.
\]

排序分与输出最终分相同：`ranking_score == final_score`。图奖励按候选自身证据计算，角色仅解释证据；查询观测、候选身份和配置固定时，加入无关候选不改变既有候选的自身奖励。候选池截断和名次不受该不变性保证。

### 1.2 传输证据的共享预算合并

令 \(w=\Omega^\gamma\)、\(g_0\) 为候选自身图请求：

\[
g=\min(g_0w,[C_T-P]_+),\qquad
t=C_T\max(e_{\mathrm{Hop1}},e_{\mathrm{XW}}).
\]

两项传输证据均已包含 Ω 门控。最终图奖励为：

\[
G=\min\left(
C_T[1-(1-g/C_T)(1-t/C_T)],
[C_T-P]_+
\right).
\]

\(C_T=0\) 时奖励为零；单项证据为零时保留另一项。合并从原始图请求与传输证据重算，不把上次合并值作为新证据，保持幂等；该有界互补算子不声明统计独立。

内部虫洞通道不将分数转换为倒数名次。最终按连续分降序稳定排序，同分保留按原最终分、联合候选分和联合候选序号得到的比较器次序。外部 Rerank+ 的 RRF 排位融合不属于内部拓扑评分。

实现见 [`assign_v3_scores()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs)、[`apply_unified_bonus()`](../rust-vexus-lite/src/rivermemo_wormhole.rs)。

## 2. 对象、职责与生命周期

| 对象 | 内容 | 生命周期及职责 |
|:--|:--|:--|
| Chunk 双曲场 | 全局均值轴、64 点分位映射、紧凑导航图、目录与成员版本基线 | 同模型共享训练代几何；查询同步实时成员与范围，增量原件单独评分 |
| Tag 双曲场 | 绑定原生资产的 Tag 编码、半径、导航图与方向目录 | 按资产签名缓存，供金字塔每层选取标签池 |
| 统一背景几何 | 局部 AGS 选列的非负锥残差／锚增益，全局星团主题面、均值与覆盖率 | 重建后同事务发布，供传输构图及 EPA 使用 |
| 共享传输图 | 有向标签关系、传输率、入度、锚增益、来源证据 | 发布后由运行时共享，不按查询改写 |
| 请求河网 | 累计节点势、实际注入边流、来源及跳数 | 单次查询生成，供拓扑、形态和 Ω 读取 |
| 请求双场 | 局部／迁移标量势、有效域和投影向量 | 同一查询源与共享传输算子的两个响应尺度 |
| 候选曲线 | 文件标签序位、权威标签向量、标签到正文闭合 | 在权限范围及共同候选边界内加载 |
| 请求观测 | 河网、双场、查询向量及原始标签向量池 | 原生运行时持有，全部内部消费者完成后释放 |

AGS 的局部／全局是预计算几何尺度；双场的局部／迁移是查询响应尺度，不能互换。主题面不是传播边，投影支持集也不是实际传播河网。

JavaScript 负责控制面配置、权限范围、候选计划和稳定结果组装。Rust 负责 EPA、金字塔、门控、Sense、融合、双场、候选曲线、形态、Ω、锚点及最终评分；候选热点通过 Rayon 并行。主入口见 [`RiverMemoEngine.rerank()`](../RiverMemoEngine.js:525) 与 [`run_pipeline()`](../rust-vexus-lite/src/memo_pipeline.rs:2140)。

### 2.1 生产候选与范围视图

同一数据库、模型和维度共用全局 Chunk 双曲场。日记本、署名、时间、目录及文件允许／排除集合决定结果范围；精确日记本列表直接下推原生范围判定。范围内不超过 128 个 Chunk 时直接精确评分，更大范围使用全局图导航。

训练对单位 Chunk 向量计算全局均值 \(\mu\)，以绝对轴对齐度 \(a(v)=|\langle v,\mu/\|\mu\|\rangle|\) 构造 64 点经验分位映射 \(F\)：

\[
r(v)=0.35+0.30[1-F(a(v))]^{1.10}.
\]

构图、查询和增量端点使用同一映射。候选精排读取 SQL 原始向量，按精确双曲距离截取候选池；常规精排量为请求数两倍，限制到 64–256 且至少等于请求量。纯 ANN 返回负距离，V5 读出输入仍为原查询余弦。

生产表保存实时成员、范围元数据及双曲场，不建立旧 TDB-SM 全库候选载荷，不预加载旧分库索引。AB 才启用旧候选载荷及余弦 Tag 观测；下一次生产查询释放旧候选载荷。实现见 [全局表](../rust-vexus-lite/src/global_chunks.rs)、[双曲 Chunk](../rust-vexus-lite/src/warped_chunks.rs)和 [LightMemo 执行](../rust-vexus-lite/src/light_memo.rs)。

### 2.2 实时同步与训练生命周期

- 新增、删除、目录、时间和正文变化在查询同步后立即生效。
- 不变向量继续使用训练图；新增或向量已修改的成员在冻结均值轴和径向映射中读取原件评分，与图候选合并。
- 日常事实版本前移不重建场、不改写场快照。范围内累计向量增量决定增量精排工作量。
- 手动全量训练与既有 1% Tag 阈值任务依次执行统一几何、原生传输资产发布、生产 Tag 双曲场和全局 Chunk 双曲场重建。
- Tag 场按资产签名恢复，Chunk 场按模型、维度、径向规则与成员基线恢复；冷请求依次尝试内存、快照和首次构建。已加载 Chunk 场使用自身快照中的径向规则，训练换代时更新。

## 3. AGS 背景几何与共享传输图

### 3.1 局部 Cone-AGS 与全局 Span

局部邻域来自有序共现事实，过滤缺失向量后按权重降序、Tag ID 升序排列。默认 `maxNeighbors=96`、`minNeighbors=3`、`maxBasis=24`、`minGain=0.015`。语义权重与 \(\ln(1+\text{共现权重})\) 组成选列先验。

局部 AGS 在原空间正交化。令 \(u_i=(I-BB^\top)v_i\)，每轮对满足 \(|\langle t,u_i/\|u_i\|\rangle|\ge\text{minGain}\) 的候选按 \(|\langle t,u_i\rangle|p_i\) 竞争，同分按 Tag ID；本轮低增益候选可在后续轮次重新竞争。范数不大于 \(10^{-6}\) 或非有限方向不入基。

选中原始单位 Tag 列组成 \(A\)，最终局部解释为：

\[
x^\star=\arg\min_{x\ge0}\|t-Ax\|^2,\qquad r_t=\|t-Ax^\star\|.
\]

目标已单位化，\(r_t\) 是范数比，\(r_t^2\) 是能量比。该最优性仅针对实际选中列，不包括未选邻居；原列非负约束不是正交轴系数截负。

对传入列分解 \(A=QR\)，小核求解 \(\min_{x\ge0}\|Q^\top t-Rx\|^2\)。小核保留全部传入列，包括相关射线；单位化缩放恢复后在原空间重构，复核非负性、对偶、平稳性、互补性与能量闭合。主动集子问题使用 SVD，FP64 累积，不添加岭正则。求解失败带 Tag ID 中止发布。

锚增益 \(a_t=\operatorname{clip}_{[a_{\min},a_{\max}]}(a_0+a_1r_t^\beta)\)，默认 \((a_0,a_1,\beta,a_{\min},a_{\max})=(0.75,1.25,1,0.5,2)\)。邻域不足保留状态记录，不生成成功残差。

全局 Span 对单位向量中心化，按星团混合生成候选方向；默认 `starNeighbors=48`、`starMix=0.8`、`priorMode=support`、`kMax=32`、`kSem=8`。选轴分数 \(\|u_i\|^2p_i\)，保留有符号子空间投影，输出真实 Tag 标签的主题面、均值及前缀覆盖率。其选轴及残差计算复用缓存投影、选择性重正交化与两遍逐轴数值回退。

实现见 [`memo_geometry.rs`](../rust-vexus-lite/src/memo_geometry.rs)、[`memo_nnls.rs`](../rust-vexus-lite/src/memo_nnls.rs)。

### 3.2 传输与资产发布

共享传输图 \(G=(V,E,P)\) 的边来自文件有序标签共现；内联语义增益、枢纽校正、锚增益与行预算共同确定传输率。每行满足 \(\sum_jP_{ij}<1\)，为衰减传输和双场求解提供有界条件。

资产链为事实快照 → 统一几何 → 传输资产 → 运行时发布。局部残差／锚增益、全局主题缓存、几何元数据和独立 `memo_local_cone_diagnostics` 在同一写事务发布。诊断记录签名、邻居数、选中原 Tag ID、活跃系数数、迭代数及 KKT／能量误差，不默认保存全维残差向量。传输依赖事实与派生几何；查询只使用已发布快照。实现见 [`memo_artifact_builder.rs`](../rust-vexus-lite/src/memo_artifact_builder.rs)。

冷加载校验就绪状态、格式身份、依赖版本、解压上限、校验和及 CSR 结构。共享资产按签名缓存；相同签名发布保持幂等，不制造新代际。观测读取还校验运行时代际和数据库代际，禁止混用旧向量池与新事实行。

## 4. 查询观测、残差金字塔与种子

### 4.1 查询与 EPA

输入向量由调用方构造，不保证是全部历史直接拼接后的 embedding。查询原文用于轻量字面覆盖，不参与查询河网形态的文本分类。

EPA 在中心化查询 \(x=q-\mu\) 上读取前缀主题面。设主题面数量为 \(m\)、向量维数为 \(d\)，则：

\[
r_Q=\frac{\sum_{k=1}^{m}\langle x,b_k\rangle^2}{\|x\|^2},
\qquad
b_{\mathrm{iso}}=
\frac{m/d+\sum_{k=1}^{m}\langle\mu,b_k\rangle^2}{1+\|\mu\|^2}
\]

默认域内门控为 \(\operatorname{clip}_{[0,1]}((r_Q-b_{\mathrm{iso}})/(c_m-b_{\mathrm{iso}}))\)；分母不足时取零。逻辑深度为 \((1-H_Q)g_Q\)。熵只在语义前缀内计算，尾部主题面不能抬高前缀解释率。随机背景是校准参考，不是域外概率或另一张传播图。实现见 [`analyze_epa_with_mode()`](../rust-vexus-lite/src/memo_pipeline.rs:306)。

### 4.2 图内残差分解

每层在当前残差上通过双曲 Tag 场检索既定 Top-K 标签池，先按 CSR 节点索引过滤图外标签，再读取权威向量。图内无出边节点仍有资格；过滤不扩大候选池或补位。

生产使用 [双曲 Tag 配置](../rust-vexus-lite/src/warped_tag_field.rs:25)：软化系数 0.15、均值减除 0.7、喉部 1.5、角尺度 2.0、自适应罗盘，半径范围 0.35–0.65。设 EPA 域内门控为 \(g\)、熵为 \(H\)、逻辑深度为 \(D\)，L0 径向位置为 \(p_0=0.55g(1-H)+0.30D\)。对于后续层：

\[
\rho_\ell=\operatorname{clip}_{[0,1]}\frac{\|r_\ell\|^2}{\|q\|^2},\qquad
p_\ell=p_0+0.75(1-p_0)(1-\rho_\ell^{0.35}),
\]
\[
r_\ell^{\mathrm{route}}=0.35+0.30p_\ell.
\]

EPA 缺失或选择层级策略时，位置改用 \(\operatorname{clip}_{[0,1]}(0.25+0.25\ell)\)。每层 Tag 精排上限为 64；半径影响标签候选来源，NNLS 仍分解原始 Tag 单位列。实现见 [残差半径](../rust-vexus-lite/src/warped_tag_field.rs:48)和 [金字塔检索](../rust-vexus-lite/src/memo_pipeline.rs:804)。

令层输入为 \(r_\ell\)、单位原 Tag 字典为 \(A_\ell\)：

\[
x_\ell^\star=\arg\min_{x\ge0}\|r_\ell-A_\ell x\|^2,\qquad
r_{\ell+1}=r_\ell-A_\ell x_\ell^\star.
\]
\[
e_\ell=\frac{[\|r_\ell\|^2-\|r_{\ell+1}\|^2]_+}{\|q\|^2},
\qquad a_{\ell,t}=\frac{x_{\ell,t}^\star}{\|r_\ell\|}.
\]

贡献是单位 Tag 的相对重构幅度，不是独立正交能量、概率或上下位关系。求解采用原空间主动集／SVD、FP64 累积和 KKT 检查；在线入口最多 128 列，输入／输出向量保持 FP32 接口。

默认边际解释能量低于 0.03 的层不接受，最多三层，残差能量比例低于 0.1 时结束。拒绝层不发布标签和剥离结果，最终残差来自最后已接受层。实现见 [`analyze_pyramid_with_pool()`](../rust-vexus-lite/src/memo_pipeline.rs)。

### 4.3 字面焦点、别名与贡献门控

字面覆盖使用标签词元集合被查询覆盖的比例：ASCII 取小写完整字母数字词元，CJK 连续片段取相邻双字，单字片段保留单字。覆盖至少 0.5 为字面支持；它不是通用实体识别或语义同一证明。

普通非核心标签贡献门槛默认为同层最大贡献的 10% 与绝对 0.05 的较大值，且要求正相关。非显式核心标签低于该门槛、词元为同层活跃正相关主概念的真子集、且二者余弦小于 0.90 时，跳过字面／别名救援；显式核心保留权威，高度共线标签不适用此遮蔽。其余字面标签可豁免低贡献过滤。同层赞助者须自身达到贡献门槛且正相关，与受助者余弦至少 0.80；受助者残差相似度至少 0.20。借用幅度按对齐与紧密度校准，低贡献别名不递归赞助。

首标签贡献平方大于 0.85 时，最多两个共线隐式冗余标签可借用有界幅度：自身贡献小于 1e-6、残差相似度至少 0.75、与首项余弦至少 0.90；总借用不超过首项贡献的 0.3。不修改 NNLS 原始贡献、解释能量和残差，也不升级显式身份。

已接受层的强贡献标签减轻层衰减，但不因该机制超过未衰减权重。字面标签免语言误罚及层衰减；非核心字面标签使用 1.6 倍幅度校准，种子权重上限为 1。核心标签保留核心增益契约，不套用该非核心上限。

存在当前图内有效显式种子时，隐式种子统一等比例缩放，使其最大权重不超过显式最大权重的 0.35 倍，并保持隐式权重比例；图外显式标签不参与压制基准，无有效显式焦点则不做相对压制。显式核心、字面种子与隐式种子分别保留来源身份。实现见 [`gate_tags_for_graph()`](../rust-vexus-lite/src/memo_pipeline.rs:888) 与 [`scale_implicit_seeds()`](../rust-vexus-lite/src/memo_pipeline.rs:874)。

### 4.4 路由残差与最终尾部

动态虫洞开启时，每个已接受层保存投影前残差。至少接受一层，且最后已接受层留下的尾残差能量有限、大于 1e-12、占原始查询能量至少 0.02 时，追加该尾残差作为最后一个路由输入。

接受 \(L\) 层时，追加条件满足则有 \(L+1\) 个路由残差；否则为 \(L\) 个。动态虫洞关闭时不保存路由残差。尾残差只供选边，不增加标签层或种子层、不改写已解释能量；拒绝后续层时不使用被拒层的剥离结果。

诊断字段 [`routingResidualCount`](../rust-vexus-lite/src/memo_pipeline.rs:1879) 与 [`routingTailAppended`](../rust-vexus-lite/src/memo_pipeline.rs:1880) 区分路由输入数量和尾部追加状态。尾部存在仅解除更深层支持资格限制，不保证发生动态虫洞注入。

## 5. 有界传播与请求级动态虫洞

### 5.1 状态、电流与累计观测

传播状态包含前驱、当前节点、原始活动能量、动量、跳数和来源层。沿真实边的注入为：

\[
f_{ij}^{(h)}=e_i^{(h)}P_{ij}d_{ij}\rho_{ij}
\]

普通／虫洞衰减默认分别为 0.25／0.70；立即回流乘 0.15。默认发火阈值 0.10、最低注入电流 0.01、安全跳数 4、每状态邻居名额 20、传播状态配置上限 2000。普通边消耗动量，虫洞边不消耗动量，均保留安全边界。

有限时域权重 \(a_h=\gamma^h/\sum_{r=0}^{H}\gamma^r\)，默认 \(\gamma=0.6\)。累计节点势为 \(E_i=\sum_ha_he_i^{(h)}\)。零跳 FIR 权重只影响累计观测，首跳电流使用原始种子活动能量；不能用面板累计能量直接代替首跳输入。

仅正 ID、有限且正能量、当前图内的种子被接收；同 ID 合并，孤立图内节点仍保留零跳观测。输入数、接收数和最终观察到的零跳数是不同口径。请求源场由最终输出节点累计能量归一化得到，包含实际到达的节点。实现见 [`sense_with_context()`](../rust-vexus-lite/src/memo_sensing.rs:385)。

河网边记录已通过注入门槛的实际电流事件；边流记录与目标状态裁剪、后继发火不是同一口径。可选逐跳转移记录还检查目标状态保留情况，并有独立硬上限，不能据边流计数声称完整后继路径已成立。

### 5.2 残差共鸣选边

来源层为 \(L\) 的状态只消费层索引大于 \(L\) 的残差：

\[
R(j\mid L)=\max_{\ell>L}[\,\cos(r_\ell,v_j)\,]_+,
\qquad
D_{ij}=P_{ij}R(j\mid L)^4
\]

目标向量来自 SQLite 权威原始向量池。动态候选只来自源的真实正权重 CSR 出边，须通过共鸣阈值与预估电流门槛。按动态分数降序、导电率降序、目标 ID 升序排序；默认在原有邻居名额内最多保留两个动态席位，静态顺序补齐剩余席位。

动态边使用虫洞衰减，但共鸣不直接乘进电流、不提供电流保底或额外能量，也不创建关系、改写传输图。默认共鸣阈值 0.2，请求级不同目标评估预算 4096。关闭开关、席位为零或目标预算为零时使用静态选边；阈值合法性仍校验。

目标按图内索引确定性截断，跨跳复用相似度与缺失向量结果；预算耗尽的未评估目标不参与动态共鸣，静态路径仍可使用。多路径合并保留最早来源层，不是完整多源血缘追踪。实现见 [`DynamicWormholeContext`](../rust-vexus-lite/src/memo_sensing.rs:281) 与 [`sense_with_context()`](../rust-vexus-lite/src/memo_sensing.rs:478)。

## 6. 双场、投影预算与向量复用

### 6.1 标量双场

同一查询源 \(S\) 与传输算子 \(T\) 求解：

\[
u_L=(1-\alpha_L)S+\alpha_LT(u_L),\qquad
u_T=(1-\alpha_T)S+\alpha_TT(u_T)
\]

默认 \(\alpha_L=0.15,\alpha_T=0.55\)。收敛条件下，\(u_\alpha=(1-\alpha)(I-\alpha T)^{-1}S\)。两场共享 CSR 遍历调度，各自判断收敛；默认迭代上限 80、容差 1e-9。有效域按累计场质量选取，默认局部 0.8、迁移 0.9。实现见 [`solve_dual_fields_with_pool()`](../rust-vexus-lite/src/memo_pipeline.rs:1721)。

候选读出使用各场除以本场最大值后的标量势，不把不同查询的原始总质量当作同一量纲。标量保留与高维投影预算独立：过滤低于本场最大质量 1e-12 倍的数值尾流，并保留有效域并集与河网必需节点。

### 6.2 种子流域投影

全部活跃河网节点作为两场共享内圈。零跳种子及记录来源提供根线索，真实观测边构造确定性多源森林；无法归属的核心节点作为独立内圈保留，不虚构连接。

每个“流域 × 场”沿真实正权重边，以负对数传输率为距离独立扩展。每通道先轮转获得最多两个外圈机会，再按重要性和近期质量收益、已用机会分配，每批最多四个。新节点须有本场已接纳的真实前驱，不能跳过桥接点选远端高峰。

默认两场投影集合的去重并集上限 \(K=256\)，核心计入预算；核心超过正预算显式失败，不静默裁剪或超额。预算为零只取消节点数量上限，不取消质量目标或工作限额。全局处理／发现状态上限为 8192，扫描边上限为 65536。

各场只用自己的支持集与质量投影，共享读取不等于共享资格。观测核心外节点采用温和入度折减 \(1/(1+\sqrt{\mathrm{inbound}/\mathrm{maxInbound}})\)，核心增益为 1。缺失向量不全图补位；支持集连通不保证有效向量子集连通。实现见 [`seed_basins()`](../rust-vexus-lite/src/memo_projection.rs:27)、[`grow()`](../rust-vexus-lite/src/memo_projection.rs:168) 与 [`project_basin_fields()`](../rust-vexus-lite/src/memo_pipeline.rs:1629)。

### 6.3 请求级复用

金字塔、动态虫洞、融合、双场和候选读出共享原始 FP32 标签向量载荷，只批量补读差集，每批最多 128 个标签 ID。候选正文向量和文件标签关系也批量读取，不新增逐候选 SQL。

投影预算不是整个请求向量池上限；动态目标和候选阶段仍会读取其他向量。4096 个 3072 维 FP32 向量仅载荷约 48 MiB，不能将数量预算解释为固定耗时、总内存上限或无损召回保证。

请求观测通过 [`MemoRuntime`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:554) 的句柄复用；全部内部消费者完成后释放，TTL 仅作兜底。释放句柄不清除常驻图，已取得共享引用的消费者可完成计算，最后引用释放后回收载荷。

## 7. 候选边界与路径证据

### 7.1 共同候选与权限

拓扑读出处理共同候选边界内的候选，不从全库凭空补回池外正确记忆。内部候选超集消费原始查询、增强查询、局部／迁移场、BM25、时间和锚来源，记录候选身份及来源；默认超集上限 300。

权限过滤先于候选归一化和统计，显式空权限集合表示无权限。候选标签顺序来自稳定文件序位，不是经正文验证的叙事或因果顺序。实现见 [`select_superset()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1362) 与 [`run_native_with_connection()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2769)。

### 7.2 Span-1／Span-2 路径

候选曲线 \(\Gamma_c=(t_1,\ldots,t_n)\) 的每个起点在相邻与跨一个标签的两种段中择优；Span-2 乘 0.7。相同端点对（包括反向重复表示）共用一次证据容量。总机会数仍为 \(n-1\)，不能因多枚举窗口刷倍数。

每场段势为两端标量势的几何平均。只有两端同在至少一个场的有效域内，且端点间存在真实正权重全局边，才有路径支持。路径并不虚构跨标签的中间传播链。

段质量为混合场势 × 方向平方根 × 连续性平方根 × 活跃支持增益 × 跨段折扣。其中：

- 场势按路径权重混合，默认局部／迁移 0.6／0.4。
- 连续性平均组合标签语义连续性与场连续性。
- 仅全局连接的活跃支持增益为 0.5；本次归一化活跃流 \(f\) 使其变为 \(0.5+0.5\sqrt f\)。
- 有活跃流时按活跃前／反向比例计方向，否则按全局前／反向导电率比例计方向，并保留方向下限。

段质量按有限机会平均，再以支持覆盖与标签到正文闭合收束：

\[
Q_c=Q_{\mathrm{core}}\left(0.5+0.25C_{\mathrm{path}}+0.25C_{\mathrm{tag}}\right)
\]

单标签没有关系段，但保留半幅最强场势的节点退化读出，不声称其具有路径关系证据。实现见 [`evaluate_path()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1516)。

## 8. 一对一拓扑对齐与支流置信度

### 8.1 节点绑定与质量信用

查询节点与候选标签首先按 ID 精确对应，其次计算权威向量余弦。语义匹配默认入口阈值 0.48。设余弦为 \(s\)、正文闭合为 \(h_t\)，质量为：

\[
a(r,t)=\sqrt{\nu(s)h_t}\,w(s),
\quad
\nu(s)=
\begin{cases}1,&\text{精确}\\
\operatorname{clip}_{[0,1]}((s-\tau)/(1-\tau)),&\text{语义}
\end{cases}
\]

语义余弦低于 0.65 时额外乘 \(w(s)=(s/0.65)^2\)，否则为 1。候选与查询双侧容量均为一；确定性贪心先精确，再按查询节点权重乘匹配质量降序，最后按 ID 和位置稳定裁决，重复标签 ID 不能多次响应。

节点覆盖按能量加权质量信用计算，不是匹配即记满票。候选无支持有效长度为标签数减已接受质量之和，其密度校准为：

\[
d_c=\frac{1}{1+[\mathrm{unsupported}-6]_+/16}
\]

密度只折减节点覆盖信用，不直接按标签总数硬罚；充分支持的丰富标注不因长度受罚。最强匹配质量指已接受对齐的质量，包含闭合和弱匹配折减，不是原始余弦。实现见 [`evaluate_topology()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1737)。

### 8.2 边对应与连续图分

查询实际河网边按最低流量和数量上限读取，默认阈值 0.015、上限 96。两端均有不同候选标签对应时，比较归一化 hop 距离、候选序位距离、方向及来源独立性。来源独立性有 0.15 下限，不将唯一来源直接归零。边覆盖按端点质量折算。

节点图分为节点对齐与平均闭合乘积的平方根。边图分组合节点对齐、相对距离、方向、边拓扑和 Motif；Motif 当前复用边拓扑值，不是独立模体或图同构匹配器。三个图头为：

\[
G_A=0.75G_N+0.25G_E,\quad
G_P=0.25G_N+0.75G_E,\quad
G_N^{\mathrm{narr}}=0.15G_N+0.85G_E
\]

最终图分 \(g_c=p_AG_A+p_PG_P+p_NG_N^{\mathrm{narr}}\)。三种形态概率只由查询河网的深度、集中度、浅层比例、方向流、链性、分叉、汇合与持续性统计产生；稳定 Softmax 后按样本量与观测完整度向均匀先验收缩，不读取查询语言关键词或候选。

图分采用完整连续概率混合；支流覆盖和角色判定使用最大概率对应的主导模式。实现见 [`compute_query_morphology()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2239)。

### 8.3 支流覆盖与精度落地

设原始全河网节点／边覆盖为 \(C_N^{raw},C_E^{raw}\)，支流覆盖为：

\[
C_N=\operatorname{clip}_{[0,1]}(C_N^{raw}/0.35),\qquad
C_E=\operatorname{clip}_{[0,1]}(C_E^{raw}/0.20)
\]

\[
C_b=
\begin{cases}
C_N,&\text{原子主导模式}\\
0.70C_E+0.30C_N,&\text{非原子且匹配边数大于零}\\
0.35C_N,&\text{非原子且无匹配边}
\end{cases}
\]

\[
\boxed{\chi_b=\sqrt{C_b\,\overline h\,a_{\mathrm{node}}}}
\]

全网覆盖可靠性保留原始语义，供诊断及角色解释，不进入图奖励乘法链。支流置信度不是候选对全河网的完整复现保证。

完全没有精确节点命中且最强已接受匹配质量小于 0.65 时，精度因子 \(\pi_c=0.65\)，否则为 1。有精确命中或质量至少 0.65 的强软匹配不触发该折减。实现见 [`branch_coverage()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1694)、[`branch_confidence()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1710) 与 [`precision_grounding()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1702)。

## 9. 场共振与查询基础分

原始查询余弦裁剪值为 \(q_c\)。查询种差方向来自已接受层内满足低贡献真子集遮蔽条件、非显式核心且与查询余弦至少 0.65 的父方向。按 Tag ID 去重，FP64 两遍正交化；相对方向范数不大于 \(10^{-5}\) 则不入基。从单位查询剥离这些基方向，剩余范数小于 \(10^{-4}\) 时不启用；否则单位化得到 \(q_\perp\)，置信度 \(d=\operatorname{clip}_{[0,1]}(\|\tilde q_\perp\|/0.1)\)。

**属门：先判断候选是否仍在被剥离的父概念范围内。** 对每个已剥离父标签 \(p\)，取它与当前 Chunk 正文的余弦，以及它与候选文件各标签的余弦，两者取最大值 \(a_p\)。精确命中父标签 ID 时按 1 计；没有标签时只看正文。多个父概念必须同时成立，基础门值取最弱父轴：

\[
g_0(c)=\min_p \operatorname{clip}_{[0,1]}\!\left(\frac{a_p(c)-0.50}{0.22}\right).
\]

**单父轴的整句焦点一跳。** 默认 \(g=g_0\)。只有一个父轴且种差置信度为正时，还可用本次传播的精确目标作为归属证据：

1. L0 标签名与非空查询整句去首尾空白、转小写后相等，相似度和原始 NNLS 贡献均为正。多项符合时取贡献最高者，同分取较小 ID。别名赞助或字面权重保底不能代替原始贡献。
2. 该焦点须实际作为零跳核心或字面种子获得正能量。目标须出现在第一跳，焦点到目标是本次观测到的普通正流边，非虫洞、非即时回流，通过活跃流量门槛且在 CSR 中有正向正权边。
3. 若候选文件的标签精确包含该目标 ID，取 \(g=1\)。例如“华为汽车”激活“尊界V800”时，具体车型标签可以证明归属，不要求重复标注“华为”。这是文件级证据，不是本体从属断言；同一文件的各 Chunk 仍分别计算正文种差分。

校准查询分为：

\[
m=0.5d,\qquad
\hat q_c=(1-m)q_c+m\,g(c)\,\operatorname{clip}_{[0,1]}\!\bigl(\cos(q_\perp,v_c)\bigr).
\]

门值只乘种差项，不改变混合系数：证据齐全但门值为零时，查询分为 \((1-m)q_c\)，并非完整原分。无有效种差或请求向量池缺少任一必要父向量时则令 \(m=0\)，保留原查询分。属门复用请求向量池、余弦缓存和已观测边，不新增 SQL，不改双场、候选池或拓扑奖励预算。该一跳规则与第 12.3 节的传输奖励分别计算。见[焦点选择](../rust-vexus-lite/src/memo_pipeline.rs:2447)、[一跳目标与父轴证据](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1767)和[种差混合](../rust-vexus-lite/src/rivermemo_topology_v3.rs:1837)。

仅有限且非零的场投影向量参与场余弦混合，缺失场不占分母。默认查询／局部／迁移权重 0.7／0.2／0.1；有效场权重占比为 \(\lambda\)，双场加权余弦为 \(F_c\)。

### 9.1 精确场势与强语义继承

候选标签按 ID 去重。每个场优先使用标签自身 ID 的标量势与有效域资格；该场没有对应势时，选择与标签余弦最高且严格大于 0.82 的活跃河网节点，按下式继承：

\[
d(s)=0.75\operatorname{clip}_{[0,1]}\frac{s-0.82}{0.18}.
\]

继承场势为来源场势乘 \(d(s)\)，来源处于该场有效域时，域接触也记为 \(d(s)\)。局部场和迁移场分别判断精确存在性；已有精确势保持不变。该计算复用请求内原始向量池与余弦缓存。

每场覆盖为域接触总量除以去重标签数，势能为标签归一化场势的平均值：

\[
C=\min(1,\mathrm{coverage}/0.5),\quad
V=\min(1,\mathrm{potential}/0.02)
\]

\[
s_f=\max\left(\sqrt{CV},\ 0.1\sqrt{\frac{\mathrm{potential}}{\mathrm{potential}+0.02}}\right),
\qquad s_c=I_c\max(s_L,s_T)
\]

### 9.2 Hop-0 意图覆盖

从查询河网提取 Hop-0 种子，同 ID 保留最大正能量。设总能量为 \(E\)、最大单种子能量为 \(E_{\max}\)。候选标签与种子先按精确 ID 对齐，再接受余弦至少 0.72 的语义接触，按相似度及 ID 稳定选择；每个种子和候选标签各认领一次，得到命中能量 \(E_{\mathrm{hit}}\)：

\[
I_c=\operatorname{clip}_{[0.35,1]}
\sqrt{\frac{E_{\mathrm{hit}}}{\max(0.55E,E_{\max})}}.
\]

无有效种子时 \(I_c=1\)。单种子命中可获得完整支持；多意图查询只覆盖弱支线时按命中能量折减。该因子仅调制标量场支持。

### 9.3 场共振与基础分

\[
\boxed{
R_c=\min\left(\min(0.03,\lambda[F_c-\hat q_c]_+)\,s_c,\ 1-\hat q_c\right),
\qquad B(c)=\hat q_c+R_c
}
\]

共振先封顶再乘包含意图覆盖的标量支持；无有效场时为零，基础分保留 \(\hat q_c\)。场支持由当前观测和候选标签计算，不依赖候选池均值。实现见 [意图覆盖](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2034)、[标量观测](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2072)和 [场共振](../rust-vexus-lite/src/rivermemo_topology_v3.rs)。

## 10. Ω 与拓扑共享预算

Ω 读取查询河网与金字塔已解释能量比例，不读取候选。令 \(e_Q\) 为裁剪到 [0, 1] 的已解释比例，未提供时取 1。设零跳种子数为 \(N_s\)、实际边数为 \(M\)、到达节点数为 \(N_r\)、涌现数为 \(N_e=\max(0,N_r-N_s)\)：

\[
\Omega_E=\operatorname{clip}_{[0,1]}\frac{M}{\kappa_E\max(1,N_s)},\qquad
\Omega_N=\operatorname{clip}_{[0,1]}\frac{N_e}{\kappa_N\max(1,N_s)}
\]

正流归一化熵为 \(\Omega_F\)，无正流为 0，单条正流为 0.5。最终：

\[
\Omega=\operatorname{clip}_{[0,1]}
\left[\sqrt[3]{\max(\Omega_E,\varepsilon)\max(\Omega_N,\varepsilon)\max(\Omega_F,\varepsilon)}\,\chi_{\mathrm{obs}}\,e_Q\right]
\]

默认 \(\kappa_E=0.5,\kappa_N=0.3,\varepsilon=0.02\)；完整／不完整观测因子分别为 1／0.5。几何平均有 epsilon 底值，空图不应被描述为 Ω 必然严格等于零；没有候选结构证据时图奖励仍为零。工况边界为 0.12、0.45，分别解释为坍缩、稀疏、稠密，不代表主题正确率。实现见 [`compute_omega()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2483)。

设路径质量为 \(Q_c\)，标量覆盖／势能组合为 \(U_c\)：

\[
U_c=\operatorname{clip}_{[0,1]}(0.35c_L+0.25c_T+0.25v_L+0.15v_T)
\]

\[
P(c)=\min\left(C_T,\ C_T\operatorname{clip}_{[0,1]}(0.625Q_c+0.375U_c)
\sqrt{\operatorname{clip}_{[0,1]}(Q_c/\tau_P)\,q_c}\right)\Omega^\gamma
\]

默认 \(\tau_P=0.15\)。图方向支持 \(\delta_c\) 在有匹配边时为 \(0.25+0.75\,\mathrm{directionScore}\)，无边时为 0.25。图请求与最终奖励为：

\[
G_{\mathrm{self}}=\min(C_T,C_Tg_c\chi_b\delta_c\pi_c),
\qquad g=\min(G_{\mathrm{self}}\Omega^\gamma,[C_T-P(c)]_+).
\]

默认 \(\gamma=1\)。路径先经 Ω 门控并占用预算，候选图请求同样经 Ω 门控；再按第 1.2 节与传输请求互补合并，最终满足 \(P+G\le C_T\)。全网可靠性不重复乘入支流置信度。

## 11. 直接锚与解释角色

### 11.1 接触与幅度

正常锚资格来自零跳核心、字面和普通种子。隐式种子按最大源质量的 20% 过滤，显式核心／字面种子豁免；无可用来源时可从源场构造兼容锚，但受回退可靠性上限限制。

接触采用精确优先、双侧一对一确定性贪心，最多三个独立接触。语义阈值至少 0.88，以超出阈值的比例连续计权并乘语义折扣，默认 0.7。

存在有效显式源时，源质量以显式最大质量归一化；否则用所有可用源的最大质量。候选没有命中显式源不会改变该分母。各接触贡献组合归一化质量、全局入度特异性、正文闭合、全局稀有度代理和匹配权重；隐式接触永久乘 0.35，与是否存在显式焦点无关。

全局入度特异性和稀有度代理不使用候选池频率。接触通过 noisy-OR 聚合 \(a_c=1-\prod_s(1-a_{sc})\)。可靠性为平均闭合平方根，有精确接触时不按种子数量打折，纯语义接触另乘语义折扣。

回退锚可靠性默认不超过 0.5。纯隐式候选可靠性不超过 0.35，锚强度不超过 0.035。这些是观测值，不是奖励。实现见 [`anchor_contacts()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2265) 与 [`compute_anchors()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2302)。

### 11.2 锚观测与排序的边界

锚接触可解释角色；锚来源仍可参与第 7.1 节的候选选择。精排不将锚强度换算成分数：即使调用方显式传入非零上限，结果中的 `anchorBonus` 也恒为 0。参数 `anchorReward` 返回 `retired-zero-unified-field`；`anchorBonusCap`、`anchorActivationFloor`、`anchorSaturation` 可解析以保持兼容，均列入 `retiredControls`。

原子主导模式解释为原子概念。非原子候选标为 `direct_answer`，必须同时满足显式精确接触和观测正文闭合至少 0.55；隐式精确接触加显式语义接触不等价于显式精确身份。结构角色受原始覆盖可靠性与 Ω 解释门槛约束，但角色不改变奖励公式。实现见 [`assign_v3_scores()`](../rust-vexus-lite/src/rivermemo_topology_v3.rs:2748)。

## 12. 全局见证与连续传输读出

### 12.1 虫洞路线与联合见证

路线来自当前请求真实观测到的虫洞边：非自环、非即时回流、正原始电流、端点 ID 有效且不同；同向关系必须存在于已发布 CSR，目标权威向量有限且非零。动态路线不要求持久化虫洞标记。相同端点对保留最大电流，按电流、端点 ID 稳定排列并受河网边数上限约束。

相对流量 \(\rho_e=f_e/\max_{\mathrm{原始全部观测边}}[f]_+\)，不因门控或候选池重新归一化。

全局见证读取同一事务中的文件 Tag 事实，不受候选范围限制，但不扩大返回权限或补召回。两见证文件必须同时包含路线两端，校验和非空且不同，并共享排除路线两端及显式焦点的第三标签。

多焦点要求至少一见证文件包含另一个零跳核心／字面焦点。仅一个显式焦点且该焦点为路线来源时，以下任一条件可准入：

- 查询具有非空遮蔽 ID 和正种差置信度。
- 来源具有已知有效全局入度统计，特异性 \(1-\sqrt{\operatorname{clip}_{[0,1]}(\mathrm{inbound}/\mathrm{maxInbound})}\ge0.65\)。

单焦点准入仍须满足两文件、校验和及第三标签条件；缺失统计不推断为稀有。每路线最多 128 文件，每文件最多 128 标签，读取第 129 项探测超限，超限不放行。读取错误明确返回错误。

### 12.2 候选虫洞证据

完整观测及正 Ω 下，来源须为零跳核心／字面焦点，\(\rho_e\ge0.5\)。目标与候选正文正相关；候选至少一个标签精确对应目标，或余弦严格超过默认 0.48 的语义阈值，并且该标签到正文正相关。

\[
e_{\mathrm{XW}}(c)=\max_{\text{合格路线 }e}
\rho_e\,\operatorname{clip}_{[0,1]}\cos(v_{\mathrm{target}},v_c)\,\Omega^\gamma.
\]

匹配标签按目标相似度择强、同分按 ID；正文闭合在此作为正值资格，不再额外连乘。文件级目标地址或目标—正文相似单独不能产生该奖励。见证关联和不同校验和不证明统计独立或因果。

### 12.3 普通 Hop-1 代理证据

完整观测下，普通代理边须非虫洞、非即时回流、有正观测流量，来源为零跳显式核心／字面种子，目标在观测中 hop 为 1。同向 CSR 导电率 \(P_{ij}>0\)，且不低于源行最强导电率的一半。候选须精确包含目标 Tag。

\[
e_{\mathrm{Hop1}}(c)=\max_{\text{合格边 }i\to j}
\frac{P_{ij}}{\sum_kP_{ik}}\,
[\cos(v_j,v_c)]_+\,\Omega^\gamma.
\]

普通代理证据不依赖虫洞全局见证，不新增图边。它与虫洞证据取最大值作为传输请求，随后与候选图奖励按第 1.2 节互补，仍消耗同一剩余拓扑预算。

实现见 [`rivermemo_wormhole.rs`](../rust-vexus-lite/src/rivermemo_wormhole.rs)。

## 13. 原生执行、结果与诊断

### 13.1 执行链

1. 读取配置、查询向量／原文及已发布资产。
2. EPA → 双曲 Tag 按残差能量选池 → 图内原 Tag NNLS 金字塔 → 字面／贡献／核心门控 → 种差校准与残差上下文。
3. 有界真实边 Sense → 请求河网 → 增强查询、标量双场及共享预算投影 → 保存同代双曲观测。
4. 按权限与候选计划同步实时 Chunk，执行全局双曲 ANN、合并、展开、去重和候选收缩。
5. 准备全局见证；批量加载候选曲线、补读向量差集，并行计算路径、拓扑、强语义场继承、意图覆盖及锚接触。
6. 按属门混合查询与种差正文分，计入有界场共振；按查询形态与 Ω 计算路径和图奖励，标注解释角色。
7. 将普通 Hop-1 与合格虫洞证据并入共享预算；按连续最终分稳定排序并截取 Top-K。
8. 返回结果，全部消费者完成后释放观测句柄。

普通 V5 准备一份双曲观测；LightMemo AB 准备旧余弦与双曲两份观测，分别读出各自候选池。并行 Rerank+ 同时准备观测与双曲候选，外部 HTTP 和 RiverMemo 读出分别排序后以 RRF 融合。

观测初始化不可用时执行双曲 ANN，并将返回链路标记为双曲 ANN；损坏资产、非法向量和存储错误返回错误。请求向量差集读取校验数据库代际，调用结束按所有权释放观测句柄。

### 13.3 诊断

- 检索后端：[联合 ANN 诊断](../rust-vexus-lite/src/knowledge_runtime.rs)记录实际候选后端、日记本范围与逐次双曲查询统计。
- 双曲 Tag：[路由诊断](../rust-vexus-lite/src/memo_pipeline.rs)记录实际模式、场来源、初始化回退、各层半径、输入残差能量比、候选 ID 和访问／原件读取量。
- 双曲 Chunk：[场诊断](../rust-vexus-lite/src/warped_chunks.rs)记录径向规则、训练事实、实时成员、向量增量、范围规模、图导航／精确扫描、预算和耗时。
- 旧轨驻留：[全局索引统计](../rust-vexus-lite/src/knowledge_runtime.rs)及 [LightMemo 诊断](../rust-vexus-lite/src/light_memo.rs)记录旧 TDB 候选载荷是否驻留、实际检索链路及降级状态。
- 几何 `memo_local_cone_diagnostics`：资产签名、候选数、选中列 ID、迭代数、活跃系数数、残差能量比、KKT 及能量闭合误差。
- 查询级 `parameters.queryCalibration`：`supersededIds` 为已剥离父轴，`differentiaConfidence` 决定混合系数（上限 0.5），`explainedRatio` 校准 Ω。`exactFocusId` 标识整句焦点（未识别时为空），`genusGateMode` 标识实际属门规则。
- 候选级 `topologyV3`：对比 `genusGateBeforeFocus` 与 `genusGate` 可看出一跳证据是否改变门值；`genusExactFocusTargetId` 给出命中的目标。`genusEvidence` 记录限制门值的父轴、正文余弦、最佳标签及其余弦和最终亲和度。父向量缺失时看 `genusMissingParentId`；此时门值为空，不是零。
- 金字塔／传播：已接受层、路由残差数量及尾残差追加、种子缺失／无效／去重、动态候选／入选／实际注入及预算。
- 双场：标量收敛、有效域、支持集、向量读取、质量覆盖、预算与工作截断。
- 全局见证：门控前／后路线、见证文件、第三标签、单焦点准入、特异性与超限状态。
- 候选详细跟踪：支流覆盖／置信度、精度、场支持、意图覆盖因子、命中与总种子能量、软场接触数量、种差余弦，以及传输读出的代理边、虫洞证据、原图奖励、传输请求和最终图奖励。
- `requestedGraphBonus` 表示已乘 Ω、尚未扣除路径预算及合并传输证据的原图请求，不等于最终 `graphBonus`。

兼容配置中的同伴异常、条件创新、批级锚异常与前沿控制不参与奖励，以原生 `retiredControls` 为准。详细跟踪按请求启用，不导出完整河网或全部绑定表。

## 15. 总结

**全局 Chunk 双曲候选 + 双曲 Tag 池 → 原 Tag NNLS、种子与种差方向 → 有界传播与双场 → 按候选归属校准种差分、计入场共振 → 加上共享预算内的路径、图与传输奖励 → 按连续最终分排序。** 锚接触用于解释结果，不另加分。

这条 V5 生产链在原生侧完成候选、观测和读出：SQL 同步实时事实，双曲场复用训练几何，查询复用向量池，结果保留实际链路与分数账目。
