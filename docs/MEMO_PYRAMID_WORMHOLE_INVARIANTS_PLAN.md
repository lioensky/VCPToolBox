## 已核实与纠偏
- orthogonal_projection 是 memo_pipeline 私有函数，唯一生产调用是金字塔。
- 当前算法是双侧子空间投影，绝对系数表示正交增量幅值；不能仅凭非负传播能量断言数学实现错误。
- 丢弃负向 Gram-Schmidt 轴并不等于原始 Tag 非负锥投影，且依赖候选顺序。禁止以 conical 名称伪装该启发式。
- NativeArtifact::prepared 按正权重降序、目标 Tag ID 升序排序；生产扫描中的 break 有契约依据。
- search_sql 通过 SQL 原向量 source 委托检索核；精排实现和分数精度继续核实，不将调用包装层当完整证明。
- 各层握手均序列化到 PyramidOutput；综合特征仅消费首层，不等于深层输出可删除。
- 握手差向量在残差趋零时趋向 -tag，不必趋向同一方向。此前“必然一致趋于1”的说法错误。
- 虫洞预算按节点下标截断有结构性偏置；通量优先也可能压制弱边跨域，需要预算反例和真实评分验证。

## 实施顺序
1. 核实构建、检索核、归因和下游输出契约。
2. 先写数学反例与不变量，确定投影/种子归因修复的准确契约；必要的决策分歧向主人确认。
3. 等价优化单独提交：握手有限方向缓存、词法 query tokens 复用、延迟名称加载（保留层输出）。
4. 行为变更单独提交：经验证的方向归因与虫洞候选预算策略，不偷偷重标阈值。
5. 全套相关 Rust/Node 回归、release 编译和加载冒烟，记录产物路径与 SHA256。

## 不变量矩阵
- 投影：有限值、重构闭合、能量不增、近共线秩阈值、重复/零向量、尺度变化。
- 有向归因：反平行与共享主轴/反向次轴反例；候选顺序敏感性明确记录，不混淆正交轴与原 Tag 系数。
- 握手：等价优化逐值对照、零距离、单 Tag、前5 pairwise及全体平均方向保留。
- 词法：ASCII边界/CJK双字/标点行为和种子权重不变。
- 虫洞：预算上限、确定性、目标去重、缓存负结果、返回流和最小注入门控；低ID弱边与高ID强边、强边与弱边高共振竞争。
- 关闭动态虫洞时路由不变；残差层级及尾残差只作路由证据不变。
- 保留现有序列化字段及 ABI。
