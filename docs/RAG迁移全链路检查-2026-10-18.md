## 结论

**主要原生检索数据链已贯通，但不能判定所有上层功能完整工作。**
真实临时数据库已经验证摄取、资产构建发布、日记索引恢复、RiverMemo 联合查询、
混合计划和聚合占位符正文注入。发现三个可复现的上层契约缺陷。
元思考在本轮小样本上明确降级到原生 ANN，未证明真实 Sense 构链正向成功。

本次仅新增[隔离审计测试](../tests/ragNativeChainAudit.test.js)，未修改生产实现，
未打开生产数据库及 WAL/SHM，也未修改 LightMemo、冷知识库或 EPA。

## 验证方式和边界

- 使用真实 Windows 原生模块和 Rust SQLite 存储，不 mock 数据库、RiverMemo 或查询返回。
- 实例化真实 KBM，显式指定系统临时目录。
- 禁用 OS watcher、空闲扫描和启动自动派生调度，手动执行资产构建。
- 插件手动设置最小配置和依赖；用固定四维向量替代外部 Embedding。
- 因此本轮不是完整服务启动验收，也未验证生产模型的召回质量和大库性能。
- 插件常规初始化、外部 Embedding / Rerank / AIMemo LLM、多模态和冷知识库未全链路实测。
- 所有临时库关闭后成功删除。

## 缺陷 1：原始候选与正文缓存模式混用

位置：[缓存读取](../Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js:2913)、
[原始结果返回](../Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js:3618)、
[AIMemo+ 候选消费](../Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js:2649)。

同参数先执行普通检索生成正文缓存，再请求原始结果，会直接返回字符串而非候选数组。
AIMemo+ 对结果调用数组过滤时会失败；外围捕获后可能使该日记候选丢失。

本轮真实临时库已复现返回类型为字符串。
建议原始结果模式绕过正文缓存，或缓存结构化结果并严格区分输出模式。

## 缺陷 2：默认 RiverMemo 缓存跳过本请求 Sense

位置：[默认启用 RiverMemo](../Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js:2941)、
[仅显式后缀绕过缓存](../Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js:2913)、
[混合占位符外层缓存](../Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js:2231)。

所有常规 RAG 已默认使用 RiverMemo，但 Sense 所需缓存旁路仍依赖显式后缀。
在启用元思考时，未写显式后缀的首轮收集到一个观测，第二轮缓存命中后观测为零。
这会让元思考退回 ANN，而非消费本轮 Sense。
建议按实际引擎和本轮观测需求决定是否绕过缓存，而不是检查后缀拼写。

## 缺陷 3：降级 KNN 被桥接层误报为 RiverMemo

位置：[KBM 自动降级](../KnowledgeBaseManager.js:2673)、
[桥接固定成功标记](../Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js:5740)、
[插件固定原生已排序标记](../Plugin/RAGDiaryPlugin/RAGDiaryPlugin.js:3266)。

使活动资产不可用后，KBM 正常返回带降级诊断的纯 KNN。
桥接层仍返回 RiverMemo 已使用，且即使调用方指定禁止回退也不会拒绝内部降级。
本轮真实库已复现结果对象属于 KNN，但桥接元数据宣称使用 RiverMemo。

插件同样未透传此降级诊断；本轮只对桥接误报做了直接复现。
建议统一传播实际引擎、降级原因与策略；不能将“有结果”当成 RiverMemo 正向成功。
资产失效时的 KNN 降级也没有执行完整混合计划，Time/BM25 行为不可据此保证。

## 回归结果

- 第一组：44 项，42 通过，2 失败。
  失败位于[联想发现测试](../tests/associativeDiscoveryRiverMemo.test.js)，
  夹具仍 mock 旧 JS 数据库，没有提供新原生路径 hydrate 契约。
- 扩展组：17 项，10 通过，7 失败。
  五个文件仍引用已删除的结构管理模块；另两项单轨测试缺失新原生 ANN / 文件作用域门面。
  这些失败反映回归保护网未迁移完整，不应为跑绿而恢复生产 JS SQL 连接。
- [清单兼容测试](../tests/nativeMemoManifestCompatibility.test.js)单独运行通过。
- [Runtime 注册表测试](../tests/nativeKnowledgeRuntimeRegistry.test.js)单独运行通过。
- 新增审计测试最后单独运行通过；它包含三个“确认缺陷存在”的断言，不是修复验收。

## 尚不能签署的验收

生产库副本迁移、真实 OS watcher 到 Embedding/摄取的闭环、
真实 Sense 构链正向、AIMemo LLM、外部精排、大库内存/并发吞吐、
长期负载与故障注入均未在本轮完成。
最终判断：**Rust 数据链可工作，上层缓存与降级语义仍需修复后才能称全链路闭环。**
