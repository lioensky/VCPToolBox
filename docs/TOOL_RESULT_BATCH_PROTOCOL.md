# 工具返回批次隔离协议

## 范围

工具批次是同一轮所有可见工具返回及本轮摘要的整体隔离单元，不等于单个工具结果。流式与非流式正文采用同一协议。此协议不改变工具结果原文，不提供 HTML/脚本执行安全沙箱。

## 线格式

按顺序输出以下独立文本行：

1. 启用角色拆分时，输出外层 user 开始标记：<<<[ROLE_DIVIDE_USER]>>>
2. 批次开始标记：<<<[VCP_TOOL_BATCH_START:2026-10-29T12:51:34.979Z]>>>
3. 所有可见工具结果，保留原结果框格式。
4. 本轮工具调用摘要，保留现有状态与记录 ID。
5. 批次结束标记：<<<[VCP_TOOL_BATCH_END:2026-10-29T12:51:34.979Z]>>>
6. 启用角色拆分时，输出外层 user 结束标记：<<<[END_ROLE_DIVIDE_USER]>>>

各标记前后使用换行。新时间戳按默认时区环境配置生成，毫秒精度，携带显式偏移，例如 2026-10-29T21:25:17.192+08:00。配置键为 DEFAULT_TIMEZONE，未设置或非法时回退 Asia/Shanghai；非法配置记录警告。偏移按对应瞬间计算，支持夏令时和非整点时区。开始和结束复用同一字符串，不是分别取当前时间。它是边界匹配键，不是工具记录 ID，也不是结束时间。生成器在同一进程内递增以避免同毫秒重复，并检查完整批次正文不存在所选同批次界定符，碰撞时更换时间戳。

前后端解析器必须同时兼容历史 Z 格式和新格式的正负 HH:mm 偏移；上面的 Z 示例仍为合法历史格式。匹配批次结束时对原始时间戳做精确字符串匹配，不先换算时区。

关闭角色拆分配置仍输出批次边界。仅摘要也形成批次；没有可见结果及摘要则不输出空批次。普通调用、Archery 可见结果及混合调用统一包装。

## 流式

继续使用 OpenAI 风格 SSE 的 choices[0].delta.content 传输正文，不新增事件类型。所有批次正文在工具执行完成后统一有序输出；不保证一个界定符或一个结果对应一个 SSE 包。客户端必须增量解析跨包标记。

## 非流式

choices[0].message.content 包含完整拼接后的同一文本，解析规则与流式累积正文一致。

## 消费规则

- 在 Markdown、HTML 清洗及全局角色/工具协议解析之前识别批次。
- 识别开始后，只查找时间戳完全相同的结束标记，不计内部嵌套深度。
- 区间内部所有角色标记、工具请求标记、旧结果框标记以及其他时间戳的批次标记都是正文，不得重新进入全局协议扫描。
- 标记本身隐藏；历史存储保留完整原文及边界。
- 断流/截断后未找到结束标记，剩余内容继续保持隔离，显示未完成状态，不回退全局扫描。
- 完整批次关闭后恢复外层解析，真实外层 user 结束标记仍生效。
- 后端恢复正文必须逐字保持原文，不对结果中的协议字面量转义或删除。
- 旧历史没有批次边界，保留旧格式兼容解析，不能保证恢复歧义数据。

## 前端展示边界

整个批次可以作为独立结果容器。批次边界不解决内部单结果旧格式的歧义；不得依据残缺的旧结果框把内容泄漏回全局解析器。若要精确拆分每个工具气泡，后续需另设单结果分帧或结构化事件。

随机 ID 和时间戳都不是鉴权凭据，本协议不防止模型仿写。时间戳由服务端生成，不要求模型生成或补齐。HTML/脚本输出另需受限沙箱。

## 上游模型可见投影

客户端传输、历史存储和内部角色解析继续使用原始协议。仅在初始请求及工具循环请求序列化之前，对上游请求副本转换外层包装两端：

- 开始转换为： 【工具返回批次开始｜时间：2026-10-29T12:51:34.979Z】
- 结束转换为： 【工具返回批次结束｜时间：2026-10-29T12:51:34.979Z】

只识别紧贴外层 user 角色开始/结束的同时间戳批次包装；角色拆分后，仅识别占据整条 user 文本的批次包装。两种可读说明没有协议语义，不自动还原为协议。投影显示时间也按 DEFAULT_TIMEZONE 转换，包括旧 Z 格式的外层包装；例如历史 2026-10-29T13:25:17.192Z 在 Asia/Shanghai 下显示为 2026-10-29T21:25:17.192+08:00。历史存储的原始界定符不重写，正文中的时间及引用不转换。

不得全局替换：批次内部引用、代码、文档、工具请求参数及工具返回原文全部保留。当前轮带内部工具载荷前缀的消息、真实 tool/function 消息不投影。多模态只处理可以明确识别包装的单文本片段，跨多个文本片段等歧义情况保持原文。

这是结构识别，不是来源认证：用户或模型仿写完全相同的外层结构时无法仅凭文本证明其来源。本投影仅降低模型复读系统包装的概率，不保证模型看不到正文引用中的真实协议，不构成安全沙箱。
