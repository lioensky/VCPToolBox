### 施工图补充注意事项的核实边界

1. 单位原向量不能直接作为曲率为 1 的合法球内点。FP32 舍入可能使其恰好越界或勉强在界内而产生极大共形因子；不是所有输入必定报错。保持 SQL 原向量，只派生半径/深度等路由元数据。
2. 双曲代理与真实测地距离单调对应但不等价；涉及剪枝比例、路径步长或指数相似度时需恢复真实测地距离，不能因排名单调就替代全部距离公式。
3. 排除节点应能导航，但不能占有效候选/精排预算；还需检查束终止条件，不能只改最后的结果过滤。
4. 合并热表后的写入需要恢复独立存储或增量尾部；若位平面已经重编码为切锥残差，不能将其直接当原全局签名恢复，必须维护残差语义或重新编码。
5. 长维度非对称累加需要按块拓宽；存在合法输入使全长 i16 累加溢出，但不是任意输入必然溢出。当前每四个 chunk 拓宽的设计已加入整数一致性及通道界测试。
6. 小作用域门槛与方差裕量属于工程保护/经验模型，不是“零误拒”证明，仍须在真实分布与小范围过滤上做召回对照。

- 未改变快照布局、候选预算、过滤语义或 SQL 权威向量；未发布原生模块。

### 新增风险：强层级与角量化误差的联合影响（待实证，不是已发生故障）

用户指出默认无量纲深度区间 [0.35, 3.20] 可能使外壳候选对角误差敏感，并让内壳枢纽挤占有效候选。**风险机制成立，但“必然黑洞”尚无数据证据。**

曲率为 1 时，本次数学数值核对：

| 项 | 数值 |
| --- | ---: |
| 深度 3.2 的欧氏半径 / 共形因子 | 0.921669 / 6.643323 |
| 深度 0.35 的欧氏半径 / 共形因子 | 0.173235 / 1.030939 |
| 外壳–外壳共形因子乘积 | 44.133742 |
| 外壳–内壳共形因子乘积 | 6.848860 |

需要同时保留以下数学边界：

1. 固定查询时，查询共形因子是所有候选共有的正因子；仅比较上述乘积不足以推出候选排名，必须合并径向项及角项。
2. 内壳候选存在不可忽略的径向代价。同方向、同深度外壳点的精确距离为零，不可能仅因共形因子大就输给内壳点。
3. 对同深度外壳点，代理对余弦误差的敏感系数为
   $$A(d,c)=2r(d,c)^2 f(d)^2=\frac{\sinh^2(d)}{2c},\qquad |\Delta P|=A(d,c)|\Delta\cos\theta|.$$
   曲率 1、深度 3.2 时系数约 74.980837；深度 1.8 时约 4.328195，前者约为后者的 17.3 倍。该式是**代理**误差放大，不是实际测地距离的线性放大倍数。
4. 外壳查询深度 3.2、内壳深度 0.35 时：内壳候选余弦为 1 / 0.5 / 0，其代理距离约为 3.836407 / 4.929933 / 6.023459；与之打平的同深度外壳候选余弦约为 0.948835 / 0.934251 / 0.919667。角量化误差是否足以跨过具体排名差距，需测真实误差与候选间隙，不能只凭“44 倍”认定。
5. 即使使用精确角度，几何目标本身也可能偏好内壳；应先区分“精确双曲目标与语义相关性不符”以及“近似核相对精确双曲目标丢召回”，不能把两者都归咎于 2-bit 量化。
6. 曲率不应和无量纲深度跨度混为同一个温度：固定所有方向与无量纲深度后，代理整体按曲率倒数缩放、真实距离整体按曲率平方根倒数缩放，**精确检索排名不变**。仅扫曲率不能找到层级收益的排序拐点。包含指数相似度时，应显式控制其温度与曲率的耦合；FP32 合成坐标舍入/数值边界仍须单独测量。

- 局部校准将原余弦相对背景0.25、近邻上界0.75线性缩放，裁剪到0至1，再代入角惩罚。两个阈值均为本轮显式基准参数，不作为已拟合的通用语义常数。

- [传输钟峰](../rust-vexus-lite/src/memo_artifact_builder.rs:320)及[局部几何钟峰](../rust-vexus-lite/src/memo_geometry.rs:794)源码默认峰为0.65，且属于不同传播/解释机制；本轮没有读取敏感运行配置，不能据源码宣称当前生产一定配置为0.67，也不能把钟峰默认值当作查询近邻分布的实测证明。
- NNLS剥离不保证把整个全局均值方向完全消除。均值对齐度下降、L1有效信号与L2能量耗尽需要按每条实际轨迹观察。
- 各向同性参考尺度为维度平方根倒数，3072维约0.01804。本轮不把它当作真实嵌入/残差的已拟合标准差；“若干倍参考尺度”不是已校准的统计显著性或语义相关性证明。

### 实例级实现与冻结v1公式

- [自适应锥模块](../rust-vexus-lite/crates/vcp-tdb-index/src/index/quiver/hyperbolic/semantic.rs)提供实例/请求级配置，支持均值背景和地标中位数背景。无进程可变全局、无层号分支、无从全扫真值取阈值。
- 构建每读取一条原向量，按其双精度范数累加单位方向，最终除以索引节点数。常驻一个双精度均值向量，3072维24576字节；不驻留全库FP32，不增加源读取遍数。
- 均值背景为当前单位查询与该非单位化均值向量的点积正部；复杂度随维度线性，不随库大小线性。地标背景为全部热地标的SM余弦中位数正部，本轮512次热评分，不读冷向量。
- 冻结参数：参考噪声倍数4、残差锥宽0.25、各向异性附加锥宽0.05、对齐参考0.45。
- 背景基线先裁入0至0.95；资格下界为基线加4倍参考尺度、最多0.98。上界为基线加0.25，再加最多0.05的对齐附加项；至少高于下界0.001、最多0.999。公式及参数逐项写入原始输出，不因留出结果改动。
- 查询余弦相对该下/上界线性缩放并裁入0至1，用于热束两通道、非对称有界精筛及最终精确分数。**仍是查询局部语义评分，不是原始Poincaré度量。**
- [查询入口](../rust-vexus-lite/crates/vcp-tdb-index/src/index/quiver/hyperbolic/index.rs)保留原入口默认关闭语义锥，另有显式可选入口。构图地标/原几何选种/四向剪枝保持既有原球面与径向几何目标；查询语义变化不被伪装成构图目标也已经改变。
- 没有热态方向硬过滤，因此没有2-bit门槛裕量误拒；所有已发现节点仍能导航，排除桥契约不变。只有最终读原向量后，以精确余弦裁决返回资格。
- 语义入口拒绝请求精排上限超过64；精排只遍历原有有界前缀，不为补足10项继续追加。拒绝项占实际冷读但不进入结果；排除项不进入精排。
- 输出明确区分原始测地距离与校准代理的单调变换，后者不称原生测地距离。径向开关的界只来自非负角损失下的径向项，没有挪用原角度三角不等式。
- 增加反向剪枝次数/耗时计数。本轮只记录、不改拓扑或调度；逐次计时本身有少量观测开销。

### 基准协议

[真实ANN入口](../rust-vexus-lite/benchmarks/sm-search/src/bin/adaptive_ann.rs)同台运行：

1. 现役余弦ANN；
2. 原入度最大值归一化、未校准庞加莱ANN（延续此前含平方根特异性的原基线，不另改成字面线性深度）；
3. 全覆盖秩深度、均值自适应语义锥ANN；
4. 同一秩图、地标自适应语义锥ANN，作为机制对照，不替代第三行或混算。

统一条件：

- 禁用AVX-512；方向3072维；深度上界1.8、下界0.35；查询深度为支撑跨度的25%/50%/75%，仍非EPA熵/逻辑深度回放。
- 名义宽度128、双曲访问256、展开128、每层唯一冷读最多64、最多三层、候选层解释门槛0.03。余弦沿现役宽度与精排接口，不宣称与双束完全相同热工作量。
- 每条路线用自身实际ANN前10和生产NNLS求下一层，接受后才排除历史结果并更新残差；不同路线后续方向不同。各自对同层方向建立自身精确评分真值及原余弦真值，不用别条轨迹当真值。
- 解释能量不足层的候选词、读次数和耗时仍计实际工作，但不算发布/接受的语义层；终局能量保留最后已接受残差，不把被拒绝层的能量下降计成收益。
- 本层最终精排读到的最多64个向量放入短生命周期有界缓存，NNLS复用，不再额外读结果向量。缓存最多64乘维度个FP32，不是全库向量驻留。
- 真值全扫在本层计时ANN之后独立执行；精确前10也求一次NNLS，单列评价读次数。该评价信息不回流搜索、阈值或实际轨迹。
- “对照真值本可解释、ANN却停机”仅指该路线同层精确前10的解释能量达到0.03；“干净停机对照”仅指同层精确前10也不足0.03，不能外推为全空间无任何可解释组合。
- 耗时仅为ANN冷读/有界缓存加NNLS，不含评价全扫，暖冻结SQLite、固定路线顺序，无CPU亲和性；不是生产端到端或磁盘冷缓存延迟。
- 热地标/选种评分不包含在束访问计数内；不把256次束访问冒称查询全部热评分。
