# Pelorus × Vexus-Lite 严格试验记录

## 2026-11-16：Stage 2A 首批位核实验

### 分支与环境

- 施工依据：[双曲施工图](双曲施工图.md)。
- 当前分支：VexusRiver双曲黎曼度规试验分支；跟踪远程同名分支。
- 基线提交：dddee235（开始试验），施工前工作区干净。
- CPU：Intel Core i7-13790F，16 核、24 逻辑处理器。
- Rust / Cargo：1.89.0；release 模式；微基准单线程。
- 本批仅修改索引核及测试，不修改生产 SQLite 数据，不发布原生模块，不提交或推送。

### 已实施范围

- [指令集分发](../rust-vexus-lite/crates/vcp-tdb-index/src/index/bq.rs)：缓存五档硬件能力，同时支持两个 AVX-512 禁用环境变量。只缓存不可变硬件能力，不增加可变的全局实验配置。
- [共享五计数内核](../rust-vexus-lite/crates/vcp-tdb-index/src/index/sm_counts.rs)：标量、硬件 POPCNT、AVX2 3-to-2 CSA、AVX2 + POPCNT 尾部和 AVX-512 路径；显式维度掩码，不读取超出切片的完整 SIMD 块。
- [固定维度评分及精排](../rust-vexus-lite/crates/vcp-tdb-index/src/index/quiver/corrected_sm.rs)：接入共享位核；新增保持旧十六条 FMA 链和归约顺序的 AVX2 精排；四候选精排入口增加硬件能力门禁。
- [通用维度路径](../rust-vexus-lite/crates/vcp-tdb-index/src/index/quiver/corrected_sm/dynamic.rs)：接入共享位核及 AVX2 精排。
- [实验测试](../rust-vexus-lite/crates/vcp-tdb-index/src/index/quiver/corrected_sm/dynamic_tests.rs)：增加确定性平扫微基准及独立旧标量递推的精排位级比较。
- 未改变评分公式、候选预算、二进制快照格式或 SQL 权威真源契约。

### 正确性结果

| 验证 | 改动前 | 首批改动后 |
| --- | --- | --- |
| 索引核 release 测试 | 83 通过，2 忽略 | 85 通过，3 忽略 |
| 主库 release 库测试 | 231 通过 | 本机请求绕过代理后 231 通过 |
| 五计数独立逐位 oracle | 未新增 | 可用内核逐整数一致 |
| AVX2 精排与旧标量递推 | 未新增 | 点积及负平方距离逐位一致 |
| 五维度平扫结果指纹 | 已记录 | 全部与改动前一致 |

五计数覆盖零维、短维、非整块尾位、65 / 384 / 768 / 1536 / 3072 维及 4096 维上限；使用精确长度数组及脏尾位测试。当前 CPU 实测分发为 Avx2Popcnt，精排为 Avx2Fma。AVX-512 在本机不可实测，不能声称已完成该硬件路径验收；测试在具备对应指令集的机器上才执行该分支。

### 单线程平扫微基准

2048 行，返回 64 个候选，预热 8 次、测量 100 次；使用确定性合成向量，不访问 SQLite。本表是单次采样，不是稳健统计或生产 QPS 结论，也不测量精排耗时。

| 维度 | 基线 μs/查询 | 首批改动后 μs/查询 | 基线/改动后 |
| --- | ---: | ---: | ---: |
| 65 | 80.542 | 73.541 | 1.10 |
| 384 | 92.460 | 82.303 | 1.12 |
| 768 | 113.509 | 100.598 | 1.13 |
| 1536 | 197.994 | 127.938 | 1.55 |
| 3072 | 337.686 | 177.638 | 1.90 |

首轮强行让短维进入 AVX2 时 65 / 384 维变慢；随后改为 512 维以下使用硬件 POPCNT，得到上表结果。完整性能验收仍需多轮统计、位核与精排独立微基准以及真实 SQLite 召回测试。

### 执行异常与证据

- 主库第一次回归为 230 通过、1 失败：本机 HTTP fixture 固定返回 429，但客户端收到 502。仅在测试子进程将本机地址设为代理绕过后，单独测试及全部 231 项测试通过；没有修改 HTTP 重排源码。代理介入是当前证据支持的解释，不是算法回归证据。
- 长时间无输出来自编译输出重定向及后台完成通知延迟；进程检查确认任务实际在 15:33:34 已结束。后续使用实时输出，避免将静默误判为卡死。
- 原始基线和首批日志存放于构建目录的 pelorus-experiment 子目录，不作为稳定交付文件；关键数值已摘录于本记录。
- 现有 SQL 基准只支持 3072 维外部数据，且不声明耗时结果，不能替代本施工图要求的完整跨维度性能基准。
