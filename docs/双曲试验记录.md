### 施工图补充注意事项的核实边界

1. 单位原向量不能直接作为曲率为 1 的合法球内点。FP32 舍入可能使其恰好越界或勉强在界内而产生极大共形因子；不是所有输入必定报错。保持 SQL 原向量，只派生半径/深度等路由元数据。
2. 双曲代理与真实测地距离单调对应但不等价；涉及剪枝比例、路径步长或指数相似度时需恢复真实测地距离，不能因排名单调就替代全部距离公式。
3. 排除节点应能导航，但不能占有效候选/精排预算；还需检查束终止条件，不能只改最后的结果过滤。
4. 合并热表后的写入需要恢复独立存储或增量尾部；若位平面已经重编码为切锥残差，不能将其直接当原全局签名恢复，必须维护残差语义或重新编码。
5. 长维度非对称累加需要按块拓宽；存在合法输入使全长 i16 累加溢出，但不是任意输入必然溢出。当前每四个 chunk 拓宽的设计已加入整数一致性及通道界测试。
6. 小作用域门槛与方差裕量属于工程保护/经验模型，不是“零误拒”证明，仍须在真实分布与小范围过滤上做召回对照。

- 未改变快照布局、候选预算、过滤语义或 SQL 权威向量；未发布原生模块。

### 新增风险：强层级与角量化误差的联合影响（待实证，不是已发生故障）

用户指出默认无量纲深度区间 [0.35, 3.20] 可能使外壳候选对角误差敏感，并让内壳枢纽挤占有效候选。**风险机制成立，但“必然黑洞”尚无数据证据。**

曲率为 1 时，本次数学数值核对：

| 项 | 数值 |
| --- | ---: |
| 深度 3.2 的欧氏半径 / 共形因子 | 0.921669 / 6.643323 |
| 深度 0.35 的欧氏半径 / 共形因子 | 0.173235 / 1.030939 |
| 外壳–外壳共形因子乘积 | 44.133742 |
| 外壳–内壳共形因子乘积 | 6.848860 |

需要同时保留以下数学边界：

1. 固定查询时，查询共形因子是所有候选共有的正因子；仅比较上述乘积不足以推出候选排名，必须合并径向项及角项。
2. 内壳候选存在不可忽略的径向代价。同方向、同深度外壳点的精确距离为零，不可能仅因共形因子大就输给内壳点。
3. 对同深度外壳点，代理对余弦误差的敏感系数为
   $$A(d,c)=2r(d,c)^2 f(d)^2=\frac{\sinh^2(d)}{2c},\qquad |\Delta P|=A(d,c)|\Delta\cos\theta|.$$
   曲率 1、深度 3.2 时系数约 74.980837；深度 1.8 时约 4.328195，前者约为后者的 17.3 倍。该式是**代理**误差放大，不是实际测地距离的线性放大倍数。
4. 外壳查询深度 3.2、内壳深度 0.35 时：内壳候选余弦为 1 / 0.5 / 0，其代理距离约为 3.836407 / 4.929933 / 6.023459；与之打平的同深度外壳候选余弦约为 0.948835 / 0.934251 / 0.919667。角量化误差是否足以跨过具体排名差距，需测真实误差与候选间隙，不能只凭“44 倍”认定。
5. 即使使用精确角度，几何目标本身也可能偏好内壳；应先区分“精确双曲目标与语义相关性不符”以及“近似核相对精确双曲目标丢召回”，不能把两者都归咎于 2-bit 量化。
6. 曲率不应和无量纲深度跨度混为同一个温度：固定所有方向与无量纲深度后，代理整体按曲率倒数缩放、真实距离整体按曲率平方根倒数缩放，**精确检索排名不变**。仅扫曲率不能找到层级收益的排序拐点。包含指数相似度时，应显式控制其温度与曲率的耦合；FP32 合成坐标舍入/数值边界仍须单独测量。

### 深度与 Chunk 映射实验要求（未来实施门禁）

- 深度下界、上界、曲率、Tag 混合权重/幂次、Chunk 聚合策略和外偏移必须为实例或实验配置，不在引擎写死默认常数。配置改变需失效并重建依赖它的派生路由元数据；SQL 原向量保持不变。
- 首批至少对比 [0.35, 1.80] 与 [0.35, 3.20]；建议增加中间跨度作响应曲线。固定数据、查询、随机种子、候选预算及冷读预算，先在仅检索模式隔离召回效果，不以全测地评分掩盖召回变化。
- 曲率实验用于数值稳定性、几何单位与评分温度校准，不把固定无量纲深度下的纯曲率缩放宣传为排名提升。
- 先做“余弦精确真值 / 双曲精确真值 / 双曲近似核”分解：分别测语义目标变化与 ANN 近似损失。记录每个深度分桶的 Recall@10、角代理误差分位数、候选间隙、内壳候选占比、最终精排冷读次数和耗时。
- **Chunk 加权均值再外移 0.25 只是基线，不是已验证合理的层级真源。** 混有少量上位 Tag 与大量长尾专名时，记录平均深度、上位/长尾权重分布及截顶比例；全长尾样本尤其检查是否大量饱和到上界。
- 对照可包括闭合度加权分位数与不同外偏移，但这些也是待测策略，不预先认定分位数一定优于均值。明确所有闭合度为零、无 Tag、无效统计与离群值的回退，避免零除或静默制造深度。
- 同时记录深度分布、方差、分位数及上下界命中率：宽区间不等于实际数据有宽层级，窄壳与截顶退化都需要检测。
- 残差重编码、非对称重排和门控预算分别开关消融。任何宣称“修复外壳误差”的策略必须在同冷读预算下对比，不用额外精排偷偷换取召回。

### 新增排除回归：残差金字塔跨层枢纽复用

- 前层选中的上位 Tag 在后层被排除的是**结果资格**，不是导航资格。原点枢纽和跨锥桥接节点必须仍可入导航前沿、展开邻接边。
- 被排除节点不得占有效候选席位、精排预算或作为“有效结果已满/足够接近”的收敛依据；但实际节点访问/展开计数应如实记录并受独立的安全上限约束，不能从所有工作计数抹掉导致无界搜索。
- 检查束停止阈值是否由可返回候选导出；不能仅在最终结果截取时过滤。具体逻辑需结合双保持束实现验证，不能假定简单过滤一个池就足够。
- 必加夹具：第零层选出连接多个锥区的内壳枢纽；第一/二层把它加入排除集，允许的长尾答案只可经该枢纽到达。与不排除但最终过滤的可达性对照，检查有效结果、唯一冷读次数、束容量、停止原因及安全访问预算。
- 增加“入口和全部初始枢纽均被排除”“连续多层排除累积”“全部结果被排除”“被排除桥接节点兼具高入度”的边界测试，避免只能在未排除首层工作。
