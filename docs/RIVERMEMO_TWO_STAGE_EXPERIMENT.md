# RiverMemo 两阶段读出实验

## 实验边界

- 分支：rivermemov3git。
- 两阶段共用过滤边界、持久化图格式和共同候选机制；不修改运行数据库。
- 阶段二继承阶段一去噪和锚点修复，仅重构拓扑读出。
- 本地构建平台：Windows x64 MSVC。其他平台二进制未更新，不代表已构建。
- 更换原生模块必须停止服务、替换对应平台文件后重启，不能在已加载进程中热替换。
- 使用相同查询、数据/图资产快照、配置和候选数量；同时核对实际候选身份。
- 版本以原生响应 algorithmVersion 为准，不能仅按文件名判断。

## 阶段一：safe-stoploss-v1

- 低于 0.03 原始查询能量的边际解释层停止注入。
- 同层按归一化正交贡献过滤低于最大贡献 10% 或绝对 0.05 的非核心标签；非正相关非核心标签不注入。
- 已接受层的强贡献标签减轻层衰减，恢复不超过原权重。
- 语义读出默认 Query/Local/Transfer 为 0.7/0.2/0.1，缺失场不占分母。
- 直锚使用高贡献源种子，一对一贪心匹配，精确优先，最多三个接触。
- 单个精确接触不按种子数量打折；仍保留闭合度和回退可靠性约束。
- 语义接触至少 0.88，按相似度连续计权；候选池稀有度不再影响锚奖励。
- 绝对平滑激活取代批均值加标准差门槛；取消最强锚自动晋升。
- 直接答案需要精确焦点接触和正文闭合；移除直接答案前沿压制。
- 路径奖励从语义基础分移出，保留原计算尺度且仍不受 Omega 门控。
- 图创新奖励保留原机制并经过 Omega 门控；路径和图共用拓扑奖励预算。
- 输出 baseScore、pathBonus、graphBonus、anchorBonus、scoreClipping：
  score = baseScore + pathBonus + graphBonus + anchorBonus - scoreClipping。
- Basin 每通道保底外层探索由八个改为两个；扩张后再按收益分配。
- 投影对观测核心以外的高入度节点温和降权，不重算或修改传输图。
- 旧 anchorActivationZ、anchorFrontier*、reliabilitySeedSaturation 配置为兼容保留，但不再控制退休机制。
- 当前焦点身份采用高贡献源场代理，不宣称已实现通用实体识别。
