核对位置：[`memo_sensing.rs`](../rust-vexus-lite/src/memo_sensing.rs)。

### E. 双场的职责重分配

1. 原始查询与正文相似度提供语义基线及跨主题防线。
2. 增强查询和 Local/Transfer 投影向量可继续参与候选扩展，不作为最终主要相关性证据。

4. 不把旧 20%/10% 场余弦权重机械搬给不同量纲的路径原值；先校准证据，再设置奖励预算。
5. 图证据缺失或不可靠时，保留方案一语义读出作为回退；可靠图证据出现时，再平滑转入拓扑改序，避免突然换标尺。
6. 明确记录回退原因与实际语义基线。没有图时不新增一个低分常数惩罚，也不虚构拓扑奖励。

### F. 路径穿场与活跃河网读出

现有问题：
- 旧路径质量检查候选相邻标签在全局图是否有连接，并不要求这条连接是本次查询活跃流道。
- 全局高势泛主题区域仍可能获得漂亮路径分。
- 文件标签位置是标注顺序，不是已验证的正文叙事或因果顺序。
- 查询边几何主要使用 hop 差，浅层图里很多边距离相同。
- 旧路径质量对全部标签段取平均，可能被无关尾巴过度稀释。

准备处理：
1. 请求级建立活跃边索引，保留原始流量与归一化流量；区分精确边支持、语义边支持及仅全局连通。
2. 候选曲线消费双端势值、有效域、方向、连续性和活跃流道支持；不只看节点高势。
3. 用焦点相关的有效支持段构造有界、长度归一化的路径证据，同时报告完整覆盖。不能靠一个孤立高分段冒充全链覆盖，也不能让追加无关尾标签任意改变得分。
4. 全局连接可作为弱辅助或缺边回退，但不能和精确活跃边拿相同奖励。
5. 路径长度不同或标签缺失时，允许有限、可解释的部分支持；不强制所有正确答案逐标签复刻查询。
6. 不虚构查询原本没有的边、候选原本没有的关系或跨未录取节点的路径。
7. 方向只作为结构证据，不能在输出中称为经正文验证的因果链。
8. 对浅层 hop 距离使用降权或中性回退，避免不适用的几何差异把真实边匹配压没；具体几何校准由回归夹具验证。
9. 复用现有边来源独立性信息，但区分“唯一来源”与“无效关系”：冷门实体只有一篇记忆，不等于该篇不应被检索。

### G. 节点与边对齐可靠性

- 当前拓扑节点对齐允许多个查询节点映射同一候选标签。不能因为锚点已一对一，就误以为拓扑对齐也已去重。
- 准备对拓扑映射增加候选侧容量约束或等价去重，精确身份优先，防止许多近义查询节点堆到一个泛标签上刷覆盖。
- 精确焦点、同义焦点和主题近邻要分开；仅高余弦不自动等价于同实体。
- 对齐缺失、漏标和同义别名必须有部分支持通道，不能所有不精确匹配一律归零。
- 可靠性由实际覆盖、闭合、唯一性、有效流道和身份保持组成；图分已含某证据时，不在后续重复相乘惩罚。
- 传输方向和候选顺序契合不能代替焦点身份；反之，单个实体命中也不能冒充复杂关系命中。

### H. 两个互补拓扑证据通道

通道一：焦点/节点证据
- 面向单标签、专名记忆、漏标或本次无可用边的候选。
- 依赖可信焦点接触、节点覆盖和正文闭合，奖励有界。
- 不要求不存在的相邻路径，避免单标签正确答案被硬乘归零。
- 与直锚身份奖励有重叠部分时必须去重或共同限额。

通道二：活跃边/路径证据
- 面向真正复现本次查询关系结构的候选。
- 依赖边对齐、路径穿场、有效覆盖与拓扑可靠性。
- 允许同样命中实体的候选根据结构契合度进一步改序。
- 泛领域高势区、单个主题相似标签不能直接拿该通道强奖励。

按证据适用性组合两个通道；不要简单把图分、路径分、可靠性原值相乘。任一证据缺失，不应自动抹杀另一通道的合法证据；但缺失复杂关系时也不能获得完整路径分。

### I. 替换同伴创新资格门槛

旧机制要求图分超过邻居均值再超过不确定性惩罚，多个好候选容易相互抵消成零。它衡量的是“相对异常”，不是“自身有无可靠结构”。

方案二：
- 主拓扑奖励直接由候选自身经校准的证据驱动。
- 同伴比较不再决定有无奖励；如保留，只能是诊断或很小的修正。
- 多条同样优秀记忆应同时有正拓扑奖励。
- 加入无关候选，不应大幅改变已有候选的自身拓扑奖励。
- 移除退休的创新控制对最终计分的隐性影响；旧配置可兼容读取，但须明确不再生效。

设计骨架（不是已批准的具体数值公式）：
- 语义基线：提供主题边界与图不可用时的回退。
- 候选自身证据：校准后组合节点与路径通道。
- 图可用性：Omega 仅调节传播结构证据的可用程度。
- 主题/焦点一致性：限制高活跃但错误主题的图证据。
- 拓扑奖励：统一预算内给予改序能力。
- 直锚奖励：保留 1.1 规则，与重复身份证据协调。
- 最终分：语义基础 + 路径奖励 + 图奖励 + 锚点奖励 - 截断扣分。

具体校准、门控和通道权重待实现时通过合成回归与服务器实验确定；不得把本节伪装成已有数学定理或已验证最优参数。

### J. Omega 与奖励预算

- Omega 原有边数、涌现数、流量熵是河网活跃度，不是主题正确率。
- 不因种子减少导致 Omega 分母缩小，就宣称检索质量提升。
- 路径和图结构奖励使用明确、统一的门控与预算，不能让旧基础分里残留一条绕过门控的加分通道。
- 节点身份直锚与传播奖励分开：无传播时精确实体仍可成立，不能被 Omega 一并抹掉。
- 先校准再提高拓扑总预算，使可靠结构能反转小幅至适度余弦劣势；不预先拍定一个巨大上限。
- 不恢复直接答案的独占天花板或角色倍率阉割。
- 输出预算请求值、实际值和截断，防止“面板拓扑为零，基础分暗藏路径奖励”再次出现。
- 同时命中主题但不命中实体的错误河网，即使 Omega 很高也不得自动赢得大额奖励。

### K. 直接答案资格补强

Step 1.1 已阻止纯隐式接触晋升，但当前“至少一次精确接触且不是纯隐式”仍存在混合漏洞：
- 精确接触可能来自隐式标签；
- 显式种子可能仅有语义接触；
- 两者组合不能宣称“精确命中显式焦点”。

方案二准备：
1. 单独统计显式精确、显式语义、隐式精确及隐式语义接触。
2. 存在显式焦点时，直接答案必须有真实的显式精确接触及正文闭合；同义支持另行解释，不偷换为精确。
3. 无字面焦点的抽象查询保留语义/拓扑结果，不以满池直接答案标签作为检索成功条件。
4. 角色主要用于解释，不作为预先分配排序特权的身份帽子。
5. 高贡献主题种子不等于实体焦点；字面覆盖是轻量启发式，不宣称完成通用实体识别。

### L. Basin、投影与性能边界

- 阶段一已将每通道保底探索从八个降为两个；之后按重要性和收益分配，并非全程均分。
- 不彻底取消弱分支保底，否则 L1 真焦点可能再被 L0 强主题饿死。
- 种子减少不保证 256 个投影节点天然正确，应看实际分支贡献和 Hub 集中度。
- 场投影不再主导最终排名后，不为追求形式纯粹立即删除全部向量投影：它仍可能用于候选扩展，避免影响共同池。
- 如确需进一步调预算，限制总保底开销、保持真实路径前驱和共享上限；单独展示策略效果。
- 保留工作量上限、请求级缓存、批量 SQL 与 Rayon 并行，不新增全库逐查询向量读取。
- 活跃边索引和对齐辅助结构按请求构建，不复制全库图，不改变已有观测生命周期。
- 防止新增候选两两比较或无界路径枚举；记录候选数、标签数、比较次数和耗时以定位退化。

### M. 必须补齐的诊断

请求级：
- 原生算法版本、实际解析的读出参数，而非只展示调用侧传入值。
- 共同候选身份/数量、资产签名、数据库代际、观测完整性。
- 显式与隐式种子来源，尽可能展示原始贡献、有效贡献及注入能量；区分 FIR 观测能量。
- 保留/拒绝层与标签的原因；若需扩展诊断，只添加有界回执，不把整个向量池跨 N-API 输出。

候选级：
- 原始查询相似度、实际语义基线和回退原因。
- 节点通道与路径通道的校准前/后证据。
- 精确与语义节点/边覆盖、活跃边支持、路径质量、闭合及可靠性。
- 显式/隐式锚点分类、实际独立匹配及必要的有界贡献解释。
- Omega 门控、主题一致性门控、拓扑请求/实际奖励、统一限额。
- 语义、路径、图、锚点、截断和最终分必须可复算。
- 只有请求详细诊断时输出较重跟踪；正常检索保持稳定结果形状与有界成本。

### N. 回归与验收矩阵

必须具备可重复的合成测试，不能只看 Lunarium 一次结果：

1. 同实体、不同关系结构：更贴合活跃边的候选可反转适度余弦劣势。
2. 同主题不同实体：高场势、密集全局图不能冒充显式焦点。
3. 多个优等生：都得到正拓扑支持，不相互抵消为零。
4. 池不变性：增加无关候选不显著改变已有候选的自身奖励。
5. 多标签防刷：追加泛标签、近义种子或重复标签不能持续刷高覆盖与奖励。
6. 单标签精确实体：无路径时节点/锚点仍有效，不被乘零。
7. 漏标与短名：保留 Lunarium 短名支持，不强制完整标签链。
8. 混合接触漏洞：隐式精确加显式语义不能获得显式精确身份。
9. 无字面焦点：抽象、隐喻查询有平滑回退，不要求词面命中。
10. 全局边但非活跃边：不得拿到与真实流道同等的路径奖励。
11. 浅层图：hop 差退化时不任意惩罚正确边对齐。
12. 方向反转：解释有区别但不声称验证正文因果。
13. 唯一来源/冷门实体：不被来源独立性机械归零。
14. 低质量或空图：无虚假拓扑奖励、无异常中止，回退分数可核算。
15. 高 Omega 错主题：不能仅凭通行证抬高无关候选。
16. 权限和同快照：越权候选不参与归一化/统计，图资产与观测代际验证不退化。
17. 确定性、缺失向量、负余弦、截断与总预算：维持稳定边界。
18. 相关 Node ABI、实验室格式、普通检索结果兼容性，以及原生加载测试。

服务器复测：
- Lunarium 原查询及无问题描述、只问历史介绍、只问具体机制等变体。
- 伊朗关系查询及不同国家、不同动作的对照，区分实体与关系效果。
- 普通游戏吐槽、泛主题、无实体、多实体及冷门新实体。
- 对比固定共同池的排名、关键相关候选覆盖、错误主题夺冠率和耗时；外部评分是参考，不当作全库真值。
- 不保证某个指定 Chunk 永远第一；验收关注可解释且可泛化的结构增益。
