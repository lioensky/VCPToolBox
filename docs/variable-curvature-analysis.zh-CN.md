## 一、结论：这次“动态双曲”究竟是什么

官方实现的准确名称是“变曲率几何研究原型”。这里的“动态”不是时间维度上的在线变化，而是突破整个空间共享一个常负曲率的限制。

实现分成两个层次：

1. **Tier 2：混合／乘积常曲率流形。** 将向量拆成坐标块，每块属于不同几何，各自采用固定曲率。整体不是一个单曲率双曲球。
2. **Tier 3：径向变曲率翘曲乘积流形。** 用一个预先指定的径向剖面描述空间，使几何随点到原点的距离变化。这才是真正的位置相关变曲率。

它没有实现在线学习曲率、按节点训练任意曲率、自动生成流形嵌入，也没有把新几何直接接到正式 `Index` 的完整生命周期上。

这次实现的核心思想是：**保持半径与方向解耦，以 2-bit 方向码近似角度，以真实几何校准的低维表近似导航距离，最后对少量候选执行真实目标几何的数值测地精排。**

不能把它理解为“查询时给原有 Poincaré 公式换一个 c”。曲率随空间变化后，测地线经过不同位置，距离必须考虑整条路径。

## 三、基础原理：为什么需要从常曲率走向变曲率

### 3.1 原有常曲率双曲球

对于曲率为 `-c`、`c > 0` 的 Poincaré 球，坐标满足：

\[
c\|x\|^2 < 1.
\]

距离由闭式公式得到：

\[
d_c(x,y)=\frac{1}{\sqrt c}\operatorname{acosh}\left(
1+\frac{2c\|x-y\|^2}{(1-c\|x\|^2)(1-c\|y\|^2)}\right).
\]

令 `x = r_x u_x`，则：

\[
\|x-y\|^2=(r_x-r_y)^2+2r_xr_y(1-\langle u_x,u_y\rangle).
\]

这正是 Pelorus 原有极坐标导航的基础：保留径向／共形标量，压缩方向，避免量化直接污染接近球边界的奇异分母。

### 3.2 变曲率带来的本质变化

在一般变曲率空间，端点半径与夹角仍然可以是充分的距离参数——前提是空间球对称——但不再能直接使用上述常曲率闭式公式。

尤其在负曲率空间，连接两个外围点的最短路径通常会向内弯曲。若外围与内部曲率不同，真实距离取决于路径下降到多深、在何处完成角向位移，而不仅是端点处的局部曲率。

因此，本实现提供：

- 真正考虑路径的数值测地求解器，作为精排与参考距离；
- 离线将该几何压缩到低维距离表，避免导航时反复求积分；
- 局部中点近似作为对照，用于检验“只看局部几何”是否足够。

## 四、Tier 2：混合／乘积流形原理与源码

### 4.1 几何定义

`ProductFactor` 定义三类坐标块：

```rust
Hyperbolic { dim, curvature }
Euclidean { dim }
Spherical { dim, curvature }
```

双曲因子的 `curvature=c` 表示实际曲率 `-c`；球面因子的正曲率参数为 `κ`。

`exact_product_distance_sq` 实现：

\[
d_{\mathrm{prod}}^2(x,y)=\sum_{j=1}^{B} d_j^2(x_j,y_j).
\]

其中：

- 双曲块使用标准 Poincaré 测地距离；
- 欧氏块使用坐标差平方和；
- 球面块使用 `acos(cosθ)^2 / κ`。

当前没有额外可学习块权重。返回的是**距离平方**，不是距离。

50k 实验将 256 维分成：

\[
\mathbb H_{-4}^{64}\times\mathbb H_{-0.25}^{64}\times
\mathbb R^{64}\times\mathbb S_{+1}^{64}.
\]

### 4.2 分块热编码

`ProductBlockSmIndex::build` 对每个块独立准备：

- 半径；
- 双曲边界因子；
- 径向深度；
- SM 重构参数；
- 可选锥编号及轴向分量；
- 两个位平面组成的 2-bit 方向／残差编码。

`BlockNodeMeta` 为每块保存 32B 元数据。节点的各块元数据和位平面合并在连续、64B 对齐的 slab 中；不是整个节点固定只有 32B 或 64B。

不同块的径向深度不同：

\[
\rho_H(r)=\frac{2}{\sqrt c}\operatorname{atanh}(\sqrt c\,r),
\quad \rho_E(r)=r,
\quad \rho_S=0.
\]

### 4.3 距离代理

`fast_block_dist_sq` 用估计的方向余弦 `ĉ` 重构各块距离。

欧氏块为：

\[
(r_q-r_v)^2+2r_qr_v(1-\hat c).
\]

双曲块在该表达式上乘共形因子并转换为双曲测地距离平方；球面块将 `ĉ` 转换为夹角，再除曲率。

`use_fast_surrogate` 控制部分超越函数的快速近似。**关闭快速代理并不等于用原始向量精确评分**：方向仍来自量化编码，只是距离转换更精细。

### 4.4 Compass 在这一层做什么

`quadri_prune_candidates` 是构图选边，不是查询时精排的下界过滤。

它把候选分为测地主干、局部等深角向环、角桥、向内／向外升降梯，并结合径向接近程度避免内部枢纽遮蔽外围邻居。

Tier 2 提供的几何信号包括：

- 各双曲块深度之和，用于向内／向外判断；
- 各块深度差的 L2 范数，用于径向比较；
- 各块 `1-cos_hat` 的平均，用于方向多样性。

这是实用启发式，不等于精确乘积测地拓扑。多个双曲块深度相加会丢失“哪个块更深”的信息，纯球面配置也没有径向升降信号。

### 4.5 查询与最终精排

`ProductBlockSmIndex::search` 大致执行：

1. 各块准备查询方向编码；
2. 按组合距离代理做束搜索；
3. 用原始查询方向与量化文档执行 Stage-0.5 非对称重评分；
4. 排序并截取精排预算；
5. 可选多块径向／锥角下界过滤；
6. 访问原始向量，用 `exact_product_distance_sq` 排序。

最终距离具有正确的乘积几何含义，但精排不能找回导航和预算截断已经漏掉的点。

### 4.6 对照方案

- `ProductBaselineIndex::EuclideanL2`：欧氏导航，乘积距离精排。
- `ProductBaselineIndex::ExactProduct`：使用真实乘积几何作为参考。
- `ProductSingleBallIndex`：按数据库最大整体范数统一缩放到单个 Poincaré 球，再使用单球 SM 导航，最终仍回到真实乘积距离精排。

单球方案用于暴露“把不同几何硬压到一个球”的排序失配。其缩放依据数据库确定，更大范数的查询也不能自动获得球内合法性保证。

## 五、Tier 3：径向变曲率的数学模型

### 5.1 度量与坐标

Tier 3 的度量为球对称翘曲形式：

\[
ds^2=dR^2+\phi(R)^2d\Omega^2.
\]

- `R`：从原点到点的测地半径；
- `dΩ²`：单位球面的角向度量；
- `φ(R)`：角向尺度函数。

`WarpedManifoldIndex` 将点保存成 `x=Ru`，故 `||x||₂=R`。这里的向量只是测地极坐标的一种参数存储形式，不能按普通欧氏 L2 理解其真实距离。

**迁移陷阱：原有 Poincaré 球欧氏半径 r 不等于 R。** 对常曲率球，转换为：

\[
R=\frac{2}{\sqrt c}\operatorname{atanh}(\sqrt c\,r),
\qquad
r=\frac{\tanh(\sqrt c R/2)}{\sqrt c}.
\]

改变几何剖面本身还会改变目标距离，坐标转换不能保证语义质量自动保留。

### 5.2 `WarpedProfile` 的三种剖面

#### 常负曲率校验

\[
\phi(R)=\frac{\sinh(\sqrt c R)}{\sqrt c}.
\]

用于检验数值测地求解器是否与标准双曲闭式距离一致。

#### `Softening { alpha }`

\[
\phi(R)=R+\alpha R^3,
\qquad
K_{\mathrm{rad}}(R)=-\frac{6\alpha}{1+\alpha R^2}.
\]

外围径向截面曲率趋近于零，中心相对更双曲。

#### `Steepening { alpha }`

\[
\phi(R)=R e^{\alpha R^2},
\qquad
K_{\mathrm{rad}}(R)=-(6\alpha+4\alpha^2R^2).
\]

越向外围径向截面曲率越负，角向尺度增长更快。

### 5.3 “一个位置的曲率”需要谨慎表述

`radial_curvature()` 实现的是：

\[
K_{\mathrm{rad}}=-\phi''/\phi.
\]

在维度足够高时，还存在切向截面曲率：

\[
K_{\mathrm{tan}}=\frac{1-(\phi')^2}{\phi^2}.
\]

只有特殊剖面下二者才相同。该实现不是一般意义上“每个点一个标量曲率便描述所有方向”的任意变曲率空间，而是预设的球对称翘曲几何。

参数应满足相应正性、有限性、单调性等条件；当前研究构造器未提供正式 `Index` 同等级别的完整输入验证，不能把任意 alpha 或 curvature 都当成合法配置。

## 六、Clairaut：真实距离如何求出来

### 6.1 旋转对称性将高维问题约化到二维

由于度量球对称，两点与原点张成的平面足以承载相应测地问题。输入只需：

```text
profile, Rq, Rv, cos(theta)
```

不需要对每次精排求一个高维边值问题。

对单位速度测地线，Clairaut 守恒量记为 L：

\[
L=\phi(R)^2\frac{d\theta}{ds}.
\]

结合单位速度约束：

\[
\left(\frac{dR}{ds}\right)^2+
\phi(R)^2\left(\frac{d\theta}{ds}\right)^2=1,
\]

得到：

\[
\frac{d\theta}{dR}=\frac{L}{\phi(R)\sqrt{\phi(R)^2-L^2}},
\qquad
\frac{ds}{dR}=\frac{\phi(R)}{\sqrt{\phi(R)^2-L^2}}.
\]

前者决定夹角，后者积分得到路径长度。

### 6.2 源码对应

- `clairaut_theta`：角度积分；
- `clairaut_length`：弧长积分；
- `clairaut_quad`：分段 Gauss–Legendre 数值求积；
- `solve_monotone`：Brent／保护二分求根；
- `clairaut_distance`：判断路径分支并组合结果。

求积使用预计算的 64 个节点及相应权重，径向变量变换帮助处理转折附近的积分行为。计算仍然是有限精度的数值近似，不是解析闭式精确计算。

### 6.3 两类路径

设 `Rlo=min(Rq,Rv)`、`Rhi=max(Rq,Rv)`。

**分支 A：径向单调。** 若角度较小，路径从较小半径单调走向较大半径。求解 L，使角度积分等于端点夹角，再积分弧长。

**分支 B：先向内折返。** 若角度较大，路径先下降到最近点 `R*`，再向外上升。在最近点满足 `L=φ(R*)`。源码对 `R*` 求根，再组合两段内侧弧长和外侧弧长。

特殊情况直接处理：

- 一点位于原点：距离是另一点半径；
- 同方向：`|Rq-Rv|`；
- 反方向：`Rq+Rv`。

它比“取端点平均曲率代入 Poincaré 公式”合理之处，就在于显式求出了路径经过的半径区间。

## 七、离线距离表：把复杂几何搬出导航热路径

### 7.1 存什么

`WarpedProxyTable::build` 预计算三维表：

\[
(R_q,R_v,u),\qquad u=(1-\cos\theta)/2.
\]

保存的是：

\[
E=d^2-(R_q-R_v)^2.
\]

径向差平方由运行时直接计算，表只保存非负角向超额。这样避免让径向项也承受插值误差，并自然利用两端半径交换的对称性。

### 7.2 表大小与查询切片

`WarpedTableSm` 默认 `nr=64`、`ns=65`：

- 完整表：`64×64×65×4=1,064,960 B`，约 1.016 MiB；
- 每查询切片：`64×65×4=16,640 B`，16.25 KiB。

`slice_for_query(Rq)` 沿查询半径做一次插值，得到文档半径 × 角度二维切片。热路径 `QueryWarpedSlice::eval` 再做双线性插值：

\[
\hat d^2=(R_q-R_v)^2+\operatorname{interp}(E).
\]

这将每个候选的积分和求根，替换成方向评分与少量表访问。

### 7.3 不能忽略的误差与成本

1. 表只在有限网格上采样，插值有误差，且不天然是保守上下界。
2. 表的 `r_max` 按构建数据最大半径加余量确定。超范围查询的表索引会被截断；径向项仍变化，但角向部分不是可靠外推。
3. 每查询会构造切片并分配空间，不等同于生产路径复用 scratch 的低分配实现。
4. 离线构表本身需要大量数值距离求解，应单列准备成本。
5. 约 16 KiB 切片适合 L1 的说法是布局意图，不代表整个查询工作集或多线程执行必然留在 L1。

## 八、方向压缩：SM 与残差锥怎样接入新几何

### 8.1 几何与方向编码相互解耦

`WarpedConeDict` 只处理单位方向，不依赖曲率剖面。也就是说，同一套方向估计可以交给不同几何距离转换器：常曲率公式、局部翘曲近似或离线表。

这是这套架构的关键复用点：**方向码不必理解整个流形，只需给出有用的夹角估计。**

### 8.2 残差分解

对于锥轴 a：

\[
u=\alpha a+\beta e,
\quad \beta=\sqrt{1-\alpha^2},
\quad e\perp a,\quad \|e\|=1.
\]

同锥查询与文档的余弦为：

\[
\langle u_q,u_v\rangle=
\alpha_q\alpha_v+\beta_q\beta_v\langle e_q,e_v\rangle.
\]

量化残差 e，而不是把大部分码字范围用在共同轴 a 上，可以更有效地区分紧簇内部的点。

### 8.3 研究原型的具体策略

`fit_and_encode` 最多抽样 4096 个方向、最多 64 个中心，进行四轮球面中心更新；支持度不足时返回 `None`，退回全局 SM。这里的阈值和字典策略不应等同于生产 `ResidualConeDict`。

查询对部分方向接近的锥准备残差状态，至少准备一个最佳锥；非活跃锥的束评分可能只保留轴向项。构图时某些跨锥评分也只保留轴间贡献。

因此误差不止来自“2-bit 量化”，还包括未激活锥残差项省略和跨锥近似。

`eval_stage05_cos` 用非对称方式减少查询量化误差，但数据库方向仍是量化状态，所以 Stage-0.5 仍不是原始向量精排。

## 九、Tier 3 的构图和查询调用链

### 9.1 构建链

```text
WarpedManifoldIndex::build_with_config
  ├─ 计算每个原始向量的测地半径 R
  ├─ 按 method 准备几何表
  ├─ 可选 WarpedConeDict::fit_and_encode
  ├─ 建立 Bq2Store
  ├─ 生成 WarpedBeamMeta / WarpedNodeMeta
  ├─ 定义 pair_dist、径向距离、角度损失
  └─ VarGraph::build_with_quadri
       ├─ 候选搜索与剪枝
       └─ 可达性修复
```

热头 `WarpedBeamMeta` 为 16B，保存 R、锥 alpha/beta 和锥编号；另有 24B 的 `WarpedNodeMeta` 保存 SM 参数及固定曲率基线所需标量。加上方向码、图、表、锥字典后才是实际热索引，不是每点仅 16B。

### 9.2 方法分派

| `Tier3Method` | 构图／导航使用的信号 | 最终精排 |
| --- | --- | --- |
| `EuclideanL2` | 普通坐标 L2 | Clairaut |
| `FixedConstantHyperbolicSm` | R 映射到固定曲率球，再用 SM 双曲代理 | Clairaut |
| `LocalWarpedFormulaSm` | 半径中点 φ 与方向码 | Clairaut |
| `WarpedTableSm` | 真实几何预校准表与方向码 | Clairaut |
| `ExactClairaut` | 原始方向与数值测地距离；大规模构图有查表捷径 | Clairaut |

局部近似公式为：

\[
\hat d^2=(R_q-R_v)^2+
2\phi((R_q+R_v)/2)^2(1-\hat c).
\]

它忽略真实测地线向内折返的细节，所以用作“没有全局测地校准”的对照，而非真距离公式。

### 9.3 QuadriPrune 不是总开关

源码实际条件为：启用 `use_compass`、不是欧氏基线、且没有拟合到残差锥时，才启用对应 QuadriPrune。

含锥簇时仍用普通 α-RNG 风格剪枝。其意图是：均匀／弥散数据通过等深角向环减少原点枢纽遮蔽，紧簇则优先依赖残差方向的区分力。

### 9.4 查询链

```text
WarpedManifoldIndex::search
  ├─ Rq = ||query||
  ├─ 准备 QueryDirState
  ├─ 若有表，生成 QueryWarpedSlice
  ├─ 定义 beam / stage05 / prune_lb / exact_dist
  └─ search_graph_with_rerank
       ├─ 多入口束搜索，维护最多 ef 个结果
       ├─ 对最终池执行 Stage-0.5
       ├─ 按代理距离排序
       ├─ 取 min(pool.len(), max(budget, top_k))
       ├─ 精排堆满后可用几何下界拒绝
       └─ Clairaut 精排，返回升序结果
```

`budget` 不是扩展节点预算，也不限制 Stage-0.5 次数。候选被下界拒绝后，不会从预算区间之外继续补取。

### 9.5 返回契约不同于正式 Index

研究 `SearchOutcome` 返回内部行号及距离，按距离升序；并给出精排数、拒绝数、扩展数。

- Tier 2 的目标评分是乘积距离平方。
- Tier 3 的最终目标评分是测地距离。
- 正式 `Index` 返回外部 `u64` ID 和相似度／负测地距离，通常按分数降序。

接入现有调用方必须明确转换，不可直接当成同一 API。

## 十、几何下界：为什么能够减少昂贵精排

### 10.1 径向下界

由 `ds²=dR²+...`，任意路径都有：

\[
d(q,v)\ge |R_q-R_v|.
\]

若该下界已大于当前第 k 名距离 B，可以跳过数值精排。

### 10.2 Dipping-Horizon 与角向下界

假设某条候选路径长度不超过 B，若它下降到半径 m，则径向行程至少：

\[
R_q+R_v-2m.
\]

所以：

\[
m\ge R_{\min}=\max(0,(R_q+R_v-B)/2).
\]

对单调递增的 φ，整条这样的路径上的角向尺度不小于 `φ(Rmin)`。再结合锥几何得到的余弦上界 `cos_max`，利用：

\[
\theta^2\ge 2(1-\cos\theta),
\]

构造源码中的距离下界：

\[
LB=\sqrt{(R_q-R_v)^2+
2(1-\cos_{\max})\phi(R_{\min})^2}.
\]

如果 `LB > B`，就与“路径长度不超过 B”的假设矛盾，可以拒绝该候选。

源码对径向和组合下界使用 `1e-4` 裕量。理想实数条件下的几何推导与有限精度代码的全域安全保证是两件事；固定裕量是否覆盖极端尺度、头部舍入和锥标量误差，仍需更系统测试。

这条下界不依赖插值表是保守的，不能把插值代理本身当成下界使用。

## 十一、实验设计与证据边界

### 11.1 50k 程序实际测什么

固定公共参数：

- N=50,000，D=256，Q=500，TopK=10；
- Tier 2：最大出度 16，构建 beam 64；
- Tier 3：最大出度 32，构建 beam 128；
- alpha=1.2；
- 搜索 `(ef,budget)`：`(32,32)`、`(64,64)`、`(128,64)`、`(128,128)`、`(256,128)`。

Tier 3 三种数据场景：

1. Softening，alpha=0.5，聚类；
2. Steepening，alpha=0.22，聚类；
3. Steepening，alpha=0.22，宽壳均匀。

输出召回、1T QPS、平均耗时、平均精排数、拒绝数、扩展数和热索引估计。预热使用前若干查询，并不是独立预热集；查询计时还包含结果命中统计等工作。因此结果应按该程序协议解释。

### 11.2 真值生成

`product_ground_truth` 使用乘积目标距离扫描。

`warped_ground_truth` 用表估计对候选排序以加速处理顺序，但随后遍历排序后的候选，除安全径向下界排除者外执行 Clairaut 求解，并非简单只取查表前几个点充当真值。

然而真值与精排共享 `clairaut_distance`，共同实现错误可能无法被召回对账发现。常曲率闭式测试提供了独立校验，但一般变曲率还需要独立求解器或更高精度参考。

### 11.3 Oracle 名称的真实边界

`ExactClairaut` 在 `n > 2000` 时构建 `128×128×65` 的高密度表用于构图加速。查询时才直接计算数值测地距离。

因此 50k 中的它应解释为“高精度几何参考方案”，不是严格全精确构图，也不是数学意义上的召回理论上界。其查询还将有效精排预算提升到 `max(ef,budget)`，与其他方案并非始终同精排工作量。

### 11.4 内存口径

`index_memory_bytes()` 统计签名、头部、部分锥／表数据和邻接边等逻辑载荷，不包含全部：

- 实际保留的原始 FP32 向量；
- 各 Vec 的容量及容器开销；
- 每查询 visited、堆、切片等工作区；
- 分配器和线程运行时开销。

50k×256D 原始向量本身约 48.83 MiB。研究索引实际保留这些向量用于精排，不能把打印的热索引 MiB 当成进程总内存，更不能把本次主线 SSD 功能自动归于研究索引。

## 十二、实现成熟度与风险判断

| 项目 | 当前状态 | 判断 |
| --- | --- | --- |
| 空间变曲率模型 | 预设球对称 φ(R) | 支持受限模型，不是任意局部曲率场 |
| 曲率学习 | 未实现优化器／目标函数／训练接口 | 不能称为自适应曲率训练 |
| 在线更新 | 研究索引无完整公开维护链 | 构图内部插入不等于在线数据增删 |
| 数据编码 | 需要符合目标几何的输入 | 不是普通 embedding 自动升级器 |
| 输入校验 | 部分 assert、分母截断、边界夹取 | 尚未达到正式 API 的防御完整度 |
| 数值距离 | 固定求积与求根 | 可作研究参考，仍须误差审计 |
| 查表导航 | 低维插值 | 有界域近似，不能泛化为任意查询外推 |
| 拓扑和方向代理 | 多级近似 | 精排只修正入池候选 |
| 内存管理 | 原始向量常驻、查询临时分配 | 与正式热冷分层路径不同 |
| 持久化／SSD | 未见研究索引接通正式快照链 | 本次其他存储更新不可直接套用 |
| 真实数据性能 | 本报告没有对应实测 | 不能套用 README 的常曲率百万级数据 |

此外，部分研究结构公开了几何字段。直接修改 factors/profile 并不是受支持的曲率更新协议：预计算元数据、码表、图和精排定义可能不再一致。正确的剖面变更至少需要重新校准距离表、重算相关元数据，并评估是否重建图。

## 十三、建议如何进一步验证原理与实现

以下为后续建议，不表示本次已经实现或运行。

1. **先验证数值几何。** 对两种剖面扫描半径、角度网格，重点测试原点、同向、反向、转折临界附近；以独立高精度积分或 ODE 边值解交叉核对。
2. **独立审计查表。** 分离“真实角度+插值表”和“量化角度+插值表”，统计排序翻转及近邻 margin，而不只看平均距离误差。
3. **隔离方向误差。** 比较原始方向、裸 SM、锥残差、非活跃锥和跨锥近似；不要把所有收益归给曲率表。
4. **固定图做表示对照。** 同图更换精确距离、查表和局部近似，区分拓扑质量与评分误差。
5. **精排下界逐项对账。** 保存被拒绝候选的真实距离，验证没有误剪；覆盖极端尺度和 FP32 头部舍入。
6. **匹配实验预算。** 相同度数、构建 beam、精排工作量，多种构图种子，独立调参／测试查询；单列建表和构图成本。
7. **真实数据先证明几何有效。** 明确 R、方向、块划分和 φ 的来源，先证明目标距离对应真实语义，再比较 ANN 性能。
8. **工程化最后进行。** 补配置校验、错误返回、持久化版本、增删协议、scratch 复用以及真实内存计量，再考虑接入正式 Index。

## 总结

这次更新最重要的不是“曲率参数可以变”，而是提出并实现了一条可运行的检索分解路线：

**预设更一般的几何 → 数值测地参考 → 低维距离表校准 → 低比特方向导航 → 非对称候选重评分 → 几何下界过滤 → 数值测地精排。**

Tier 2 证明这条思路可以组织多个不同几何块；Tier 3 将它推进到径向变曲率、没有常曲率闭式距离的情况。

目前最合适的定位是：具有明确几何结构和端到端检索链的研究原型。它还不是在线动态曲率模型，也不是现有生产 Index 的直接替代品。后续价值主要取决于数值／下界可靠性、真实嵌入的几何来源，以及在匹配实验预算下能否证明查表和方向压缩的实际收益。
