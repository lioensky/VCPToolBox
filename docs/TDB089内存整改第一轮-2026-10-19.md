# TDB 0.8.9 内存整改第一轮

## 状态与真实库基线

本轮完成构建工作区整改、启动阶段诊断及 Windows 正式模块构建；真实库内存验收仍未通过，不进入 LightMemo。

用户确认：彻底删除旧 PM2 进程并重新启动，未对话约 1.06 GB，首次对话约 1.08 GB。早先另有约 1.4 GB 的观测；观测阶段不同，不能混用。不能用上一个进程的分配器残留解释新进程的启动占用。

服务器提供的文件规模：
- 全局 Tag 正式派生资产：525,531,214 字节。
- 全局 Tag 私有 checkpoint 源：456,931,916 字节。
- SQL 主文件：2,376,568,832 字节；另有 WAL。
- 私有源文件按现有 3072D 平坦布局精确反推为 37,161 条向量，布局反推并非 SQL 实际计数。

文件长度不是驻留内存。当前 checkpoint 将活动实例换到私有 SQL 源映射，公开双槽文件承担持久化恢复职责；私有源可能仍为活动索引所需，不能在服务运行时直接删除。旧进程非正常退出也可能留下源文件，本轮没有新增批量清理。

## 已实施

### AGS 构建

- 原先全量原始 f32 表与全量归一化 f64 表重叠存活。
- 原件读取改为每批 128 条。
- 完整归一化 f64 行改为构建期私有文件，只读映射供并行计算借用。
- 堆中只保留 ID 到槽位的轻量表及有界批次向量，不保留全库高维向量数组。
- 保持 f64 归一化、点积、Gram、轴构造、ID 顺序及固定 128 项覆盖率归约。
- 全局候选向量、邻接数组在覆盖率阶段前释放；覆盖率完成后即解除工作区映射并删除文件。
- 私有工作区不是持久化资产，正常完成和返回错误时清理；进程强杀仍可能遗留文件。
- 映射长度随 Tag 总数增长，文件页仍可能进入工作集；本轮不承诺峰值 RSS 为固定常量。
- 需要系统临时目录有相应空间；写入或映射失败时返回错误，不覆盖已发布健康资产。

### RiverMemo 构建

- 不再读取所有 Tag 的高维向量表。
- 同一 SQL 读快照中，按文件读取最多 100 个参与共现的 Tag。
- 非语义边权模式不读取向量；超限文件沿用原有跳过规则。
- 保留原始逐边累加顺序，不先生成每文件矩阵再合并。
- 事实图、关系行、传输构建表、provenance 构建表、JSON 对象树及原始编码缓冲区在最后使用后及时释放。
- 活动查询图及其 provenance 功能保留，不通过删除图功能降低内存。
- 活动图紧凑化、流式 JSON 编解码、冷加载单飞及完整字节诊断尚未实施。

### 诊断

日志前缀为 `[KnowledgeBaseMemory]`，同时在既有内存诊断结果中返回最近最多 32 条阶段样本。

阶段包括：
- initialize:begin
- store:opened
- store:orphans-cleaned
- tags:restored
- memo:manifest-checked
- initialize:ready
- training:geometry-begin / geometry-end
- training:artifact-begin / artifact-end
- training:finished

字段包括进程 RSS、V8 堆、external、arrayBuffers、Tag 热内存估计与映射长度、已加载日记数量及其热内存与映射长度。

注意：
- external 已包含 arrayBuffers，不能相加。
- RSS 包含文件映射驻留页；映射长度不是 RSS。
- 样本是阶段边界值，不是连续峰值记录。
- 采样不会加载 Memo 图、读取全库向量或强制 GC。
- 进程统计包括其他插件和并发任务，阶段增量不自动证明单一模块独占该增量。

判读：先看 initialize:begin 是否已高，再看 SQL 打开、Tag 恢复、就绪后构建的增量。若没有 training 阶段，不能把该次启动占用归因为本轮发现的数学构建表。

- 孤儿清理后 RSS 273,735,680 字节。
- Tag 恢复后 RSS 948,809,728 字节，增长 675,074,048 字节。

- 该批日志没有训练阶段，因此第一轮数学工作区优化不是此次冷启动增长的解释。

已确认源码问题：全文件 CRC 直接扫描长期 mmap，触碰完整冷 f32 区；SQL 背书检查完成后又重新打开资产并再次扫描。
本次改为同一文件句柄通过 256 KiB 缓冲区进行完整 CRC 校验，并将校验且经 SQL 背书的同一映射直接移交索引，保持图与 SM 结构检查。没有跳过 CRC、修改格式或强制清空系统工作集。文件缓存仍可能占用系统内存，真实 RSS 降幅待上机验证；不宣称所有增量均由 CRC 解释。
