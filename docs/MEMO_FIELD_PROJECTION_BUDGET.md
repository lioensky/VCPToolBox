## 预算契约

默认预算为 256；接受任意非负整数，不要求是 SQL 批大小的倍数。
**K 现在约束双场选点的去重并集，包含全部核心骨架；不再是旧版每场 K、并集 2K。**
0 仅取消节点数量上限，质量目标与搜索工作限额仍有效，不恢复全正支撑投影。
核心骨架超过正预算时显式返回预算冲突，不静默裁剪路径或突破上限。

投影选点采用**种子流域内圈复用＋共享预算动态扩展**，实现见
[`memo_projection.rs`](../rust-vexus-lite/src/memo_projection.rs)：

1. 以本次 Spike 活跃河网为全局保留骨架。不重新聚类，不读取额外向量筛选质心。
2. 复用 hop-0 种子和记录的种子来源作为根线索；来源标记是代表来源，不是完整血缘。
   在正流量且存在真实 CSR 边的观测图上，按根 ID、邻接 ID 稳定排序构造多源 BFS 森林。
   每个流域内圈有完整的同流域路径；无法分配的骨架节点保守作为独立内圈保留。
3. 每个“流域 × 场”维护独立最短路前沿，从自身内圈边界零距离起步，
   边代价为负对数传输率，仅沿 0 < 权重 ≤ 1 的真实出边推进。
   这是内圈边界外的预算受限扩展，不是从单个球心出发的完整测地球。
4. 每个活动前沿前 8 个外圈接纳机会按轮转推进，完全不看收益；
   遍历已有内圈不消耗该保底。机会受剩余共享预算、质量目标、可达性和工作限额约束，
   不是每个流域无条件得到 8 个不同新向量的承诺。
5. 保底完成后每次最多推进 4 个外圈节点，再按“流域重要性平方根 × 近期新增归一化场质量 /
   (1 + 已接纳外圈数 / 8)”选择下一前沿。重要性为该流域内圈的观测能量之和；
   近期收益取本批每外圈机会新增质量与旧估计各半。两场收益按各自总质量归一化。
6. 一个节点全局只扣一次席位；两场独立接纳、独立累计质量，不能因为另一场读取过就自动参与本场投影。
   核心节点两场均保留。缺失向量不全图补位；因此路径保证针对选点支持集，不保证有效向量子集连通。
7. 搜索全局最多处理 8192 个出队状态、发现 8192 个流域—场—节点状态，
   扫描 65536 条边；即使 K 为 0 也有效。前沿重复改进产生的陈旧堆项由有界边扫描限制。
   达到工作上限时保留已选支持集并输出截断诊断，不伪装成完整半径覆盖。
8. 每个外圈入选节点均有同场已选前驱，不跳过低质量桥接点直取高峰；
   零质量与低于该场最大质量 1e-12 倍的数值尾流不用于扩展。
   核心可有多个分量，不强制跨主题连通，也不承诺保底席位一定跨过所有低谷。

各场达到原有效域实际累计质量时停止扩展，允许域外桥接计入预算和投影质量；
有效域本身不改写，候选路径解释仍消费原有效域。
两场都达到目标、前沿耗尽或工作限额耗尽时结束。
共享预算满后不再接纳新 ID，但可在剩余工作限额内补全已有 ID 的独立场资格。
交汇不放大质量，不修改 Sense、Ω 或查询河网形态评分。

配置文件中位于 KnowledgeBaseManager → riverMemo → effectiveSupport →
maxProjectionNodes。查询顶层 maxFieldProjectionNodes 可覆盖它；
查询 effectiveSupport.maxProjectionNodes 也可覆盖已有有效配置。
显式 0 不回退到默认值。负数、小数、非有限数及字符串拒绝执行。

## 读取与计算边界

AGS 全图 CSR 标量迭代不截断。先求质量场与有效域，再用节点索引导航到
需要投影的质量值，只补读请求级池内不存在的向量，每批最多 128 个 ID。

金字塔、融合、双场投影共用同一个请求级原始 FP32 向量池。
观测持有该池，候选读出克隆共享引用，不复制高维载荷。
候选曲线先批量读取标签关系、位置和名称，再对向量差集补查，
关联查询不再重复搬运已加载标签的向量 BLOB。

跨事务读出校验数据库代际；期间发生事实写入时明确返回过期观测错误，
不把旧池向量与新 SQL 行混用。

标量保留不由投影 K 决定。仅过滤低于该场最大质量 1e-12 倍的数值尾流，
两场有效域并集及河网节点强制保留，以尽量保留路径势能与域外尾流读出。
这仍是标量裁剪语义变化，需要随真实检索结果观察。

## 诊断

管线顶层分别输出双场标量求解、有效域处理、向量投影耗时。
双场诊断包含：

- 原始有效域节点数。
- 选中投影节点的去重数与成功取得有效向量的节点数。
- 本次投影实际新加载的有效向量数、差集请求数与 SQL 批次数。
- 各场选点支持诊断：核心数、选点数、域外数、缺失向量数及停止原因。
- 生长诊断：共享预算、核心与并集节点数、实际探索到的跨流域重叠节点数、处理状态数和扫描边数。
- 每个流域—场前沿的内圈数、外圈数、保底接纳数、新增并集节点数、距离半径、工作量和截断标志。
- 停止原因区分质量目标、共享预算、前沿耗尽、工作限额及空核心；空源场短路沿用默认空诊断。
  重叠仅统计实际接纳触达，不代表完整球交叠、Betti 数或实际流量汇聚。
- 各场选点质量比例，以及取得有效向量后的投影质量比例。
- 各场最终保留的标量条目数。

候选诊断区分标签关系 SQL、候选向量差集 SQL、查询河网补查 SQL。
内存统计增加请求向量节点数、FP32 载荷字节数，并纳入总载荷估算。

## 生命周期

观测是跨原生调用的请求上下文，不是跨请求查询结果缓存。
RAGDiary / LightMemo 上层结果缓存命中不需要使用旧观测。

独立查询在结束时释放；共享请求作用域在内部消费者全部结束后释放。
不能在第一个读出完成时删除仍被后续读出使用的句柄。
准备阶段产物校验失败也释放已创建句柄。

保留原有 TTL 作为原始 ABI 调用者漏释放时的既有兜底；
正常完成不等待 TTL，立即注销句柄并释放载荷。
本次没有把活跃请求改成十五秒硬过期，也没有新增后台定时清扫器。
原始 ABI 直接调用者仍需显式释放自己持有的句柄。

释放观测不清除常驻 CSR 图。已取得共享引用的原生消费者保持有效，
载荷在最后一份引用释放后回收。

## 验证范围

预算测试覆盖 0、1、64、128、193、256、512 和大于域大小的值，
验证独立选点、共享去重上限、缓存命中、缺失向量和配置校验。
流域专项测试覆盖弱主题保底、低质量桥接、交汇去重、内圈不占保底、
前沿耗尽后资源回收、来源标签不完整、确定性与无限节点预算下的搜索终止。
集成测试验证候选零补查与显式释放后的载荷归零。

这些是工程正确性验证，不替代大规模 K 选型与召回质量测试。
高维读取和投影受预算约束，不表示全图标量求解或整条查询变成 O(1)。

## CSR 传播热路径预计算

构建和冷加载均通过统一预处理派生邻接顺序与紧凑属性数组。
每行出边按权重降序排列，同权重按目标 Tag ID 升序，保证 Top-K 选择确定。
传播直接读取前 K 条正权重边，不再按每个脉冲状态分配邻居列表或重复排序。

节点锚增益按节点下标存储，缺省为 1.0；显式虫洞标记按 CSR 边游标存储。
运行时判定仍为“显式虫洞或边权乘目标锚增益达到本次请求阈值”。
没有将请求阈值固化进图资产，也没有新增每边 8 字节的张力数组。
新增常驻载荷约每节点 8 字节、每边 1 字节，不包含容器头。

预计算数组只在内存中派生，旧持久化资产冷加载同样可用，无需数据库格式迁移。
行内重排保持边权和目标配对，不改变图的数学传输关系；
浮点累加顺序可能产生末位差异，不承诺所有中间结果逐位一致。

新增测试覆盖乱序行、同权重目标排序、显式虫洞、请求阈值变化、
Top-K 选点和重复预处理幂等性。
