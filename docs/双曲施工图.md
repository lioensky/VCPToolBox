## 0. 全局工程红线与不变量（Codex 动手前必读！）

1. **SQLite 权威真源与冷热分离铁律（严禁驻留全量 FP32）**
   - `Pelorus` 独立版在 `NativeSpace` 中持有 `vectors: &[f32]` 全量切片；但 `vexus-lite` 在生产环境中通过 `TdbIndex::release_originals()`（`crates/vcp-tdb-index/src/engine.rs:99`）释放冷向量，精排时通过 `fill: FnMut(usize, &mut Vec<f32>) -> bool` 从 SQLite 读事务按需拉取。
   - **铁律**：移植 `HotSmStore`、`ResidualConeDict`、`PolarRouter` 与 `QuadriPrune` 时，**构图阶段必须全部适配为 `fill(slot, &mut buf)` 流式按需读取（允许固定 $O(1)$ 或小批量缓冲，严禁分配 `n * dim * 4` 字节的全库 `Vec<f32>`）**；查询阶段在进入末尾精排前必须**零冷向量读取**。
2. **禁止使用进程级全局 `Atomic` 静态配置污染生产实例**
   - `Pelorus` 为服务论文消融，在 `src/graph/hyperbolic/settings.rs:198-470` 中使用了 `HYPERBOLIC_STRATEGY`、`EXECUTION_BITS`、`STORAGE_BITS`、`RECALL_BITS` 等进程级全局原子变量，并将核心特性（`HotSmStore`、`ResidualConeDict`、`CJ-Gate`）包裹在 `#[cfg(feature = "research")]` 下。
   - **铁律**：在 `vcp-tdb-index` 中，上述特性**全部剥离 `#[cfg(feature = "research")]` 限制**，改为 `QuIVerConfig` / `QuIVerSearchConfig` / `TdbIndex` 实例级结构体字段，确保多线程多日记本并发查询 100% 线程安全且互不干扰。
3. **跨维度全兼容（65D / 384D / 768D / 1536D / 3072D）**
   - 严禁写死 768D 常量假设。`HotSmStore` 在 `dim <= 15616` 时均满足单页（4096B）容纳条件：
     - `768D`（12 chunks）：`64 + 12*16 = 256B` $\rightarrow$ `record_bytes = 256`（16 节点/页）；
     - `1536D`（24 chunks）：`64 + 24*16 = 448B` $\rightarrow$ `record_bytes = 512`（8 节点/页）；
     - `3072D`（48 chunks）：`64 + 48*16 = 832B` $\rightarrow$ `record_bytes = 1024`（4 节点/页）。
4. **快照版本演进与自动回退重建**
   - 任何涉及 `routing_snapshot.rs`（原 `VCPSM001`）或 `global_chunks.rs`（原 `VCPGCH01`）的二进制格式变更，必须升级 Magic（如 `VCPSM002`）并保留旧版解析或触发明确的格式升级错误，使 `index_lifecycle.rs` / `global_chunks.rs:219` 自动从 SQLite 权威表流式重建，严禁静默读脏数据。

## 2. 阶段二（Stage 2B）：4KiB 单页合表、流式切锥残差与 SM 构图

### 2.1 消除 `bq_store` + `default_sm` 双份位平面冗余，落地 `HotSmStore`
- **参考源**：`Pelorus/src/graph/hyperbolic/metadata.rs:10-120`（`PolarNodeMeta` 32B）、`Pelorus/src/graph/hyperbolic/storage.rs:6-175`（`HotSmHeader` 64B、`HotSmPage` 4096B、`HotSmStore`）。
- **目标文件**：`crates/vcp-tdb-index/src/index/quiver.rs`、`crates/vcp-tdb-index/src/index/quiver/corrected_sm/production.rs`、`crates/vcp-tdb-index/src/index/quiver/corrected_sm/routing_snapshot.rs`。
- **具体设计**：
  1. **统一节点热头部 `HotSmHeader`（严格 64B = 1 条 CPU 缓存行）**：
     - 前 32B 为 `PolarNodeMeta`（在纯余弦模式下：`radius = 1.0`、`boundary_factor = 1.0`、`depth = 0.0`、`sm_weak`、`sm_delta`、`sm_sigma`、`packed_strong_cone` 低 20 位存 `strong_ones` / 高 12 位存 `cone_id`，`cone_alpha` 存切锥主轴投影 $\alpha_v$ 或 `exact_scale`）；
     - 后 32B 为 `sketch256: [u64; 4]`。
  2. **4KiB 页对齐合表 `HotSmStore`**：
     - 紧跟在 64B `HotSmHeader` 之后存放 `pos: [u64; chunks]` 与 `strong: [u64; chunks]`；
     - `record_bytes = (64 + chunks * 16).next_power_of_two()`，确保只要 `record_bytes <= 4096`（支持到 `dim <= 15616`），任何节点的头行与全部位平面 **100% 落在同一个 4KiB OS 虚拟页内**，彻底消灭跨数组二次 DTLB 翻译与跨页断裂。
     - 保留 `prefetch_header(idx)`（仅预取前 64B，占 1 个硬件 LFB）与 `prefetch_body(idx)`（仅对通过早筛的节点预取后序位平面缓存行）。
  3. **单份位平面共享**：
     - 在 `QuIVer` 中，当 `HotSmStore` 就绪且无未合并增量时，`bq_store` 直接通过 `Arc<HotSmStore>` 借用节点的 `(pos_ptr, strong_ptr)`（参考 `Pelorus/src/quantization/store.rs:95-100, 396-430` 的 `reclaim_for_colocated` 与 `restore_interleaved`），**释放重复的 `interleaved` 与 `default_sm` 位平面数组**。

### 2.2 流式双遍 `ResidualConeDict`（零额外字节球面切锥正交残差）
- **参考源**：`Pelorus/src/graph/hyperbolic/residual.rs:10-355`、`Pelorus/src/graph/hyperbolic/scratch.rs:42-345`（`QueryConeCache`）。
- **数学原理（余弦球面与双曲流形通用）**：
  - 在高浓度聚簇区域（例如同一个技术专题或同一人物的多篇日记 Chunk），向量高度贴近簇中心轴 $\mu_c \in \mathbb{S}^{D-1}$（$\alpha_v = \langle u_v, \mu_c \rangle \ge 0.94$）。此时若对全局坐标 $u_v$ 做 2-bit 量化，几乎所有维度都被主轴方向主导，簇内微小的区分方向被量化噪声淹没。
  - 将 $u_v$ 做二次 Gram-Schmidt 双精度正交分解：
    $$u_v = \alpha_v \mu_c + \beta_v r_v, \qquad \beta_v = \sqrt{1 - \alpha_v^2} \le 0.341, \qquad \langle r_v, \mu_c \rangle = 0, \qquad \|r_v\|_2 = 1$$
  - 将节点原有的 2-bit `(pos, strong)` 槽位**原地覆写**为单位切向残差向量 $r_v$ 的 2-bit SM 签名，`PolarNodeMeta` 原地记录 `cone_id`（12-bit）、`cone_alpha = \alpha_v` 以及 $r_v$ 的 `(sm_weak, sm_delta, sm_sigma)` —— **每节点额外热内存开销严格为 0 字节**！
  - 查询时（`QueryConeCache`）：
    - 若查询与主轴对齐度 $|\alpha_{q,c}| \ge 0.20$（最多物化前 16 个切锥槽位）：用二次 Gram-Schmidt 计算查询的单位切向残差 $r_{q,c}$ 并编码为 2-bit SM / `AsymQuerySm`，重构余弦为：
      $$\hat{\cos}(u_q, u_v) = \alpha_{q,c}\alpha_v + \beta_{q,c}\beta_v \hat{\cos}_{\text{SM}}(r_{q,c}, r_v)$$
      量化误差标准差直接按 $\beta_{q,c}\beta_v$ 衰减一个数量级！
    - 若查询与主轴弱相关（未物化槽位）：利用正交恒等式 $\langle u_q, r_v \rangle = \beta_{q,c}\langle r_{q,c}, r_v \rangle$，直接用全局查询编码评估 $\hat{\cos}(u_q, r_v)$：
      $$\hat{\cos}(u_q, u_v) = \alpha_{q,c}\alpha_v + \beta_v \hat{\cos}_{\text{SM}}(u_q, r_v)$$
- **适配 Vexus-Lite 冷热分离的流式构建改造（重点！）**：
  - `Pelorus/src/graph/hyperbolic/residual.rs:94` 的 `ResidualConeDict::build` 依赖内存中的 `space.vector(slot)`。在 `vcp-tdb-index` 的 `rebuild_from_cold_slots(ids, slots, config, &mut fill)`（`production.rs:116`）中，改为**流式双遍扫描**：
    1. **Pass 1（采样与主轴学习 + 全局初始签名）**：遍历 `slots` 调用 `fill(slot, &mut buf)`，一边生成初始 `Bq2Store` 与 `PolarNodeMeta`，一边按确定性步长抽取最多 `min(n, 4096)` 个代表样本（3072D 下 4096 个样本仅占 48MB 临时内存，構图结束即释放）。在样本上运行球面 Leader 初筛（$\tau_{\text{leader}} = 0.91$）+ 2 轮球面均值精炼（$\alpha_{\min} = 0.94$，簇均纯度 $\ge 0.955$，支持度 $\ge \text{min\_support}$），提取最多 `MAX_RESIDUAL_CONES = 512` 条单位主轴 $\mu_c$。
       - *注*：在纯余弦模式下，移除 `p90_depth < MIN_CONFORMAL_DEPTH_P90` 的双曲深度门槛，仅凭球面簇支持度与纯度门控自动决定是否激活（均匀分布下自动退化为 `None`，零开销）。
    2. **Pass 2（流式正交残差重编码 + 构图）**：先基于全局 SM 校准余弦（及已提取主轴）完成并行构图；构图冻结后，对命中主轴的节点流式调用 `fill` 执行二次 Gram-Schmidt 正交化，将 `r_v` 的 2-bit SM 签名与 `PolarNodeMeta` 原地写入 `HotSmStore`。

### 2.3 用 SM 校准距离 + `wire_unreachable_native_nodes` 升级余弦构图与查询

#### (1) Tag 节点的无量纲测地深度 $d_{\text{tag}}(i)$（数据源于 `memo_geometry.rs` 与 `memo_artifact_builder.rs`）

  $$s_i = 1 - \sqrt{\operatorname{clamp}_{[0,1]}\!\left(\frac{\text{inbound}_i}{\max_j \text{inbound}_j}\right)}$$

### 5.1 预计算全局 Tag 双曲场的四维物理结构（零全量 FP32 常驻）

参考 `Pelorus/src/var_curvature.rs`（commit `98136b2`，Tier 3 `WarpedManifoldIndex` & `WarpedProxyTable`），结合 Vexus-Lite 冷热分离铁律，定义预计算场 $\mathcal{H}_{\text{AGS}}$ 的四个核心正交组件：

#### 组件 A：AGS 各向异性底座正交剥离球面 $\mathbb{S}_{\perp}^{D-1}$（破解 L0/L1 度规分裂与 72° 宽张角陷阱！）
- **病根复盘**：昨日试验表明，原始 3072D Tag 向量含公共均值 $\bar{u}$（$\|\bar{u}\|_2 \approx 0.41$），导致 L0 无关词余弦达 $0.45\sim0.49$，而 L1 经 `memo_nnls` 剥离主成分后均值对齐归零、真近邻余弦跌至 $\sim 0.265$。若在查询期用动态裁剪锥硬拍扁背景，会直接撕裂构图与查询的度规一致性（Holdout L0 召回暴跌至 32%）。
- **流形底座中心化与角向有效变换（构图、查表、精排 100% 同构）**：
  1. **读取/流式合成全局均值 $\bar{u} \in \mathbb{R}^D$**（直接复用 `memo_geometry.rs:863` 的 `mean` 或单遍流式统计，仅占 `24 KB`）。
  2. **部分底座剥离（Partial Mean Subtraction，$\beta_{\text{mean}} \in [0, 1]$，实验扫描 $\{0.0, 0.70, 1.0\}$）**：
     对任意 Tag 原向量 $v_i$ 或查询/残差向量 $q^{(\ell)}$，定义去底座单位方向：
     $\tilde{u}(x) = \frac{u(x) - \beta_{\text{mean}} \langle u(x), \hat{\mu} \rangle \hat{\mu}}{\big\|u(x) - \beta_{\text{mean}} \langle u(x), \hat{\mu} \rangle \hat{\mu}\big\|_2} \in \mathbb{S}^{D-1}, \qquad \hat{\mu} = \frac{\bar{u}}{\|\bar{u}\|_2}$
     - 当 L0 原始查询进入时，其自带的 $\sim 0.41$ 公共底座被自动正交剥离；

### 物理机制诊断：$\phi(0)=0$ 圆锥奇点下的“高维大张角折返退化”
1. **瓶颈首先在精确几何目标（Target Bias），其次才是 L1 ANN 近似损失**：

2. **为什么 `Softening` ($\phi(R) = R + \alpha R^3$) 没能阻止内壳垄断？**
   - 在 3072D 下，即使经过均值剥离，L0 真近邻余弦也仅 $\sim 0.55$（欧氏张角 $\theta = \arccos(0.55) \approx 0.99\text{ rad} \approx 57^\circ$），L1 真近邻余弦仅 $\sim 0.25$（$\theta \approx 1.32\text{ rad} \approx 75^\circ$）。

   - 结果：同外壳好词（$R_v = 1.3, \theta = 57^\circ$）因为比内壳词（$R_v = 0.45, \theta = 70^\circ$）多了一整段“从 0.45 爬到 1.30”的径向路程（$+0.85$），在精确 Clairaut 距离下无条件输给内壳高频词！
