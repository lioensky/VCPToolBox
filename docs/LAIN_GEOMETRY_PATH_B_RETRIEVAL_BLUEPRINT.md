## B1：只换坐标，不换曝光算子
raw 与冻结均值轴下原生 transform_into(beta=0.7) 的 z 配对；查询与点同变换。核对实际配置及原生 FP32 输出，不能用新估均值代替冻结轴。各空间独立构建每轴排序样本、切点、IQR/8 半窗、桶内 ECDF 和码流。沿用 A1/A2 的闭窗、重复切点右插入、空桶零票、FP64 归约及稳定 ID 升序决平局。
- 主交付为 2-bit 等权量化直出；3-bit 单列。两臂采用相同位宽和候选预算，不声称总索引等大。
- 分列全库 FP32 坐标硬窗排序、量化直出、候选内硬窗重排，明确输入池与输出 K。只重排同一批 K 个点不会改变 Hit@K；若做 128→64 须另标池预算。
- raw 直出可复用已验证的 A2 文件（slot → bits 2/3 → 128 个小端 uint64），复核清单、哈希、长度与 ID。z 重建并校验码流，不复用 raw 桶号。
