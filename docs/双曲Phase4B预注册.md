# Phase 4B 预注册与边界约定

注册时间：2026-11-17，北京时间；开发扫描及第三版验证读出之前。
基线提交：10c1d253。源SQLite只读，所有私有结果独占新建，禁用AVX-512。

## 几何

- 定义非负半径域与球面方向的内蕴长度度量。喉部正值时，零半径处是有边界球面，不再将全部方向识别为原点。
- 翘曲函数为角尺度乘以“喉部常数加软化剖面”。吸收角尺度后，求解器始终使用原球面夹角，不能对超过半周的有效角再次取余弦。
- 路径包括径向单调、内部折返和边界滑行三类。边界滑行距离为两条相切段及剩余边界弧之和。
- 零喉部且角尺度不为1时为度量锥，原点一般不是光滑黎曼点；不宣传为处处光滑流形。
- 原有零喉部单位尺度的光滑原点不是圆锥奇点；内壳排名偏置待数据检验，不将“全部大张角必经原点”作为前提。
- 本轮固定恒等角映射，不使用旧非度量角校准。

## 开发矩阵

- 半径下限0.35，上限0.65、0.90、1.20。
- 喉部0、0.8、1.5；软化0.15、0.35；均值剥离0.5、0.7、1.0。
- 角尺度0.5、1.0、2.0，共162组，另加现役余弦与首轮中心参数参考。
- 开发只读取原12开发与旧32留出，不读取上一轮32新留出的向量或评价。
- 使用冻结4096节点库，宽度128、访问256、展开128、每层唯一精排冷读上限64、三层及0.03原空间解释接受门槛不变。
- 默认以方向地标选种运行自身闭环。另在相同查询、图和排除集上运行内壳入口对照，结果不回流实际轨迹；对照冷读单列，不冒充单次生产成本。
- 方向地标来自最多512个确定性全壳样本的热码最远点选择，最多64个，和内壳8入口合并后按实际访问预算截断。
- 首轮原选种其实已有64个全壳等距样本，不是只有8内壳入口；内壳单独组是新增消融，不作为首轮代码现状。
- 真值全扫只用于评价，记录四个阶段命中及最终召回、同层精确候选原空间解释能量、平均原余弦、半径与入度分位数。
- 不把非对称前64命中率与最终召回预先设为相等，而是检验冷读、精排与下界后的一致性。

## 锁定与终验

开发门槛按44查询L0均值：返回入度分位数小于0.85，精确候选和ANN解释能量分别不低于同次现役余弦的98%。
符合者按全部开发查询终局解释能量排序，保留最多3组，参数顺序作确定性平局规则。
若不足2组，不降低门槛、不偷偷补失败组冒充达标；可锁定失败诊断对照，但必须明示未过开发门禁。

锁定文件独占新建，保存完整参数、开发来源及内容哈希。只有锁定之后才允许新建种子20261118的32查询终验集；显式排除前76个查询ID。
