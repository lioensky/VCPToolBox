## 8. 进阶技能————使用html代码绘制图标和壁纸。
将完整 HTML 源码或 SVG 源码渲染为图片，适合绘制图标、Logo、信息图、卡片和壁纸，也可以基于已有图片用 HTML/CSS/SVG 添加滤镜、遮罩、文字、边框、渐变和光效。服务器直接通过 CDP 连接已有 VCP 托管 Chrome，不经过 ChromeBridge。

参数：
- command（可选）：固定为 RenderImage；省略时也按 RenderImage 执行。
- html（与 svg 二选一）：完整 HTML 文档或 HTML 片段。支持 HTML/CSS/内联 SVG。
- svg（与 html 二选一）：完整 SVG 源码。
- sourceImage（可选，兼容 image、image_url、source_image）：需要用代码编辑或添加特效的底图。支持 data:image Data URI、http/https 图片 URL 和 file:// 图片。提供后，html/svg 源码中必须使用 {{SOURCE_IMAGE}} 作为图片地址，例如 `<img src="{{SOURCE_IMAGE}}">`。file:// 图片会在 Node.js 侧读取并转为 Data URI，浏览器不会获得任意本地文件访问能力；http/https 只放行该素材的精确 URL。
- width（必需）：输出宽度，整数，64-4096。
- height（必需）：输出高度，整数，64-4096。
- format（可选）：png、jpg 或 webp。透明图标推荐 png；壁纸推荐 jpg。transparent=true 且 format=jpg 时会自动改为 png，因为 JPEG 不支持透明通道。
- transparent（可选）：是否保留透明背景，默认 false。设为 true 时仅令 HTML 页面根画布透明，不会删除源码中元素自己绘制的背景。
- background（可选）：非透明输出的底色，默认 #ffffff。只填充源码未绘制的透明区域，不覆盖 HTML 自带背景。
- quality（可选）：JPG/WebP 质量，1-100，默认 90。
- showBase64（可选）：是否额外内联图片 Data URI，默认 false；一般应使用返回的图床 URL。
- allowJavaScript（可选）：是否允许 HTML 中的 JavaScript，默认 false。CSS/SVG 特效不需要开启；Canvas 脚本处理时才显式设为 true。
- waitMs（可选）：截图前额外等待 0-10000 毫秒，默认 0。
- timeoutMs（可选）：单步超时 1000-120000 毫秒，默认 45000。
- fileName（可选）：输出文件名主体，插件会清理危险字符并自动追加唯一尾缀及扩展名。

安全限制：除显式 sourceImage 外，其他 HTTP/HTTPS、file: 等资源请求全部阻断，只允许源码内联资源、data: 和 blob:。sourceImage 本地或内联图片最大 25MB，HTML/SVG 源码最大 2MB，单次最多 16 张。
