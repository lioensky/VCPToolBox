## 一、配置字段

用户在配置表页填写以下信息：

| 字段 | 类型 | 默认值 |
|------|------|--------|
| 安装路径 | 文本输入 | 当前目录 |
| GitHub 镜像 | 下拉选择 | 优选镜像站（由镜像测试生成） |
| npm 镜像 | 下拉选择 | 官方源 |
| pip 镜像 | 下拉选择 | 官方源 |
| API 端点 URL | 文本输入 | http://localhost:3000/v1 |
| API 密钥 | 密码输入（掩码） | 空 |
| 管理面板密码 | 密码输入 | 随机生成 |
| 工具授权码 | 密码输入 | 随机生成 |
| 服务端口 | 数字输入 | 6005 |

## 二、交互设计

- Tab 键切换字段
- Enter 键确认（VCPToolBox 必须选中）
- Esc 键返回上一页面

## 三、MSVC 必需组件（v18.11 起）

- MSVC Build Tools 在组件选择页显示为**必需组件**
- UI 锁定不可取消
- 默认勾选
- 未检测到就强制安装
