## 九、日志系统

- **分段日志**：按安装阶段分段存储（01_prepare.log → 09_scripts.log）
- **全量日志**：安装结束后合并所有分段日志为 00_full_log.txt
- **防重复**：安装过程中只写分段日志，不写全量日志，消除双写问题
- **StageGuard**：统一管理阶段边界（START/END 标记），日志写入自动路由
- **write_prepare_log**：TUI/Headless 统一调用，内容完全一致

## 十、headless 模式完善

- MSYS2 路径自动转换
- 无 TUI 干扰，所有日志输出到 stdout + Install_log/
- **headless 测试配置**（精简）：VCPToolBox + VCPChat（不含 NewAPI/VCPDistributedServer/VCPBackUpDEV 以加快测试）

```

**键位**：
- PgDn: 下一页

**底部导航条**：
```

**快捷脚本**：show-tui-pages.bat（双击运行）
