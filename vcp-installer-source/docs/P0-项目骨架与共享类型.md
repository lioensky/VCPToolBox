## 一、TUI 页面骨架

应用包含 7 个页面，状态机定义在 app.rs：

```rust
pub enum AppState {
    Welcome,          // 欢迎页（红色网络警告）
    EnvCheck,         // 环境检测页（止损逻辑 + 日志前移）
    ComponentSelect,  // 组件选择页（安装方式选择 + MSVC 必需组件）
    ConfigForm,       // 配置表页
    Installing,       // 安装进度页（11步简化 + 5段布局）
    Complete,         // 完成页（运行时环境 + 已安装应用）
    ConfigGuide,      // 第七页 VCP 使用引导（2026-08-28 新增）
}
```

### 翻页链路（真实安装流程）

- 安装完成页（Complete）按 Enter → 第七页（ConfigGuide）
- 第七页（ConfigGuide）按 Q/Enter/Esc 退出
- 翻页链路：Complete → next → ConfigGuide（终点），ConfigGuide → prev → Complete

### --ui-preview 预览模式

- main.rs::run_ui_preview() 复用 6 个 render 函数 + mock 数据
- PgDn/PgUp 翻页，Q 退出
- 底部导航条：`[UI Preview] {页名} (idx/total)`
- 预览 7 页（page_names/page_states 数组各 7 项）

## 二、核心类型定义（app.rs）

### 运行时组件

```rust
pub enum RuntimeComponent {
    Git,
    NodeJs,
    Python,
    MSVCBuildTools,  // 必需运行时组件（npm 原生模块编译依赖），默认勾选
}
```

### is_required 逻辑

```rust
pub fn is_required(&self) -> bool {
    matches!(self, Self::VCPToolBox | Self::VCPChat | Self::MSVCBuildTools)
}
```

**v18.11 起 MSVC 改为必需**：
- UI 锁定不可取消
- 默认勾选
- 未检测到就强制安装

### 应用组件

```rust
pub enum Component {
    VCPToolBox,           // 必选
    VCPChat,              // 推荐
    NewAPI,               // 推荐
    VCPBackUpDEV,         // 可选
    VCPDistributedServer, // 可选
    MSVCBuildTools,       // 必需运行时组件
}
```

### 安装方式

```rust
pub enum InstallMethod {
    GitClone,
    Tarball,
}
```

### 安装结果

```rust
pub struct InstallResult {
    pub success: bool,
    pub installed_runtimes: Vec<RuntimeComponent>,
    pub installed_components: Vec<Component>,
    pub install_path: PathBuf,
    pub backend_start_script: Option<PathBuf>,
    pub frontend_start_script: Option<PathBuf>,
    pub errors: Vec<String>,
}
```

### 安装配置

```rust
pub struct InstallConfig {
    pub install_path: String,
    pub components: Vec<Component>,
    pub mirror: GithubMirror,
    pub npm_mirror: NpmMirrorChoice,
    pub pip_mirror: PipMirrorChoice,
    pub api_endpoint: String,
    pub api_key: String,
    pub admin_password: String,
    pub tool_auth_code: String,
    pub service_port: u16,
}
```

**headless 默认配置**（main.rs）：
```rust
// headless 模式：VCPToolBox + VCPChat（不含 NewAPI/VCPDistributedServer/VCPBackUpDEV 以加快测试）
// MSVC Build Tools 由 Stage::Msvc 阶段独立安装，不依赖组件选择
components: vec![Component::VCPToolBox, Component::VCPChat]
```

### 镜像选择（动态化）

GithubMirror/NpmMirrorChoice/PipMirrorChoice 基于 MirrorConfig，支持索引引用镜像站列表，不再硬编码单一镜像。

### 事件通道

- EnvCheckEvent：环境检测后台任务 → TUI
- ProgressEvent：安装后台任务 → TUI

## 三、TUI 模块文件

| 文件 | 职责 |
