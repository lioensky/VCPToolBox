## 一、流式下载

downloader.rs 使用 reqwest 流式下载，支持实时进度回报 + 断点续传：

```rust
pub async fn download_file(url: &str, dest: &Path, progress_tx: &mpsc::Sender<ProgressEvent>) -> Result<()>;
pub async fn download_with_retry(url: &str, dest: &Path, max_retries: u32, ...) -> Result<()>;
```

**关键特性**：
- 流式写入，不占满内存
- 通过 mpsc::Sender<ProgressEvent> 实时上报进度
- 支持重试（网络波动时自动重试）
- **断点续传**：底层 download_once() 支持 RANGE 头 + PARTIAL_CONTENT + RANGE_NOT_SATISFIABLE 处理

## 五、多镜像降级下载（v18.12 新增）

### 5.1 download_with_mirror_fallback

```rust
pub async fn download_with_mirror_fallback(...) -> Result<()>;
// 为 GitHub 资产实现的多镜像降级下载
// 候选顺序：用户镜像 → preferred_github（去重）→ GitHub 直连兜底
```

### 5.2 download_with_preferred_fallback（运行时下载韧性）

```rust
pub async fn download_with_preferred_fallback(
    config: &MirrorConfig,
    github_mirror: &str,
    mirror_config: &MirrorConfig,
    progress_tx: &mpsc::Sender<ProgressEvent>,
    max_retries_per_mirror: u32,
) -> Result<()>;
```

**候选顺序**：
1. 用户所选镜像
2. preferred_github（去重）
3. GitHub 直连兜底

**重试策略**：
- 每镜像 max_retries_per_mirror=2 次
- 重试时自动 resume=true（续传）

**应用场景**：
- PortableGit（portable_git.rs）
- Python（portable_python.rs）
- NewAPI（config_gen.rs::download_newapi）
- **Node.js 不走此函数**（非 GitHub 资源，用独立的双源循环）

## 八、断点续传机制

**底层支持**（downloader.rs::download_once）：
- 发送 RANGE 头请求续传
- 处理 RANGE_NOT_SATISFIABLE（服务器不支持续传 → 从头重下）
- 处理 PARTIAL_CONTENT（追加写入）

**应用层**：
- 四运行时（PortableGit/Node/Python/NewAPI）resume:true
- 重试时自动续传
- 断网中断后不必从头重下几百 MB 文件
