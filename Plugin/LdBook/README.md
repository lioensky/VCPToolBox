# 📚 LdBook - VCPToolBox 电子图书检索与下载插件

本插件是基于原生 Go 编写的高性能公有领域电子图书检索及高速断点下载引擎，专为 VCPToolBox（Virtual Cherry-Var Protocol）深度定制适配。

## ✨ 核心特性

- 🚀 **多镜像全异步竞速检索**：多路镜像并发检索，毫秒级汇流。一旦目标格式满足，立即触发短路取消，终止其余冗余请求。
- 📖 **智能概念图书聚合（Title-Level Aggregation）**：自动合并同一书名的不同格式版本，每一行代表一本唯一的实体图书，自动去重聚合该书支持的全部格式（如 `[epub, pdf, mobi]`）。
- 🎯 **一步直达直接下载（`DownloadBook`）**：无需先看列表再挑 MD5，直接输入书名与格式，算法自动加权锁定最佳目标并下载落盘。
- ⚡ **分段并发与断点续传（抗抖动设计）**：基于 Range 分块多协程并发写入，连接中断或网络抖动时自动自愈断点续传，先写 `.part` 临时文件，下载完毕原子替换，杜绝损坏文件。
- 🛡️ **严格格式防御机制**：如果请求的格式该书不存在，明确给出可用格式集合并拒绝下载，绝不“挂羊头卖狗肉”。
- 🌐 **镜像站动态可配置（抗倒闭设计）**：所有搜索镜像与下载网关均可通过 `config.env` 自由增删改查。

## 🛠️ 指令清单

### 1. `SearchBooks`（图书目录与格式探索）
- **功能**：检索图书，返回唯一的独立书名、作者、以及该书所支持的全部可用格式列表。
- **参数**：
  - `query` (string, 必填)：书名、作者或 ISBN。
  - `format` (string, 可选)：格式过滤（如 `epub`, `pdf`）。
  - `searchField` (string, 可选)：匹配字段，`"def"`（模糊搜索，默认）、`"title"`（书名）、`"author"`（作者）、`"isbn"`（国际标准书号）。
  - `count` (number, 可选)：最大返回数量（默认 10）。

### 2. `DownloadBook`（直接凭书名一键下载，最常用）
- **功能**：一步到位凭书名和格式直接下载图书，自动匹配最高相关度的单本并下载落盘。
- **参数**：
  - `title` (string, 必填)：书籍名称（例如 `"三体 Ⅲ"`、`"Effective Java"`）。
  - `format` (string, 可选)：目标格式（`"epub"`、`"pdf"`、`"mobi"` 等，默认 `"epub"`）。
  - `searchField` (string, 可选)：匹配字段，`"title"`（默认）、`"def"`、`"author"`、`"isbn"`。
  - `outputDir` (string, 可选)：保存目录（默认 `"./downloads"`）。

### 3. `DownloadByMD5`（底层精准断点下载）
- **功能**：已知具体文件 32 位 MD5 时的直接高速断点下载。
- **参数**：
  - `md5` (string, 必填)：32位哈希。
  - `title` (string, 可选)：书籍名称。
  - `format` (string, 可选)：预期格式。
  - `outputDir` (string, 可选)：保存目录。
