# FileChangeApproval

`FileChangeApproval` 是一个后台 service 插件，为文件类插件提供统一的变更提案能力。

当前阶段接入 `DailyNote`，支持：

- 保存变更前和预期变更后的快照；
- 文本 Diff；
- 用户审批或自动批准；
- 审批前文件版本校验；
- 待审批提案持久化；
- 已结束提案的归档与恢复；
- 已结束提案及其快照的删除；
- 管理面板 API。

运行时数据库和快照位于插件自己的 `state/` 目录，不属于源码。

只有 `applied`、`rejected`、`failed` 和 `stale` 状态的提案允许归档或删除。
归档只会从默认列表中隐藏记录，不会删除快照；归档记录可以在管理面板中恢复。
待审批、批准执行中或正在执行的提案不会被删除，以避免绕过审批或干扰正在进行的文件操作。

当插件被禁用或加载失败时，接入插件会按兼容模式回退到原有直接文件操作。
