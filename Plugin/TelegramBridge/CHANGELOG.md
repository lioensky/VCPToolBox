# Changelog

## 0.1.0-beta.1

- Initial public Telegram transport: authorized private chats, Agent switching, bounded conversation history and streamed replies.
- Native inbound media, bounded local/public-HTTPS attachments, albums and image follow-up context.
- Correlated tool approvals and generic asynchronous results through Host Integration v1.
- Durable update/delivery ledgers, restart recovery, cancellation and conservative handling of uncertain effects.
- Disabled by default. Full media staging requires Linux/Docker. No user configuration, credentials, runtime data or local acceptance history is distributed.
