# VCPTimeLine

为 Agent 生成按月时间线、月度一句话摘要，并按当前对话召回相关月份。

## 三种占位符

| 入口 | 输出 |
| --- | --- |
| [VCPTimeLine 合并入口](VCPTimeLine.js:7)（写法：[[VCPTimeLine::小克]]） | 所有月度摘要＋相关月份全文，保留旧版行为，无需迁移 |
| [VCPTimeLineSummary 总览入口](VCPTimeLine.js:7)（写法：[[VCPTimeLineSummary::小克]]） | 仅所有月度一句话摘要，按月份排序；不生成查询向量、不读取月份全文、不执行检索 |
| [VCPTimeLineRecall 召回入口](VCPTimeLine.js:7)（写法：[[VCPTimeLineRecall::小克:3:0.5]]） | 仅相关月份全文，无命中或检索不可用时输出为空 |

合并入口和召回入口都支持以下参数形式：

- 无参数：使用面板配置的默认最大展开月份数和最低阈值。
- 单个整数，例如 :3：指定最大展开月份数。
- 单个小数，例如 :0.5：指定最低阈值。
- 两个参数，例如 :3:0.5：依次指定最大展开月份数和最低阈值。

阈值有效范围为 0.01–0.99；参数解析与旧版保持一致。总览入口不需要检索参数。

## 推荐放置方式

将总览入口放在系统提示词的稳定区域，将召回入口放在靠近上下文末尾的系统通知中。例如：

- 系统提示词内放置 [[VCPTimeLineSummary::小克]]。
- 本轮通知正文为“[系统通知]”换行后接 [[VCPTimeLineRecall::小克:3:0.5]]。

三个入口都在声明原位置替换，插件不会自动搬动消息。
缓存收益取决于最终请求中的实际顺序：动态召回应尽量靠后，避免改变稳定前缀。
总览仅在摘要数据变化时变化，并非永远不变。

已有用户继续使用 [[VCPTimeLine::小克]] 即可；旧入口不带参数也会使用默认设置执行召回。
通常选择“旧合并入口”或“两个拆分入口”，不建议混用，否则会重复输出。

## 可信声明与去重

沿用现有可信规则：系统角色消息，或正文以“[系统”开头的用户角色消息。
三个入口分别接受整个上下文中各自第一个可信声明，其余重复声明和不可信位置的占位符被清除。
总览不会挡住后续通知中的召回声明；各入口可独立使用，也可指定不同 Agent。
替换为单次处理，不递归展开注入内容中的占位符。

这是按角色与文本前缀判断的现有约定，不代表新增来源认证。
禁用插件时，消息与占位符保持原样。

## 数据与管理

通过 Vue 管理面板的 Agent TimeLine 管理页面生成、编辑月度时间线和一句话摘要。
召回复用现有 ContextBridge 查询与知识库向量索引，不重新向量化月份文档。
本次入口拆分不改变时间线生成、摘要存储或管理接口。
