# OpenHerPersona Observer

纯观测插件：只测量历史中最新的 Agent 回复，不修改提示词、不注入表达指令，也不把用户情绪直接当作 Agent 情绪。不提供独立向量数据库、不写长期记忆、不主动发送消息。

## 数据与内存边界

- 从历史中选取最新 assistant 回复，清洗后最多使用 4000 字符；队列不保存完整聊天历史或原始长回复。
- 消息向量只用于当前评分，不逐条写入数据库。
- 接入 ContextBridge 时复用共享缓存，不额外保留本地消息向量，不修改共享缓存的淘汰规则。
- 无 ContextBridge 时才使用有条数、字节预算和有效期的本地兜底缓存。
- 每个 Agent 保留独立的固定锚点向量；当前轴状态、基线和最近观测覆盖更新。
- 审计历史追加写入，后台按年龄和条数分批清理。当前 Agent 状态不会自动删除。
- 任务统一调度：同 Agent 串行、全局并发受限，待处理任务受条数和文本字节预算限制；重复指纹合并，空闲队列释放。
- 超时不能取消不支持取消的共享底层请求。未结束请求仍占名额，达到上限后新向量请求直接跳过，避免持续积压。若全部请求永久卡住，需恢复共享服务或重启进程。
- 字节预算不包括对象元数据、共享服务内存及网络库内部缓冲，不是整个进程的硬内存上限。

## 配置

首次运行读取插件环境配置并建立 JSON 配置，之后以运行状态目录中的 JSON 为准。通过管理面板或工具配置保存可实时调整。环境变量模板见 [config.env.example](config.env.example)。

| 选项 | 默认值 | 含义 |
|---|---:|---|
| OpenHerPersonaGlobalConcurrency | 2 | 同时运行观测与未结束向量调用的各自上限 |
| OpenHerPersonaGlobalQueueMaxSize | 128 | 全局待处理任务上限 |
| OpenHerPersonaQueueMaxSize | 64 | 每 Agent 待处理任务上限 |
| OpenHerPersonaQueueMaxBytes | 1048576 | 待处理文本 UTF-8 字节预算 |
| OpenHerPersonaMessageCacheMaxBytes | 1048576 | 独立接口模式本地向量缓存预算；0 关闭 |
| OpenHerPersonaMessageCacheTtlMs | 300000 | 本地缓存有效期 |
| OpenHerPersonaSqliteCacheKiB | 4096 | SQLite 建议页缓存预算；关闭内存映射 |
| OpenHerPersonaAuditRetentionDays | 30 | 审计最长保留天数 |
| OpenHerPersonaAuditMaxRowsPerAgent | 1000 | 每 Agent 审计保留条数；0 停止记录并逐步清空历史 |
| OpenHerPersonaMaintenanceIntervalMs | 60000 | 后台维护间隔 |
| OpenHerPersonaMaintenanceBatchSize | 100 | 每轮迁移、审计删除、锚点清理各自的最大行数 |

预算下调后，缓存和数据库预算立即应用；已执行任务不强制中断，历史审计逐轮收敛。新任务入队时执行队列预算检查。

## 现有数据库原地升级

- 继续使用原数据库，原地新增二进制向量列，不重建 Agent 状态，不调用模型重新生成旧向量。
- 对有旧向量的数据库，在升级前生成一次一致性备份，备份位于数据库旁，后缀为 `.pre-f32.bak`。
- 首次备份使用 SQLite 一致性快照，需要磁盘空间并可能暂时阻塞初始化；不要在磁盘空间不足时升级。
- 旧文本逐轮转换为小端 32 位浮点二进制，转换成功后释放原文本内容；未转换行仍兼容读取。迁移进度写入元数据，可中断续跑。
- 32 位浮点有微小舍入误差，不改变评分算法。无效旧向量不会强制转换。
- 后台清理旧模型签名、不再匹配当前定义或 Agent 名称的锚点，以及没有当前状态的孤立锚点。
- 空闲页供后续复用；不自动执行整库压缩。因此数据库文件不会保证立刻缩小。
- 回退时先停止服务，再还原升级前完整数据库备份；不能直接只回退代码读取已转换的文本占位内容。备份生成之后的新观测不在备份中。

## 查询与诊断

现有状态、快照、重置、删除、配置读取/保存和架构解释接口保持兼容。状态结果新增资源统计：活动观测数、待处理数、文本字节数、本地缓存大小、未结束向量请求数、丢弃及去重计数、最近维护结果。

这些统计只描述本插件持有的资源，不代表 RAG 共享缓存或整个进程。进程常驻内存不立即下降并不等于对象泄漏；运行时可能保留已回收内存供复用。

## 验证

隔离测试见 [资源回归测试](../../tests/openHerPersonaResources.test.js)。测试使用临时数据库，不触碰真实运行状态。覆盖旧库迁移、浮点精度、连续观测、共享缓存零本地保留、队列预算、超时请求限额、关闭后防写回与审计清理。
